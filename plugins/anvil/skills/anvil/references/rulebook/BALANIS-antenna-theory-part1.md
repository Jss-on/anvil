## 3. Mechanizable checks

Inputs are columns of an antenna spec / link-budget table. c = 299,792,458 m/s (text uses 3e8); lambda = c/f in the medium. All dB quantities 10*log10 of power ratios.

`CHECK-far-field-distance`: inputs D_max (m, largest dimension of the antenna — or of either antenna for a link/range), f (Hz), R_test (m, measurement or link distance) → lambda = c/f; R1 = 0.62*sqrt(D^3/lambda); R2 = 2*D^2/lambda; if D <= lambda use R_reactive = lambda/(2*pi) and also require R_test >> lambda → pass if R_test >= max(R2, reactive boundary) (far field) → margin = R_test/R2 (>= 1 passes; report region = reactive / Fresnel / Fraunhofer) → BALANIS-1010, -1011, -1012, -1014, -1064. Note: multibeam/phase-sensitive apertures may need > 2D^2/lambda; patterns below -25 dB and near first nulls are not certified at exactly R2.

`CHECK-friis-link-margin`: inputs Pt (dBm), G0t, G0r (dBi) — or D0 and ecd per antenna —, |Gamma_t|, |Gamma_r| (or VSWR), PLF (dB, default 0; -3 dB for 45 deg linear misalignment; 0 for orthogonal = fail), f (Hz), R (m), receiver sensitivity S (dBm), other losses L_other (dB, cables etc.) → FSL(dB) = 20*log10(4*pi*R/lambda); mismatch_t = 10*log10(1 - |Gamma_t|^2), mismatch_r likewise; Pr(dBm) = Pt + G0t + G0r - FSL + mismatch_t + mismatch_r + PLF - L_other → pass if Pr - S >= required_margin_dB (spec) → margin = Pr - S - required_margin → BALANIS-1064, -1065, -1037, -1038, -1048. `CHECK-mismatch-efficiency`: inputs Zin (complex ohm) or VSWR, Z0 (ohm) → Gamma = (Zin - Z0)/(Zin + Z0); er = 1 - |Gamma|^2; mismatch loss (dB) = -10*log10(er); VSWR = (1 + |Gamma|)/(1 - |Gamma|) → pass if VSWR <= VSWR_spec (e.g., 2.0) across the band → margin = VSWR_spec - VSWR_worst → BALANIS-1037. ## 5. Pitfalls, failure modes, review checklist

- [ ] Antenna feed mismatch leaves standing waves that store energy in the line; at high power the peak fields can arc inside the line — check VSWR at rated power (§1.1 p.1–3).
- [ ] Balanced two-wire feed radiates if the spacing is not << lambda or if the conductors flare apart — keep s << lambda up to the antenna terminals (§1.4 p.16).
- [ ] 2D^2/lambda far-field distance may be inadequate for multibeam reflectors and other phase-sensitive apertures — increase range length or use near-field techniques (§2.2.4 p.32).
- [ ] The 0.62*sqrt(D^3/lambda) and 2D^2/lambda region boundaries assume D > lambda; for electrically small antennas use lambda/(2*pi) for the reactive boundary instead (§2.2.4 p.31–32).
- [ ] Patterns measured at exactly 2D^2/lambda differ from infinite-distance patterns near the first null and below about -25 dB — do not use such measurements to certify deep nulls/low side lobes (§2.2.4 p.33, Fig.2.9).
- [ ] Using peak-phasor formulas with RMS field values double-counts the 1/2 factor — state peak vs RMS in every power-density calculation (§2.3 p.36).
- [ ] Beam solid angle approximated by the product of two HPBWs overestimates wide beams (31% for a 60 deg-wide cap) (§2.2.5 Ex.2.1 p.35).
- [ ] Kraus beam-solid-angle directivity (41,253/(theta1*theta2)) doubles the true value for two identical main lobes and overestimates with significant minor lobes; Tai-Pereira always underestimates — pick by HPBW (39.77 deg crossover) (§2.6.1 p.48–51).
- [ ] Quoting "gain" without mismatch: IEEE gain excludes reflection and polarization loss — use realized gain (1 - |Gamma|^2)*G in link budgets (§2.9 p.62–63).
- [ ] A resonant lambda/2 dipole (73 ohm) fed directly from 50 ohm coax already loses 0.155 dB to mismatch (er = 0.965) (§2.9 Ex.2.10).
- [ ] Polarization mismatch: 45 deg linear misalignment costs 3 dB; orthogonal linear or opposite-sense CP gives (ideally) no signal — include PLF in every link budget (§2.12.2 p.72–74).
- [ ] The series Rr + RL equivalent circuit is invalid for antennas with lossy dielectric or over lossy ground (§2.13 p.76 footnote).
- [ ] At conjugate match only half of the captured power reaches the load; the rest is re-radiated/dissipated — aperture efficiency > 50% does not mean > 50% delivered (§2.13 p.79; §2.15.2 p.84).
- [ ] A long lossy feed can add tens of kelvin to antenna noise temperature (10 m WR-90 at 0.13 dB/m: 150 K -> 190.9 K) (§2.18 Ex.2.18).
- [ ] Very short dipoles (l <= lambda/50: Rr ~ 0.3 ohm) are almost unusable without matching; realized gain -14 dB on 50 ohm even though ecd ~ 92% (§4.2 Ex.4.1; Table 4.2).
- [ ] Assuming X = 0 at l = lambda/2 is wrong: a thin lambda/2 dipole has Zin = 73 + j42.5 ohm; resonance needs 0.47–0.48*lambda, shorter for thicker wire (§4.6 p.179).
- [ ] Full-wave (l = n*lambda) centre-fed dipoles: ideal theory predicts infinite Rin; real value is very large and set by feed gap/radius — never design from the ideal formula; use MoM (§4.5.5–4.5.6; §8.5.1).
- [ ] Quarter-wave monopole impedance 36.5 + j21.25 ohm assumes an infinite ground plane; handset chassis and finite grounds change pattern and impedance (§4.7.3–4.7.5).
- [ ] Horizontal dipole placed very close (h << lambda/4) above a PEC ground/chassis radiates poorly (image cancels; Rr ~ (h/lambda)^2) (§4.7.6 eq.(4-120); §4.8.3).
- [ ] Vertically polarized antennas over real earth have a null at the horizon (Rv -> -1 at grazing), unlike over PEC; low-angle coverage predicted with PEC ground is optimistic (§4.8.1 p.205).
- [ ] Flat-earth reflection models fail within ~57.3/(ka)^(1/3) deg (usually ~3 deg) of grazing; include divergence factor and roughness (Rayleigh h_m < lambda/(8*sin(psi))) (§4.8, §4.8.4).
- [ ] Handset antenna operated at a parallel (anti-) resonance: impedance varies rapidly and is hard to match — design for the series resonance (monopole: first; grounded folded loop: second) (§4.7.5; §5.8).
- [ ] Multiturn small-loop loss estimated as straight wire ignores proximity effect, which can double the ohmic resistance at close turn spacing (§5.2.3 p.243).
- [ ] Uniform-current loop formulas used beyond C ~ 0.2*lambda (a > 0.032*lambda) give wrong patterns/impedance; use nonuniform (Fourier) current analysis (§5.3–5.4).
- [ ] Ferrite rod effective permeability is set by core shape (demagnetization factor), not by the catalog mu of the material (§5.7.1).
- [ ] Grating lobes: uniform broadside d >= lambda, end-fire d >= lambda/2, scanned d >= lambda/(1 + |cos(theta0)|) — check at the highest frequency and largest scan angle (§6.3, eq.(6-37)).
- [ ] Hansen-Woodyard phasing with d ~ lambda/2 (instead of ~lambda/4) makes back lobes larger than the main lobe (§6.3.4 Fig.6.14).
- [ ] Binomial tapers for large N need huge amplitude ratios (126:1 at N = 10) — inefficient, hard-to-hold feed networks (§6.8.2).
- [ ] Dolph-Tschebyscheff designs with SLL above ~-21 dB (N = 10, d = lambda/4) have non-monotonic (edge-peaked) excitations; check coefficients before building the feed (§6.8.3 Fig.6.26).
- [ ] Dolph-Tschebyscheff spacing above (lambda/pi)*acos(-1/z0) lets the end-fire lobe exceed the design SLL; scanning reduces the allowed spacing further (0.8731 -> 0.5821 lambda for theta0 = 60 deg, N = 10, -26 dB) (§6.8.3–6.8.4).
- [ ] Lowering the design SLL does not always raise directivity (a -15 dB D-T array has lower D than a -20 dB one) (§6.8.3 p.341).
- [ ] Superdirective element spacing/excitations require impractical current tolerances (< ~0.3% is usually unattainable) and yield tiny efficiency — constrain with the sensitivity factor K (§6.9).
- [ ] Pattern multiplication ignores mutual coupling: surface waves in printed/waveguide arrays create scan-blindness dips (e.g. 46 deg, 72–73 deg examples) invisible in isolated-element patterns (§6.10.1; §8.7.4–8.7.5).
- [ ] Matching an array element to its isolated impedance is wrong for a scanned array — the active driving impedance changes with scan (§8.7.1).
- [ ] Woodward-Lawson gives exact values only at sample points and no control of side lobes in unshaped regions; Fourier synthesis gives Gibbs overshoot at pattern discontinuities (§7.4–7.5).
- [ ] Linear aperture phase error tilts the beam, cubic error skews side lobes, quadratic error (defocus, horn flare) fills nulls and raises side lobes — include phase-error tolerance in reflector/horn/lens specs (§7.9).
- [ ] MoM with too few segments can mislead badly (0.47*lambda dipole: 26.8 + j24.9 ohm at N = 7 vs ~77 + j9 ohm converged) — run convergence and compare feed models (§8.5.1 Table 8.2).
- [ ] Delta-gap feeds are least accurate for impedance; for coax-fed wires prefer a magnetic-frill model with b/a from the line impedance (§8.3.3).
