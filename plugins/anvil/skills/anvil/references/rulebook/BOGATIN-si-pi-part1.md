## 3. Mechanizable checks

Each check: inputs (columns, units) → formula → pass criterion → margin definition → source rows.

- `CHECK-high-speed-regime`: inputs Fclock[GHz], RT[ns] per driver → flag = (Fclock > 0.1) or (RT < 1) → informational; sets `hs_mode=true` enabling all checks below → margin n/a → BOGATIN-101.
- `CHECK-rise-time-default`: inputs Fclock[GHz], RT[ns] (may be blank) → if RT blank: RT = 0.1/Fclock (record assumption; use 0.07 × period for BW) → n/a → BOGATIN-102, 150.
- `CHECK-signal-bandwidth`: inputs RT[ns] → BW = 0.35/RT; if ringing present use f_ring → used by all model/measurement BW checks → n/a → BOGATIN-147, 151.
- `CHECK-model-bandwidth`: inputs BW_signal[GHz], BW_model[GHz] per model (T-line: ∞; n-section LC: n/(10·TD); single-C trace model: 1 GHz/in class; RLC cap model per datasheet fit) → pass if BW_model ≥ BW_signal → margin = BW_model/BW_signal − 1 → BOGATIN-154, 172, 266.

## 4. Verification procedures & plots

1. **Spectrum / bandwidth plot** (§2.6–2.12): DFT of the driver waveform with period = clock period, Hanning window; x = harmonic frequency (log), y = amplitude (dB or V) overlaid with the ideal square-wave 2/(πn) envelope; the knee where amplitude < 70% of the ideal harmonic is the BW; compare to 0.35/RT. Ringing shows as a peak > 10× above envelope → fix termination.
2. **Impedance-vs-frequency (SPICE impedance analyzer)** (§3.9): 1 A AC current source across the DUT model; plot abs(V) and phase 1 kHz–10 GHz log-log; capacitor RLC model must show −90° → +90° through SRF; PDN: curve must stay below Z_target from DC to signal BW; parallel resonant peaks flagged.
3. **Model-bandwidth comparison** (§2.15, §3.8): overlay measured abs(Z) (VNA/impedance analyzer) and simulated abs(Z); BW_model = highest f with agreement; add elements (C → LC → RLC → T) until BW_model ≥ BW_signal.
4. **Field-solver calibration** (§5.7, §7.16): run 2D solver on coax / twin-rod / rod-over-plane with exact formulas; require < 1% error before trusting Z0/CL results; then sweep w, t, soldermask, plane width (Figs 5-8, 5-9, 5-13, 7-32–7-36).
5. **Stack-up impedance sweep** (§7.17): Z0 vs w for each layer at nominal and ±fab tolerances; pass band ±10%; include soldermask −2 Ω/mil and plane extension ≥ 3h.
6. **TDR profile** (§1.13, §8.7, §8.16): x = round-trip time (or position via v/2), y = instantaneous Z (from 50(1+ρ)/(1−ρ)); flag dips (capacitive: pads, vias, corners) and peaks (inductive: gaps, connectors); compare to simulated TDR of the model with lumped C/L to extract values (e.g., 200 fF for two corners, 0.4 pF via).
7. **Reflection / ringing transient** (§8.5–8.6): SPICE transient with driver R_s, ideal T-line (Z0, TD), load; sweep RT 0.1–1 ns and R_series 0–90 Ω; pass if overshoot/undershoot ≤ 10% swing (5% conservative) and edges monotonic within switching window at every receiver.
8. **Discontinuity sweep** (§8.11–8.18): vary neck-down TD (0–40% RT), stub TD (20–60% RT), shunt C (0/2/5/10 pF), series L (0/1/5/10 nH) with 50 ps–0.5 ns edges; record reflected/transmitted peaks and 50% delay adders; compare to 4×RT pF and 10×RT nH limits and 0.5·Z0·C / 0.5·L/Z0 adders.
9. **Insertion-loss S21(f)** (§2.16, §9.12): VNA or lossy-line sim, 50 Ω ports, 10 MHz–20 GHz; y in dB; slope ≈ 0.1–0.2 dB/in/GHz for FR4; 3-dB point = interconnect BW; fit RLGC + via pi model to extract Dk/Df; note where constant-property fit fails (~14 GHz for FR4).
10. **Attenuation decomposition** (§9.11): plot α_cond (∝ sqrt f) and α_diel (∝ f) vs f for the trace width; crossover ≈ 1 GHz at 8 mil; check A(f_nyq) against 10/15/35 dB limits.
11. **Rise-time degradation** (§9.13–9.14): lossy-line transient (R ∝ sqrt f, G ∝ f — never constant R/G); input 50 ps step; report 10–90 and 20–80 RT and 70%-point delay; compare to sqrt(RT_in² + (10 ps/in × Len)²).
12. **Eye diagram** (§9.1, §9.14–9.16): PRBS at data rate through channel model, successively enabling conductor loss, dielectric loss, via C (0.5 pF each end); eye opening vs receiver mask; vertical closure ↔ ISI, horizontal crossover width ↔ jitter; if closed, evaluate CTLE/FFE/DFE budget.
13. **Crosstalk NEXT/FEXT** (§10.3, §10.11–10.13): coupled-line sim or measurement with all four ends terminated in Z0; aggressor step (e.g., 200 mV, 50 ps); near-end plateau = NEXT (lasts 2·TD), far-end pulse at TD of width RT = FEXT; sweep spacing 1w–3w and coupled length; pass ≤ 2% NEXT per pair, Σ ≤ 5%.
14. **Capacitance-matrix review** (§10.5–10.7): 3-D bar plot of SPICE C matrix; adjacent/diagonal ≈ 5% at s = w; two-over < 0.6%; negative off-diagonals mean Maxwell matrix — convert before SPICE.
15. **Current-distribution / return-path view** (§6.16, §7.13–7.14): 2D solver current density at 10 MHz and 100 MHz; return current must sit under the trace; check plane-switching vias and reference-plane nets.

## 5. Pitfalls, failure modes, review checklist

- Vendor die-shrink shortens rise times without notice; re-run SI checks on any new silicon revision even at < 50 MHz clocks (§1.7).
- Never use a model above its bandwidth; ask "how accurate, what bandwidth" of every model (§2.15, §3.8).
- Rules of thumb / approximations are never sign-off; use verified 2D/3D solvers when > 5% error matters; a 1% Z0 bias costs yield (§1.12, §7.17).
- Calling the return path "ground" leads to ignored return-path design; return current follows the trace (§7.1, §7.13).
- Plane-to-plane capacitance is negligible for decoupling (0.4 nF for 4 in² at 10 mil) — its job is low loop inductance (§5.5).
- Capacitance above SRF is irrelevant; only mounted loop inductance matters — six caps 10 pF–1 µF look identical at HF (§6.9).
- Multiple vias per cap pad help only if same-direction vias are ≥ via length apart (§6.7).
- Same-direction power leads/bonds packed closer than their length raise net inductance (§6.7).
- Ferromagnetic lead frames (Kovar, Alloy 42) have very high HF resistance — plate with silver (§6.17).
- Clearance-hole "Swiss cheese" adds only ≈ 25% plane inductance — not a disaster, but keep holes small (§6.12).
- Signal vias without a nearby same-net return via, or referencing planes of different nets, inject ground bounce and plane resonances (150–300 MHz on 10–20 in boards) (§7.14).
- A capacitor between different-voltage planes does not fix fast-edge ground bounce (> 1 GHz) — thin dielectric does (§7.14).
- Old CMOS drivers (90–130 Ω) cannot launch a usable level into 50 Ω; 50 Ω source → only half swing (§7.12).
- Series-terminated lines show a half-amplitude shelf at the source end for one round trip — no receivers near the driver (§8.10).
- Unterminated lines longer than RT (ns) in inches ring; today essentially all nets need a termination strategy (§8.9).
- BGA plating stubs (< 0.25 in) cause problems once RT < 0.25 ns (§8.12).
- Capacitive loads at the far end add 2.2·Z0·C delay (10 pF, 50 Ω → 1.1 ns) — include in timing; a mid-line 1 pF pad adds 25 ps and 50 ps of rise time (§8.13–8.15).
- Vias effective Dk 8–15 and impedance ≈ 35 Ω; via stubs are the chief serial-link limiter — back-drill / blind vias, stub < 10 mil (§8.17, §9.15).
- Axial-lead resistors (10 nH) are unusable below 1 ns edges; SMT (2 nH) below 0.2 ns needs integrated resistors (§8.18).
- Non-monotonic edges (inductive discontinuity at near end, capacitive dip) can false-trigger receivers placed there (§8.14, §8.18).
- 90° corners are negligible for ≤ 10-mil traces (10–20 fF) — do not spend effort there (§8.16).
- Lossy-line simulators with constant R and G predict no rise-time degradation — verify the simulator's model (§9.14).
- Radiative loss and coupling are not "attenuation"; reflections also degrade rise time in lossless lines — analyze each root cause separately (§9.2).
- Roughness can add ≈ 35% conductor loss above 5 GHz; humidity can double Df in polyimide flex (§9.5, §9.11).
- Dk and Df vary lot-to-lot; state the frequency; measure with a stripline coupon when better than 10% is needed (§5.4, §9.12).
- Line widths < 5 mil sharply raise conductor loss; > 10 mil buys nothing in FR4 (§9.15).
- 10 dB at Nyquist closes the eye; equalization needs a predictable, characterized channel (§9.16).
- Field solvers usually output Maxwell (negative off-diagonal) capacitance matrices — convert to SPICE form (§10.6).
- Removing dielectric above a microstrip reduces coupling capacitance yet increases FEXT; adding soldermask reduces FEXT but raises NEXT and lowers Z0 (§10.12–10.13).
- Crosstalk sums over all aggressors; a bus victim can see 2× the pair NEXT — budget 2% per pair (§10.1, §10.11).
- Specs demanding << 5% crosstalk cost density and money — challenge them (§10 intro).
- Never run a simulation or measurement without first estimating the answer (Rule #9); when results disagree with the estimate, stop and find out why (§1.12).
