## 3. Mechanizable checks

- `CHECK-route-stack-height`: inputs: panel thickness t (mm), n_panels, backup depth d_b (mm, default 1.5), entry thickness t_e (mm), router flute length L_f (mm) → H = n*t + d_b + t_e → pass if H <= 0.85*L_f (warn if > 0.75*L_f) → margin = 0.85*L_f − H → COOMBS-3004.
- `CHECK-route-spindle-speed`: inputs: router dia d (mm), V_target (m/min, default 200), n_min (RPM, 20,000), n_max (RPM, 100,000) → n = 1000*V/(pi*d) → pass if n_min <= n <= n_max; else flag "cutting speed deviates from target" → COOMBS-3008.
- `CHECK-vscore-clearance`: inputs: board thickness t (mm), web w (mm), score angle a (°), distance from score centerline to nearest copper/component feature s (mm), required extra clearance c (mm, per assembly rules) → groove half-width g = ((t − w)/2)*tan(a/2) → pass if s >= g + c → margin = s − (g + c) → COOMBS-3012 (medium: geometric derivation).
- `CHECK-vscore-coupon-present`: inputs: list of V-score lines, coupon nets → pass if every score line crosses an I- or U-shaped e-test coupon trace → COOMBS-3016.
- `CHECK-etest-spec-complete`: inputs: test spec fields {continuity_max_ohm, isolation_min_Mohm, isolation_V, fixture_method, class} → pass if all present and isolation_V <= 250 V unless hi-pot explicitly requested → COOMBS-3020/3022.
- `CHECK-tdr-required`: inputs: max signal frequency f (MHz), controlled-impedance nets → if f > 100 MHz and impedance-controlled nets exist → require TDR coupon in fab drawing; coupon trace >= 2 in, unbranched (Ch.40 value) → margin = L_coupon − 2 in → COOMBS-3023, COOMBS-3036.
- `CHECK-etest-continuity`: inputs: continuity threshold R_c (ohm), test current I (mA), product flag precision_or_highspeed (bool), matrix type (2-wire/4-wire) → pass if R_c specified and few ohm <= R_c <= 1000 ohm AND 5 <= I <= 50 mA; warn if precision_or_highspeed and R_c > 10 ohm (10 ohm is the common production floor; 5/10/25-ohm nets impair such products); warn if R_c < 10 ohm and matrix = 2-wire (switch resistance error) → margin = R_c,spec − R_c,used → COOMBS-3027/3028/3029.
- `CHECK-etest-isolation`: inputs: isolation threshold R_i (Mohm), test voltage V (V), test-area RH (%), algorithm {true, log, adjacency}, hi_rel (bool) → pass if R_i >= 2 Mohm (common floor; 1 kohm–1000 Mohm range), V <= 250 V (unless hi-pot is a separate requirement), RH < 55 %; warn if hi_rel and algorithm = log (misses parallel leakage) or adjacency analysis is 2-D only → COOMBS-3030/3031/3033/3038.
- `CHECK-parallel-leakage`: inputs: per-net list of leakage resistances R_k (Mohm) to other nets, threshold R_i (Mohm) → R_par = 1/Σ(1/R_k) → pass if R_par >= R_i → margin = R_par/R_i → COOMBS-3032.
- `CHECK-etest-measurement-count`: inputs: test points X, nets N, method → continuity C = X − N; isolation M_true = N, M_log = ceil(log2 N), M_flying,all-pairs = (N² − N)/2 → report counts/time estimate; flag flying-probe all-pairs when N > ~1,000 (499,500 measurements) unless adjacency/indirect methods used → COOMBS-3026/3033/3052.
- `CHECK-grid-density`: inputs: max local test-site density ρ (points/in²), grid type, min target pitch p (in) → capacity 100/200/400 points/in² for single/double/quad; pass if ρ <= capacity AND p >= 0.010 in for tilt-pin fixtures (else flying probe, coupled/shorting plate) → COOMBS-3040/3057.
- `CHECK-probe-compression`: inputs: compression stroke x (in), full travel x_full (in; text: 0.167 in = 2/3 travel ⇒ x_full ≈ 0.25 in, derived) → F = 55 g + 503 g/in · x → pass if x <= (2/3)·x_full and F < 180 g (never bottom) → margin = 180 g − F → COOMBS-3043.
- `CHECK-press-capacity`: inputs: active points per side N, probe force f (oz, 4–10), press rating F_press (lb) → F_req = N·f/16 lb → pass if F_req <= F_press → COOMBS-3051.
- `CHECK-tiltpin-hole`: inputs: pin dia PD (in), tilt A (°), plate thickness T (in), clearance HT (in), pin displacement PDisp and length PL (in) → HD = PD/cos(A) + T·tan(A) + HT (simplified for A < 15°: PD + T·PDisp/PL + HT + 0.001–0.002 in); drill = HD + 0.001 in (polycarbonate) → pass if A <= 10° (rule of thumb) and adjacent holes do not break out → COOMBS-3047/3048 (medium: equation reconstructed from prose).
- `CHECK-pth-lead-clearance`: inputs: finished hole dia D_h (mm, min of tolerance), lead dia d_l (mm, max incl. finish/solder-dip build-up) → gap = (D_h − d_l)/2 → pass if 0.07 <= gap <= 0.15 mm → margin = min(gap − 0.07, 0.15 − gap) → COOMBS-3063.
- `CHECK-via-aspect-ratio`: inputs: board thickness t (mm), drill dia d (mm), process Pb-free (bool) → AR = t/d → pass if AR < 10 (Pb-free), warn if 8 <= AR < 10 → COOMBS-3072.
- `CHECK-wave-board-thickness`: inputs: t (mm), SMDs on primary side (bool), fine-pitch/area-array on primary (bool), finish = OSP (bool) → warn if t > 2.36 mm (mixed mount); fail-risk if t > 2.54 mm with primary-side SMDs unless thermal shielding + profiling planned; warn OSP and t >= 2.36 mm (barrel fill) → COOMBS-3162/3216.
- `CHECK-pin-in-paste-volume`: inputs: t_board (mm), hole dia D_h, pin cross-section area A_pin (mm²), fillet volume allowance V_f (mm³), aperture area A_ap (mm², incl. over-print), stencil t_s (mm), transfer factor TF (0.6–1.0), solder volume fraction of paste f_v (from paste data sheet — not given in text) → V_req = t_board·(π D_h²/4 − A_pin) + V_f; V_avail = f_v·TF·A_ap·t_s (+ preforms) → pass if V_avail >= V_req; warn if t_board > 1.6 mm → COOMBS-3202/3206 (medium: volumetric model).
- `CHECK-stencil-deposit`: inputs: aperture W, L, stencil t (mm), TF (default by size 0.6–1.0), pitch p (mm), alloy → V_dep = TF·W·L·t; if Pb-free and p < 0.5 mm → recommend slightly larger apertures; if pitch range on board too wide for one t → stepped stencil → COOMBS-3083/3084.
- `CHECK-paste-viscosity`: inputs: viscosity η (kcps), method → pass if screen 250–550, stencil 400–800, dispense 100–400 kcps; metal content 80–90 wt % → COOMBS-3082.
- `CHECK-reflow-profile`: inputs per thermocouple: max heating ramp r_h (°C/s), max cooling ramp r_c (°C/s), soak plateau T_s (°C), TAL (s), peak T_p (°C); alloy liquidus T_L; per-component T_max and ramp limits; paste-vendor window → pass if r_h <= min(4, component limit), |r_c| <= component limit (typ. 1–4 °C/s), T_s in 100–125 (Sn-Pb) or 150–200 °C (Pb-free) unless vendor overrides, TAL in 30–60 s (vendor window), T_p >= T_L + 20 °C on the coldest TC and T_p <= min(component T_max, 260 °C for SAC / 240 °C Sn-Pb) on the hottest TC; warn if board ΔT_peak > 20 °C → margins = each limit − value → COOMBS-3073/3128/3131/3140/3188/3189/3190.
- `CHECK-component-reflow-rating`: inputs: component rated peak T_max,c (°C), rated reflow cycles n_rated, process peak T_p, cycles seen n (reflows + rework) → pass if T_p <= T_max,c and n <= n_rated; else route as odd-form/selective → COOMBS-3070/3128/3207/3231.
- `CHECK-msl-pbfree`: inputs: MSL rating (Sn-Pb profile), process Pb-free (bool) → MSL_eff = MSL + 2 (conservative) → flag if MSL_eff >= 5 or original MSL 5/6 → separate assembly/bake per J-STD-033 → COOMBS-3095/3200.
- `CHECK-wave-preheat`: inputs: top-side peak before wave T_top (°C), SMT alloy liquidus T_L,SMT (°C), barrel TC peak T_barrel (°C), wave alloy liquidus T_L,wave → pass if T_top <= T_L,SMT − 50 °C (SAC305: 160–170 °C) and T_barrel > T_L,wave → margin = (T_L,SMT − 50) − T_top → COOMBS-3209.
- `CHECK-wave-parameters`: inputs: pot T (°C), alloy, contact time t_c (s), preheat ramp (°C/s), component ramp limit → pass if pot T in 245–270 °C (Sn-0.7Cu: 255–275 °C), 2 <= t_c <= 10 s, ramp <= component limit (as low as 2 °C/s) → COOMBS-3069/3090/3158/3208.
- `CHECK-hand-solder-time`: inputs: dwell per joint t (s), alloy → pass if 3 <= t <= 7 s (Sn-Pb typical 3–4, Pb-free 5–7) → COOMBS-3066/3092.
- `CHECK-n2-oxygen`: inputs: oven O2 (ppm), smallest passive size, tombstone history → recommend 1000–1500 ppm; warn if O2 < 1000 ppm with 0402/0201 parts (tombstoning) → COOMBS-3185.
- `CHECK-oven-capability`: inputs: rail-to-rail ΔT (°C), zone set-point drift (°C), conveyor speed variation (cm/min), zone-separation test drift (°C) → pass if ΔT <= ±2 °C, drift <= ~2 °C, speed variation <= 1–2 cm/min, adjacent zones stay at set point → COOMBS-3191/3192.
- `CHECK-gold-embrittlement`: inputs: Au thickness t_Au (µm) on lead + pad, wetted Au area A (mm²), solder joint volume V_s (mm³), densities ρ_Au and ρ_solder (inputs; not given in text) → w_Au = ρ_Au·t_Au·A / (ρ_Au·t_Au·A + ρ_solder·V_s) → pass if w_Au < 2 wt %, warn 2–4 wt %, fail > 4 wt % (Thwaites threshold) → COOMBS-3163 (medium: mass-balance model).

- `CHECK-yield-vs-dpmo`: inputs: DPMO, joints per assembly N, target first-pass yield Y_t → Y = exp(−DPMO·1e-6·N) → pass if Y >= Y_t; else required DPMO_max = −ln(Y_t)/(N·1e-6) → COOMBS-3334.
- `CHECK-inspection-coverage`: inputs: package list (BGA/CSP/QFN/LGA/J-lead/0.5 mm gull-wing/0402/0201/01005), class, volume → require AXI (or x-ray sampling after process qualification) for hidden joints, AOI for <= 0402 parts; flag visual-only strategies (≈ 5 joints/s, ~50 % repeatability); require SPI + pre-reflow AOI on Pb-free/OSP lines → COOMBS-3337/3339/3341/3342.
- `CHECK-laser-power-density`: inputs: laser power P (W), spot diameter d (mm), laminate damage threshold (W/mm², input) → I = 4P/(π d²) → pass if I below damage threshold at the board; report sensitivity dI/I = −2·dd/d → COOMBS-3222.
- `CHECK-jumper-wires`: inputs: class, jumper shares PTH with component lead (bool), passes over/under components on primary side (bool), stacked count, staking at direction changes (bool) → fail if Class 3 and shares PTH; fail if Class 2/3 and passes over/under components; fail if stacked > 2 or staking missing → COOMBS-3333.
- `CHECK-lga-stack`: inputs: components/traces inside bolster, socket frame and heat-sink footprints, socket reuse count vs vendor limit, fastener pattern → pass if keep-outs empty (or bolster relieved and thickened), reuse <= vendor limit, tire-lug torque sequence specified → COOMBS-3247/3248/3249.
## 4. Verification procedures & plots

- **V-score web thickness**: measure web with caliper or edge-view microscope per lot; plot web vs. lot/time; pass = within drawing tolerance; off-center web indicates entered thickness ≠ actual (§38.8.5–6).
- **Routing tool life**: log distance in material per router; replace at 40–60 m (2.0 mm, FR-4, 4.5 mm stack); laser measurement station checks tool length/diameter/run-out before and after use (§38.4, §38.6.5).
- **Bare-board TDR**: impedance (ohm) vs. distance (in/ns) along coupon trace; several-inch uninterrupted trace; compare to target ± tolerance (§39.4.1.4).
- **Bare-board fixture validation** (§40.5.5): (1) compress fixture on a non-conductive plate of product thickness and run all-isolations (expect zero shorts); (2) compress on a conductive shorting plate (copper-clad G-10 wrapped in fresh Al foil, or flash-gold) and run all-shorts over several compressions (expect every point continuous, count = program count); then product test; identical errors on every board → pin-load error.
- **Spring-probe force plot** (§40.5.5): y = force (g), x = compression (in); line F = 55 + 503·x; mark 2/3 travel (0.167 in, 139 g) and bottoming (~180 g); good = operating point at ~2/3 travel with margin to bottoming.
- **Isolation leakage verification** (§40.3.2): per net, plot measured parallel leakage R_par (log Mohm) vs net index with threshold line; good = all above threshold; fail nets feed pair-search localization (may be ambiguous for distributed leaks — confirm on grid, not flying probe).
- **TDR** (§40.4.3, Fig. 40.7; §53.11.1.10.3): y = impedance (ohm), x = distance/time along a >= 2 in unbranched coupon trace; upper/lower pass bounds (default ±10 %); ignore launch region; rising to open at end is normal; prefer fixtured or flying-probe TDR over handheld (repeatability).
- **Flying-probe indirect test learning** (§40.4.4.1): test a first article with direct DC continuity/isolation, then learn per-net capacitance signature (C = i·t/dv); plot measured vs learned C per net; high C on adjacent nets ⇒ short suspect (verify DC), low C ⇒ open.
- **Reflow profile** (§49.3.4–49.3.8, Fig. 49.10, Fig. 43.23): y = temperature (°C), x = time (s), one trace per thermocouple (leading/trailing edge, center, sides, inner/outer BGA balls drilled from the back, fine-pitch leads, power/ground pins on planes, heavy parts and shadowed neighbours); overlays: liquidus line (183/217 °C), soak band (100–125 or 150–200 °C), TAL window (30–60 s), peak band (Sn-Pb ≈ 205–240, SAC 245–260 °C), component max line, ramp-rate annotations (heat 2–4 °C/s max, cool 1–4 °C/s); pass = every TC inside all windows; tracker >= 1 board length behind; re-run with a loaded train of boards and compare to single-board profile.
- **Oven diagnostics** (§49.3.3, §49.3.8.1, Fig. 49.11): transverse array of identical TCs on a low-mass insulating fixture; plot peak T vs rail position (good = within ±2 °C); zone-separation test (one zone +50 °C vs neighbours; good = neighbours hold set point); exhaust smoke test (lazy inflow at both ends, hot, with hottest/coolest recipes and with dummy boards); log manometer readings each shift.
- **Wave-solder profile** (§49.4.3): two-sided profile board (thermocouples top-side at SMT joints and connector bodies, bottom/barrel TCs at PTH pins); y = T, x = t; pass = top-side pre-wave T <= T_L,SMT − 50 °C (SAC305: 160–170 °C) and no top-side excursion to SMT liquidus, barrel TC > wave-alloy liquidus, wave contact 2–10 s; also use wave-height/contact-area/dwell diagnostic plates.
- **Flux deposition map** (§49.4.2.2.4, Fig. 49.26): pre-weighed labelled microscope slides taped under a carrier, spray, remove before preheat, dry gently, re-weigh; plot deposit (mg) vs x-y slide position; good = uniform edge-to-edge and front-to-back and matching vendor dried-weight target.
- **Solder-pot chemistry trend** (§47.4.2.1.3, §49.4.5): periodic chemical assay (not just melting range); plot Cu wt % (and Au, Fe, Zn, Cd, Al) vs time; for Sn-0.7Cu hold Cu ≈ 0.7 wt % (top off with Sn/Sn-Cu).
- **Press-fit force–distance fingerprint** (§51.8, Fig. 51.11): y = force (N), x = ram travel (mm); expected inflections: initial contact (a), compliant-section collapse (b–c), sliding friction rise (d–e), housing seated (f), steep wall (g); stop at gradient >= 75 %; log every cycle; alarms on peak force outside the empirically set envelope; after pressing check bottom-side protrusion and slivers.
- **Hot-bar setup** (§49.8.5): thermocouples at pad extensions/heels at both ends and center of the lead set plus neighbours (y = T, x = t per TC; good = uniform span temperature within process window); cold planarity by ink-transfer on a ceramic flat or pressure-transducer array.
- **Conformal coating QC** (§44.3–44.5): dyne-pen or 5 µL drop-diameter (Fig. 44.4) surface energy on production boards and coupons (>= 40 dynes/cm); daily cross-hatch tape adhesion on a coupon with the production mask (IPC-TM-650 2.4.1.6, no loss); thickness on a witness strip/coupon processed with the assembly vs type range; 100 % UV-light (or fluorescent AOI) coverage inspection (corners, lead ends, shadowed areas).
- **Thermal shock** (§53.12.1): daisy-chain resistance (ohm) vs cycle number (1…100…n) with continuous monitoring; y-axis ΔR/R (%); limit line +10 % between stabilized hot readings at cycle 1 and cycle 100; intermittents (usually at the hot extreme) flagged as failures.
- **SIR / MIR / ECM-CAF** (§53.12.2–53.12.5): insulation resistance (log ohm) vs time in chamber at the stated RH/T/bias; good = stays above the specified minimum with no dendrite/filament growth; precondition specimens with simulated assembly/rework cycles first.
- **Microsection evaluation** (§53.11.2): vertical section to hole center ±10 % at 100x (plating thickness at 3 points + minimum, voids, cracks A–F, etchback, smear, wicking, post separation) plus horizontal section (annular ring 360°, registration, separation); x- and y-direction sections for layer shift.
- **Yield vs joint count** (Fig. 55.2): y = first-pass yield (%), x = solder joints per assembly (log, 100–100,000), family of curves Y = exp(−DPMO·1e-6·N) for DPMO = 10, 40, 100, 400; mark design's N and target yield to read the required DPMO.
- **Inspection SPC** (§55.3.4, §55.7.1, Fig. 55.4, Fig. 55.8): SPI paste volume/height/area/offset per aperture as X-bar/R or individuals charts with control limits; pre-reflow AOI placement offset/skew charts; post-reflow heel-fillet height and void volume maps across the board (oven profile and spatial non-uniformity), average solder thickness (squeegee/stencil), pin-to-pad offset (placement accuracy); defect Pareto by type (opens, bridges, misalignment, tombstones, voids).
- **BGA x-ray** (§54.4.2.6, §50.2.2.14): per-ball void area % histogram with 25 % limit line; bridges/opens/missing balls/incomplete reflow flagged; 100 % on reworked BGAs, sampling after process stabilizes.
- **Solderability** (§53.11.1.9, §54.5): J-STD-003 (boards) and J-STD-002 (components) after accelerated aging per durability category; result = % area wetted (100 % on attachment points), dewetting only on planes for Class 1/2.
- **Rework IMC/reliability study** (§50.2.3, Fig. 50.2): cross-section IMC thickness vs number of reflow cycles at a site (1…5+); combine with thermal-cycle/shock results to set the site rework limit (2–3).
- **Laser/hot-bar pad integrity** (§49.7.3.10, §49.8.6.4): lead pull/peel tests and cross-sections after process setup to prove no pad delamination.
## 5. Pitfalls, failure modes, review checklist

- [ ] Router path runs CCW on outer contours and CW on cutouts (product side gets conventional milling) — §38.2.1.
- [ ] Router radius compensation and deflection compensation verified by first-run measurement — §38.2.3.
- [ ] Stack height ≤ 75–85 % of flute length including backup/entry — §38.2.4.
- [ ] Cut-out PCBs taped or pinned so they are not dragged by vacuum/pressure foot; vacuum off between boards — §38.2.2, §38.4.
- [ ] "Pressure-foot routing" used on last tab cut to avoid tips (else manual tip removal) — §38.4.
- [ ] V-score: board thickness in NC program equals actual; top/bottom cutter offset checked — §38.8.6.
- [ ] V-score coupon (I/U trace) included in e-test netlist — §38.8.5.
- [ ] Depth-controlled routing to inner layer uses electrical reference, not surface, when resin-flow thickness variation matters — §38.7.2.
- [ ] Bare-board test spec has explicit continuity/isolation thresholds and voltage; not just "100 % test" — §39.3.2.
- [ ] Leakage faults are treated as latent shorts (metal migration), not ignored — §39.4.1.3.
- [ ] Self-learned e-test programs prove boards are the same, not good — use data-driven (IPC-D-356) programs — §40.5.1.
- [ ] Learning switch/contact resistance on a dirty shorting plate masks high product resistance — §40.3.1.2.
- [ ] Log(N) isolation or 2-D adjacency analysis can miss parallel/cross-layer leaks on hi-rel boards — §40.3.2.3, §40.4.4.2.
- [ ] Flying-probe "verification" of distributed leakage may not reproduce it — re-test on a grid — §40.3.2.4.
- [ ] Over-compression of grid fixtures marks pads; probes never bottomed — §40.5.5.
- [ ] Flip testing leaves PTH links (and tented-via traces) untested — §41.3.4.1.
- [ ] Ship-from-verification can pass boards where an open masks a short — §41.5.
- [ ] Dense probe fields without opposing blind pins bow the board ("potato chip") — §42.2.
- [ ] Probe witness marks through HDI pad metallization degrade joint reliability — §42.1.
- [ ] Pb-free wave/selective: Cu erosion at PTH knee (dwell, Ni/Ge-doped alloy) — §43.2.2.3.
- [ ] Bottom-side SMT parts on a wave-soldered side must be glued and thermal-shock tolerant — §43.3.3.5.
- [ ] MLCCs crack under fast ramps and board flexure — §43.3.3.1.
- [ ] LCCCs on non-CTE-matched laminate fail by thermal fatigue — §43.3.3.1.
- [ ] Flux-only BGA/DCA attach lowers standoff and self-alignment — §43.3.3, §50.2.3.
- [ ] Sn-Pb and Pb-free on the same line: wrong paste, wrong finish, wrong MSL, wrong profile, wrong fiducial settings — §43.3.3.10.
- [ ] Printed/stuffed boards waiting in air due to line imbalance degrade paste — §43.5.1.
- [ ] Silicone coating/adhesive cross-contaminates other boards (adhesion failures) — §44.2.2.3, §52.4.2.
- [ ] Coating control coupon uses a different solder mask than production (false adhesion failures) — §44.3.4.
- [ ] Moisture not baked out (93 °C/4 h) before coating → corrosion, dendrites, CAF — §44.3.6.
- [ ] RTV silicone cured in a dry oven does not cure — §44.5.1.2.
- [ ] UV-cure coatings uncured under components without secondary cure — §44.5.1.4.
- [ ] Coating flowed under BGAs crushes balls on thermal cycling — §44.7.3.
- [ ] Coating over surface microstrip shifts impedance — §44.7.1.2.
- [ ] High-modulus coating below −10 °C cracks BGA balls; Tg inside the operating range causes sudden stiffening — §44.7.2.
- [ ] Polyglycol water-soluble fluxes lower laminate insulation resistance — §45.7.
- [ ] VOC-free (water) flux not fully dried in preheat → solder balls — §45.8.
- [ ] Pb-free flux residues set harder — delay between reflow and cleaning makes removal worse — §45.9.3.
- [ ] Toe fillets absent on excised (bare Cu) lead tips are acceptable — do not rework — §46.4.5.
- [ ] Tall, shiny fillets can mean overheating/brittle joints or wicking — §46.4.5.
- [ ] Bi-bearing solders + any Pb (HASL, Sn-Pb lead finish, high-Pb balls) → 96 °C ternary — §47.4.2.1.1.
- [ ] Bi fillet lifting in PTH wave joints; cooling fix may exceed component ramp limits — §47.4.2.1.1.
- [ ] Sn-0.7Cu pot drifts off-eutectic as Cu dissolves — §47.4.2.1.3.
- [ ] Zn solders: paste shelf life, dross, corrosion, spalling — §47.4.2.1.5.
- [ ] OSP loses protection after two reflows; misprint solvents strip it; OSP test pads resist ICT probes — §47.5.2.
- [ ] Au > ~2–4 wt % in joints embrittles; fine-pitch joints (small solder volume) reach it sooner — §47.5.3.
- [ ] ENIG black pad (P-related) — brittle fracture, no quick screen — §47.5.4.
- [ ] ImAg sulfidizes, forms planar microvoids and migrates under bias — §47.5.6.
- [ ] Sn directly over Cu: IMC growth, short solderable shelf life — §47.5.7.
- [ ] Pure Sn: whiskers; below 13 °C tin pest — §47.5.7.1–2.
- [ ] Pooled/unheated no-clean repair flux stays acidic and corrodes — §48.6.2.2.5, §50.6.2.
- [ ] Wave spray flux wicks under pallets onto ICT pads — §48.6.2.2.3, §49.4.9.
- [ ] Aqueous cleaning a no-clean board gives white sticky residue (SIR loss) — §48.6.3.1.2, §50.6.1.
- [ ] Ultrasonic cleaning of populated boards damages crystal oscillators and internal bonds — §48.6.3.1.1.
- [ ] Wiping misprinted paste drives solder beads into vias/PTHs/gold fingers — §48.6.3.1.1.
- [ ] Mixed no-clean flux families (paste/wave/repair) untested for SIR/ECM compatibility — §48.6.4.
- [ ] Ultralow O2 in N2 reflow promotes tombstoning of small passives — §48.7.1.3.2.
- [ ] Tombstoning from thermally unbalanced pads (one pad on a plane, one on a thin trace) — §48.7.1.3.2.
- [ ] Hydrogen "fluxing" is only a cover gas and an explosion hazard (LEL 4.65 %) — §48.7.3.1.
- [ ] Rapid paste heating → spatter/solder balls; under-heating → graping; over-heating → charred flux, brittle joints — §49.3, §49.3.5.1.
- [ ] Thermocouple with a stray junction reads oven air → cold joints — §49.3.8.2.1.
- [ ] Profile tracker/dummy board too close to the profile board biases the profile — §49.3.8.5.
- [ ] Taped thermocouple beads lift off their target — §49.3.8.3.4.
- [ ] Boards spaced too closely in the oven change the profile — §49.3.3.4.
- [ ] Thin, large boards sag above Tg on pin-chain conveyors — §49.3.1.2.1.
- [ ] Flux condensate in cooling zones drifts the profile and drips on boards — §49.3.2.2.
- [ ] Plastic connector bodies distort at reflow (contact normal force loss) — §49.3.5.3.4, §49.3.9.4.
- [ ] Pin-in-paste on thick boards is solder-starved; overprint creates loose balls; displaced paste beads on pin tips — §49.3.9.
- [ ] Wave re-reflows primary-side fine-pitch/BGA joints on thin dense boards or via-connected pads — §49.5.
- [ ] Component body sealing a PTH (gas lock) → poor fill/voids — §49.5.
- [ ] Small or unchamfered pallet openings starve heat and solder (gas lock) — §49.4.8.2.
- [ ] Air knife with air (not N2) increases dross; wrong angle disrupts the wave — §49.4.2.5.1.
- [ ] CO2 laser soldering chars laminate; reflected beams damage neighbours — §49.7.3.
- [ ] Hot-bar: excess force slides leads off domed pads, bridges; distorted blades give opens — §49.8.3, §49.8.6.
- [ ] Hand-held hot-air tools give inconsistent, scorched rework — §49.9.
- [ ] Rework beyond 2–3 cycles per site, or re-balled ICs beyond their rated reflow count — §50.2.3.
- [ ] Wick allowed to freeze on the pad lifts it (board scrapped) — §50.2.2.5.
- [ ] Solder fountain pulling a part before all joints are molten tears barrels — §50.3.
- [ ] Solder or flux on gold fingers (dissolves Au; needs replating) — §50.6.4.
- [ ] Press-fit into HASL/over-plated barrels: pre-compressed pins, slivers, lifted rings — §51.6.2–51.6.3.
- [ ] Press-fit with arbor press / no force monitoring; unsupported board flexes and cracks joints — §51.8.1.1, §51.11.6.
- [ ] Soldering press-fit pins or reusing a removed press-fit connector — §51.9, §51.11.11.
- [ ] Surface traces crushed under press-fit standoffs or LGA socket frames — §51.10.4, §52.6.1.
- [ ] LGA socket wiped or air-blasted (contacts damaged); silicone-adhesive tape residue on LGA lands — §52.4.2–52.4.4.
- [ ] Uneven LGA fastener tightening (no tire-lug pattern) — §52.4.7.
- [ ] Test coupons not drilled/processed like the product misrepresent it — §53.3.2.
- [ ] Microsections from sheared/punched samples or polished off-center give false results — §53.11.2.1.
- [ ] Ionic and organic cleanliness tests each miss the other's contaminants — §53.11.1.8.4.
- [ ] Conductor-width acceptance allows 20–30 % reduction — design ampacity/impedance with it — §53.11.1.3.1.
- [ ] "Target" condition treated as a requirement, or process indicators ignored (no trend monitoring) — §54.1.2.4.
- [ ] Pb-free grainy joints rejected as "cold" — §54.1.1, §43.3.3.7.
- [ ] Components >= 2 years old used without solderability re-test — §54.5.
- [ ] Leads trimmed after soldering without reflow or 10x inspection — §54.6.8.
- [ ] Jumper wire in the same PTH as a component lead on Class 3 — §54.10.3.
- [ ] Electrical test alone used as the quality gate (finds faults, not defects) — §55.2.
- [ ] Visual-only inspection for fine pitch/hidden joints (≈ 50 % self-repeatability) — §55.6.4.
- [ ] Board "families" with intentionally empty sites confuse missing-part calls — §55.6.4.5.
