## 3. Mechanizable checks

Units: V, A, ohm, F, H, Hz, s, W unless stated. "margin" is reported as (actual - limit)/limit unless stated.

### Power conversion

- `CHECK-linreg-headroom`: inputs V_sec_rms (V, transformer rating), line_low_frac (default 0.10; brownout 0.20), V_F (V per diode, bridge = 2 diodes), I_load (A), C_nom (F), C_tol_low (default 0.30), f_line (Hz), V_out, V_DO (LDO 0.5-1 V; LM317-class 2 V) -> V_pk = 1.414*V_sec_rms*(1 - line_low_frac) - 2*V_F; V_trough = V_pk - I_load/(2*f_line*C_nom*(1 - C_tol_low)) -> pass if V_trough >= V_out + V_DO -> margin = V_trough - (V_out + V_DO) (V) -> AOE-3015, 3017, 3020, 3026, 3195. (Also measure: loaded transformer droop is not modeled.)
- `CHECK-linreg-dissipation`: inputs I_out, V_in_avg (use high line, V_pk - ripple/2), V_out, R_thJC, R_thCS, R_thSA, T_A, T_Jmax -> P = I_out*(V_in_avg - V_out); T_J = T_A + P*(R_thJC + R_thCS + R_thSA) -> pass if T_J <= T_Jmax - derate (e.g. 25 C) -> margin = T_Jmax - T_J -> AOE-3016, 3031, 3196, 3197.
- `CHECK-reservoir-cap-voltage`: inputs V_sec_noload_rms (or V_sec_rms x regulation factor), line_high_frac (125-130 V on 120 V: ~0.083), V_F, V_rating -> V_max = 1.414*V_sec_noload_rms*(1 + line_high_frac) - 2*V_F -> pass if V_rating >= V_max -> margin = V_rating/V_max - 1 -> AOE-3022.
- `CHECK-reservoir-ripple-current`: inputs I_dc, I_rms_meas (optional), I_rip_rated (A rms at T), ESR_max, n_parallel -> I_rms = I_rms_meas or 2*I_dc; per-cap I = I_rms/n_parallel; P = I^2*ESR_max -> pass if I <= I_rip_rated (with margin >= 1.5 recommended) -> margin = I_rip_rated/I - 1 -> AOE-3019, 3023, 3024, 3049.
- `CHECK-line-fuse`: inputs I_line_rms_meas (true rms), fuse_rating, fuse_type -> pass if fuse_rating >= 1.5*I_line_rms_meas AND fuse_type == slow-blow -> margin = fuse_rating/(1.5*I_line_rms_meas) - 1 -> AOE-3004, 3005.
- `CHECK-xcap-bleeder`: inputs C_X, R_bleed, V_line_rms -> tau = R_bleed*C_X; P_standby = V_line_rms^2/R_bleed -> pass if tau < 1 s; report P_standby -> AOE-3009, 3010.
- `CHECK-charge-pump-ripple`: inputs I_out, f_osc, C_out, ESR, V_ripple_max -> V_rip = I_out/(2*f_osc*C_out) + 2*I_out*ESR -> pass if V_rip <= V_ripple_max; also I_out <= ~100 mA -> AOE-3032, 3033.
- `CHECK-buck-ccm`: inputs Vin_min, Vin_max, Vout, Iout_min, Iout_max, f_sw, L, I_sat_L, I_sw_limit -> T = 1/f_sw; D = Vout/Vin; Iout_crit = (T/(2L))*Vout*(1 - Vout/Vin_max); dIL = (T/L)*Vout*(1 - Vout/Vin_max); IL_pk = Iout_max + dIL/2 -> pass if Iout_min >= Iout_crit (if CCM required) AND IL_pk <= min(I_sat_L, I_sw_limit) -> margins reported for each -> AOE-3043..3048.
- `CHECK-boost-ccm`: same inputs -> D = 1 - Vin/Vout; Iout_crit = (T/(2L))*(Vin/Vout)^2*(Vout - Vin) (evaluate over Vin range, take max); IL_pk = Iout_max/(1 - D_max) + (T/(2L))*Vin_min*D_max -> pass as above -> AOE-3060..3063.
- `CHECK-inverter-ccm`: inputs as above with abs(Vout) -> D = abs(Vout)/(abs(Vout) + Vin); Iout_crit = (T/(2L))*abs(Vout)*(Vin/(Vin + abs(Vout)))^2; IL_pk = Iout_max/(1 - D) + (T/(2L))*Vin*D -> pass as above -> AOE-3064..3066.
- `CHECK-current-mode-slope-comp`: inputs control_mode, D_max -> fail if control_mode == current AND D_max > 0.5 AND slope_compensation == false -> AOE-3075.
- `CHECK-flyback-dcm`: inputs P_out, V_F, R_loss_sec, f_sw, L_M, Np, Ns, Vin_min, V_out -> N = Np/Ns; P_sec = (V_out + V_F)*I_out (+ I^2 R); E = P_sec/f_sw; L_Msec = L_M/N^2; Is_pk = sqrt(2E/L_Msec); Ip_pk = Is_pk/N; t_p = L_M*Ip_pk/Vin_min; t_s = L_Msec*Is_pk/(V_out + V_F) -> pass (DCM) if t_p + t_s < 1/f_sw -> margin = dead time -> AOE-3116, 3117, 3118.
- `CHECK-flyback-clamp`: inputs L_leak, Ip_pk, f_sw, V_Z, N, V_out, V_F, Vin_max, V_DSS -> P_clamp = 0.5*L_leak*Ip_pk^2*f_sw; V_DS_pk = Vin_max + V_Z -> pass if V_Z > N*(V_out + V_F) AND V_DS_pk <= 0.8..0.9*V_DSS AND P_clamp <= TVS rating -> AOE-3103, 3119, 3120.
- `CHECK-forward-switch-voltage`: inputs Vin_max, reset_ratio (1 for 1:1 tertiary) -> V_DS_pk = Vin_max*(1 + reset_ratio) + spike_allowance -> pass if V_DS_pk <= derated V_DSS -> AOE-3103.
- `CHECK-hard-switching-loss`: inputs C_node (F), V_sw (V), f_sw -> P = 0.5*C_node*V_sw^2*f_sw -> report; flag if P > x% of P_out -> AOE-3105.
- `CHECK-offline-inrush`: inputs V_line_pk, R_series (NTC cold R or switched resistor), bridge I_FSM, fuse I2t -> I_inrush = V_line_pk/R_series -> pass if I_inrush <= bridge I_FSM (and fuse/upstream breaker tolerate) -> AOE-3101, 3129.
- `CHECK-pfc-required`: inputs P_in, market -> flag PFC required/expected if P_in > 100 W (common practice >= 50 W; regulatory) -> AOE-3102.
- `CHECK-crowbar-window`: inputs V_nom, tol, V_transient (load step + remote-sense overshoot), V_trip_min, V_trip_max, V_absmax_load -> pass if V_nom*(1 + tol) + V_transient < V_trip_min AND V_trip_max < V_absmax_load -> margins both sides -> AOE-3176..3179.
- `CHECK-foldback-startup`: inputs I_max, I_sc, load V-I curve (optional) -> pass if I_sc >= I_max/3 (preferred I_max/2) AND (if curve given) no stable intersection below V_out_nominal -> AOE-3186, 3321.
- `CHECK-load-switch-fault`: inputs V_supply, I_limit (short-circuit), R_fault sweep, SOA/thermal limit, fault duration -> P_fault(R) = I(R)*(V_supply - I(R)*R) with foldback I(R); pass if max P_fault <= allowed for the fault duration (or protected switch used) -> AOE-3320, 3321, 3322.
- `CHECK-ldo-output-cap`: inputs C_out, ESR, C_min, ESR_min, ESR_max -> pass if C_out >= C_min AND ESR_min <= ESR <= ESR_max -> AOE-3184.
- `CHECK-outboard-pass-headroom`: inputs V_out, V_DO_reg, V_BE (0.7), n_VBE (1 or 2), V_in_min -> pass if V_in_min >= V_out + V_DO_reg + n_VBE*V_BE -> AOE-3187.
- `CHECK-hv-resistor-voltage`: inputs per resistor V_across, package -> rating table (1/4 W axial 250 V; 1206 200 V, 0805 150 V, 0603 75 V, 0402 50 V, 0201 30 V) -> pass if V_across <= rating (and not carbon comp in HV dividers) -> AOE-3191, 3192.
- `CHECK-isolation-spacing`: inputs V_working_rms/dc, V_peak_transient, insulation_type, pollution_degree, material_group, measured clearance/creepage -> look up required values (IEC tables; first cut 120 Vac: 2 mm / 4-8 mm) -> pass if measured >= required (clearance vs V_peak, creepage vs V_rms) -> AOE-3108..3113.
- `CHECK-emi-input-filter`: inputs C_X, f_ring (switch-node ringing), target attenuation A -> f_c = f_ring/sqrt(A); L_required = 1/((2*pi*f_c)^2*C_X) -> pass if L_leak(CM choke) >= L_required -> AOE-3126.
- `CHECK-output-lc-postfilter`: inputs L, f_sw, Z_C(f_sw) -> pass if 2*pi*f_sw*L >= 10*Z_C (example 27x) -> AOE-3124.
- `CHECK-flyback-gap`: inputs L_M, N_p, A_L_ungapped -> A_L = L_M/N_p^2 -> flag if flyback and A_L ~ A_L_ungapped (core not gapped) -> AOE-3121.
- `CHECK-battery-life`: inputs C_batt (mAh), I_avg (mA), derating -> t = derating*C_batt/I_avg -> pass if t >= requirement -> AOE-3237.

### References / precision analog

- `CHECK-zener-bias-sensitivity`: inputs r_z, dI_z, TC, dT -> dV_bias = r_z*dI_z; dV_T = TC*V_Z*dT -> flag if dV_bias > dV_T (bias from constant current) -> AOE-3142.
- `CHECK-reference-error-budget`: inputs accuracy (ppm), TC (ppm/C), dT, drift (ppm/sqrt(kHr) or ppm/kHr), t_hours, hysteresis (ppm), line_reg (ppm/V), dV_in, load current (should be ~0) -> total = accuracy + TC*dT + drift_term + hysteresis + line_reg*dV_in -> pass if total <= budget; flag if I_load > datasheet light-load value (self-heating) -> AOE-3161, 3162, 3165, 3167.
- `CHECK-reference-filter`: inputs R, C (bootstrapped two-stage), op-amp I_B -> f_-3dB = 3.3/(2*pi*R*C); t_settle(0.1%) = 14*R*C; dV = I_B*R -> pass if dV <= LSB/2 and t_settle acceptable -> AOE-3159.
- `CHECK-thermal-emf`: inputs lead dT, material pair (Kovar-Cu 35 uV/C), V_ref -> error_ppm = 35e-6*dT/V_ref*1e6 -> pass if <= budget -> AOE-3146.

### Digital logic

- `CHECK-logic-level-compat`: inputs driver (V_OH_min@I, V_OL_max@I, V_OH_max = its V_CC), receiver (V_IH_min, V_IL_max, V_in_max incl. tolerance, powered/unpowered) -> NM_H = V_OH_min - V_IH_min; NM_L = V_IL_max - V_OL_max -> pass if NM_H >= 0.4 V (TTL-class) or >= design margin, NM_L >= margin, V_OH_max <= V_in_max (receiver) -> AOE-3201, 3206, 3207, 3261, 3276, 3279.
- `CHECK-unused-inputs`: netlist scan -> count CMOS inputs with no driver/pull and async SET/CLR not tied inactive -> pass if count == 0 -> AOE-3208, 3259.
- `CHECK-cmos-dynamic-power`: inputs C_pd per gate, C_L per node, V_DD, f per node -> P = sum((C_pd + C_L)*V_DD^2*f) -> report vs budget -> AOE-3209.
- `CHECK-sync-path-timing`: inputs t_co_max, t_logic_max (sum), t_setup, t_skew, f_clk; t_co_min, t_logic_min, t_hold -> setup slack = 1/f_clk - (t_co_max + t_logic_max + t_setup + t_skew); hold slack = t_co_min + t_logic_min - t_hold - t_skew -> pass if both >= 0 -> AOE-3220, 3230, 3232.
- `CHECK-async-crossing`: netlist: every signal crossing clock domains (or from switches/external) passes >= 1 (preferably 2) synchronizer flip-flops; report metastability window rate R = f_clkS*f_clkF*(t_s + t_h) -> AOE-3221, 3226, 3246.
- `CHECK-no-async-reset-from-decode`: netlist: flag async CLR/LOAD driven by combinational decode of the same counter's outputs -> AOE-3228, 3249.
- `CHECK-bypass-caps`: inputs IC list with supply pins, 0.1 uF ceramics near each, bulk electrolytics per board -> pass if each IC has >= 1 x 0.1 uF within placement distance and board has >= 1 bulk ~10 uF (damping) -> AOE-3252, 3347.
- `CHECK-ground-bounce`: inputs N_switching outputs, C_L each, V swing, t_r, L_ground (5 nH/cm x length or package L) -> V_bounce = L*N*C_L*V/t_r^2 (from V = L dI/dt with I = C dV/dt, triangular) ; simpler per text: I = C*V/t_r, V = L*I/t_r -> pass if V_bounce < NM_L -> AOE-3254, 3348.
- `CHECK-slow-edge-clock`: inputs t_r of clock nets, receiver family (fast), Schmitt? -> flag if t_r > receiver t_pd (or > ~2x) on an edge-sensitive input without Schmitt -> AOE-3247, 3283.
- `CHECK-latchup-series-R`: inputs V_overdrive_max, V_rail, V_diode (0.6), I_IK_max -> R_min = (V_overdrive_max - V_rail - V_diode)/I_IK_max -> pass if R_series >= R_min -> AOE-3257, 3274.

- `CHECK-esd-input-network`: inputs exposure (connector?), R_total, C, t_edge needed -> tau = R_total*C -> pass (option C) if R_total >= 1.5 kOhm AND tau >= 100 ns AND Schmitt input; or clamp diodes + series R present -> AOE-3288, 3289.

## 5. Pitfalls, failure modes, review checklist

### Power entry and linear/unregulated supplies
- [ ] Line fuse present, slow-blow, sized >= 1.5 x measured true-rms line current (not from dc load). (p.630-631)
- [ ] Cartridge fuse holder: hot lead on the rear terminal. (p.631)
- [ ] 3-wire cord, PE bonded to the case; transformer isolation for any instrument that connects to other gear. (p.629, 632)
- [ ] X caps across line / Y caps line-to-ground only (correct class); X-cap bleeder with tau < 1 s; bleeder standby power budgeted. (p.631-632)
- [ ] MOV fitted with thermal-cutout fuse. (p.632)
- [ ] All mains terminations insulated (heat-shrink, not tape). (p.632)
- [ ] Unregulated rail checked at low line (-10%/-20%) and full load at the ripple trough, and at high line/no load against cap voltage rating. (p.632-634)
- [ ] Transformer rms current rating ~2x dc load; reservoir cap ripple-current rating vs ~2x dc load; ESR heating computed. (p.633-634)
- [ ] Electrolytic tolerance -30%/+100% assumed in ripple math; do not oversize caps (transformer heating). (p.633-634)
- [ ] Bleeder / minimum-load resistors on unregulated rails; RC snubber across the transformer secondary. (p.634)
- [ ] Signal diodes (1N914/4148) never used as power rectifiers; fast/Schottky rectifiers in switchers. (p.634-635)

### Switching converters
- [ ] Switcher noise measured at the LOAD end, not just across the supply pins (ground-current spikes ~150 mV observed 50 cm away). (p.636)
- [ ] Low-level analog (<= ~100 uV signals) on linear regulators, not switchers. (p.650, 673)
- [ ] Converter stability tested with the actual input LC filter (negative input resistance can oscillate). (p.646, 650)
- [ ] DCM at light load considered (loop gain change; minimum-load spec; burst mode). (p.643, 650, 672)
- [ ] Current-mode with D > 50% has slope compensation; LEB + RC/100 pF on current-sense. (p.650, 652, 658)
- [ ] Soft start present (overshoot, inductor/transformer core saturation is a major failure cause). (p.650)
- [ ] Transformer converters: core reset (forward), flux balance (bridge/push-pull: blocking cap or current mode), dead time against shoot-through, snubbers on the switch node. (p.657-660)
- [ ] Off-line switch V_DS rated for 2 x Vin_max (forward) or Vin_max + reflected + leakage spike (flyback). (p.662)
- [ ] Flyback clamp is a TVS-class part with fast soft-recovery series diode; clamp power 1/2 L_L Ip^2 f budgeted. (p.669-670)
- [ ] Isolated feedback (opto/transformer) for isolated converters; clearance/creepage met including across Y caps, optos, transformer margins, and PCB slots where needed. (p.662-665)
- [ ] Controller powered from an aux winding has a kick-start path. (p.668-669)
- [ ] Inrush limiting (NTC or switched resistor) or PFC; PFC for >~50-100 W off-line. (p.661-662, 668)
- [ ] Never probe an off-line primary with a grounded scope ground; use an isolation transformer. (p.672)
- [ ] Don't rely on a switcher's internal OVP alone - add an independent crowbar where overvoltage is destructive. (p.672, fn119)
- [ ] Spread-spectrum dithering is not a substitute for layout/filtering (total energy unchanged). (p.649 fn82)

### References, crowbars, protection
- [ ] Zener references biased from a constant current (r_z x dI can exceed TC error). (p.675)
- [ ] Self-biased reference op-amp on a single supply (no wrong-polarity latch) with start-up path. (p.675-676)
- [ ] Precision reference not used as a regulator (self-heating); buffered by a precision op-amp; low-DA/no-piezo (avoid ceramic) noise-filter capacitor. (p.682-684)
- [ ] Reference line regulation checked when powered from a battery/unregulated rail. (p.684)
- [ ] Floating-gate references shielded from X-ray (airport, AXI). (p.684)
- [ ] Thermal EMFs at reference/precision leads (Kovar-Cu ~35 uV/C) - avoid gradients. (p.675 fn128)
- [ ] Crowbar trip window above tolerance + transients, below load abs max; supply behind a crowbar has foldback or fuse that will actually open. (p.690-692)
- [ ] Power-zener clamps sized for V_Z x I_limit or replaced by active zeners; MOSFET clamps checked for oscillation. (p.692)
- [ ] Foldback not so aggressive that nonlinear loads (lamps, LDOs, capacitive, motors, dc-dc) fail to start. (p.694, 824)
- [ ] Outboard pass transistors have their own current limit and heatsinking for shorts (no thermal shutdown). (p.695)
- [ ] HV circuits: MOSFET rated beyond the full supply; resistor voltage ratings (not just power) respected; no carbon-composition resistors in HV dividers; gate zeners, gate resistors/ferrites against HV-MOSFET oscillation. (p.696-698)

### Digital logic
- [ ] No floating CMOS inputs (including unused gate sections and SET/CLR pins). (p.718, 738, 754, 760)
- [ ] Every power pin connected (a chip can run parasitically through an input). (p.760)
- [ ] Mixed-voltage interfaces: level/threshold compatibility and input over-voltage tolerance (including unpowered state) checked; no 5 V TTL-level (2.4 V min) outputs into V+/2-threshold 5 V CMOS. (p.718, 795-800)
- [ ] Inputs that may be overdriven (connectors, other boards) have series R limiting clamp current below latch-up level (e.g. 20-50 mA). (p.759, 795, 806)
- [ ] Async inputs synchronized; no combinational decode of ripple counters; no async reset from decoded counter states; state machines escape all unused states; power-on reset via supervisor. (p.733-757)
- [ ] Clock nets driven by strong fast buffers, not slow heavily-loaded MCU pins; Schmitt on slow/noisy clock sources; PLD clocks on global nets. (p.757, 801)
- [ ] Hazard-cover (consensus) terms retained in HDL MUX logic. (p.724 fn40, p.756)
- [ ] Removal time respected after async control de-assertion. (p.758)
- [ ] 0.1 uF per IC plus bulk electrolytics; ground plane; avoid faster families than needed; watch ground bounce on wide buses. (p.758-759, 856-857)
- [ ] Switch inputs debounced when they drive edge-sensitive logic; switch contact wetting current or gold contacts. (p.729, 802-804)
- [ ] Multiplexed LED peak current only with short ON time; firmware crash cannot leave an LED/driver stuck ON. (p.752)
- [ ] Transmission-gate multiplexers: unselected outputs pulled to a defined level; no fan-out assumed. (p.725-727)

### Interfacing, loads, cables, isolation
- [ ] LEDs/relays wired so the logic output sinks (TTL/nMOS-style outputs); series resistor always present; GaN LEDs not on 3.3 V drive. (p.817-818, 826-827)
- [ ] Relay coils have flyback diodes (or driver avalanche energy >= L I^2/2); coil current within driver sink rating; coil polarity checked. (p.817-820)
- [ ] Power load switches protected against shorts/faults (current limit, foldback, thermal) - preferably protected/intelligent switches. (p.823-826)
- [ ] High-current SSR drop dissipation heatsinked; zero-cross SSRs not used to switch transformer primaries. (p.823, 850)
- [ ] LED-driver boost converters have open-LED overvoltage clamps. (p.832)
- [ ] Comparators always have hysteresis (+ small speed-up cap), low source impedance, input common-mode and differential-voltage limits respected; accurate thresholds not loaded heavily at the output. (p.807-817)
- [ ] Op-amp or analog signals never drive clock inputs directly. (p.808)
- [ ] Connector-exposed logic inputs have ESD protection (clamps + series R, RC + Schmitt, termination + series R, or opto). (p.804-805)
- [ ] Cables: every off-board fast logic signal terminated (series termination preferred for logic); coax never driven unterminated from logic (15 Vpp overshoot, clamp current, false edges). (p.858-863)
- [ ] Differential links have correct termination (100-120 ohm; both ends for RS-485), CM range verified against ground offsets, isolated transceivers for long industrial runs, short unterminated stubs. (p.865-868)
- [ ] TOSLINK audio receivers not used where dc/slow data is needed (not dc-coupled). (p.854)
- [ ] Capacitive/transformer/GMR digital isolators understood as edge-transfer (not dc-correct at power-up). (p.845)
- [ ] Gate-driver optocoupler CMTI and bootstrap supply adequate; desaturation detection for IGBT shorts. (p.846-847)

### Data conversion
- [ ] Anti-alias filter designed with oversampling guard band; aliasing cannot be removed digitally afterward. (p.900-902)
- [ ] Converter latency included in any control-loop timing. (p.904)
- [ ] Current-output DAC uses its internal R_fb (else +/-25-35% gain error, 100x drift); bipolar via diff-amp offset. (p.885-886)
- [ ] MDAC attenuation at low codes checked at frequency (datasheet BW is for full-scale code). (p.884, 891)
- [ ] Control-loop DACs chosen for DNL < 1 LSB (monotonic); setpoint DACs for INL/gain; no audio converters in dc/control roles. (p.899-900)
- [ ] Fast ADC driven differentially through the datasheet RC network; clock jitter within the SNR requirement. (p.904-907)
- [ ] SAR input driver can charge the sampling capacitor within acquisition time; reference/input pins bypassed per datasheet; driver op-amps sequenced with the ADC supplies (no input overdrive at power-up). (p.909-912)
- [ ] Integrating converters: low-DA integrating capacitor with outer foil to the integrator output; integration time locked to powerline; digital bus quiet during integration endpoint; break-before-make switches in current-steering integrators. (p.915, 920)
- [ ] MCU-internal ADC/DAC not relied on for > ~10-bit performance. (p.880)

## 7. Process / lifecycle guidance

The book is a circuit-design text, not a product-development text; the few lifecycle-type recommendations in this range are:
