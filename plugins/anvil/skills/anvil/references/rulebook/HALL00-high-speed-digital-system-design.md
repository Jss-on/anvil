`CHECK-eps-eff-delay`: inputs er, H, W, T, layer type, len → er_eff (microstrip formula; stripline er_eff = er) → PD = 84.7·sqrt(er_eff) ps/in (= sqrt(er_eff)/c) → TD = PD·len → outputs for timing sheet; sanity: 150 ± 20 ps/in microstrip, 170 ± 20 stripline (FR4). Sources: HALL00-010, -013, -014.

`CHECK-reflection-ringback`: inputs Vs, Rs, Zo (use Z_even worst case), R_load or open, TD, Vih/Vil, Tr → Vi = Vs·Zo/(Zo + Rs); rho_s, rho_l; lattice for >= 3 round trips (second reflection dominates) → V_min_after_first_peak (rising) must stay >= Vih (falling: <= Vil) → margin = V_min − Vih. Sources: HALL00-017..021, -052.

`CHECK-termination-select`: inputs PW (bit time), TD, Rs_buffer, Zo, scheme → if scheme = series: R = Zo − Rs_buffer, require Rs_buffer < 0.5·Zo (resistor dominates) and PW > TD; if parallel: R = Zo, dc power = V^2/R flagged; if AC: R = Zo, C in [Tr/R, 2Tr/R]; pass if Zo tolerance ±15% still gives |rho| <= user limit at both ends. Sources: HALL00-027..031.

`CHECK-crosstalk-next-fext`: inputs L, C, Lm, Cm (per in), X, Tr, V_in, R_victim, Zo, noise budget → NEXT = (V/4)(Cm/C + Lm/L)·min(1, 2·X·sqrt(LC)/Tr); FEXT = |X·V/(2Tr)·sqrt(LC)·(Lm/L − Cm/C)|; multiply each by (1 + (R − Zo)/(R + Zo)) for unmatched ends → pass if max(NEXT, FEXT) <= budget → margin = budget − max. Sources: HALL00-038..040. (Formula body reconstructed; validate against a coupled SPICE run per §4.)

`CHECK-pattern-impedance-slem`: inputs L, C, Lm(k), Cm(k) for nearest neighbors, S, H, Zo_target, Zo_tol → Z_even = sqrt((L + ΣLm)/(C − ΣCm)), Z_odd = sqrt((L − ΣLm)/(C + ΣCm)); TD_even/odd; guard S/H >= 1 → pass if [Z_odd·0.85, Z_even·1.15] within the bus impedance window from sweeps (or within Zo_target ± tol) → margin = window slack. Sources: HALL00-044..051, -153.

`CHECK-diff-termination`: inputs Z_odd, Z_even, network (pi|T), standard resistor set → compute R1..R3, snap to nearest E-series, recompute residual rho_odd, rho_even → pass if |rho| <= 0.1 (user) → margin. Sources: HALL00-054, -055.

`CHECK-skin-onset`: inputs t (m), rho → F_skin = rho/(pi·mu0·t^2) → report; require loss model to include R ∝ sqrt(F) above F_skin when 0.35/Tr > F_skin. Source: HALL00-059.

`CHECK-rac-loss`: inputs rho, W, H (H1, H2 for stripline), t, len, F_knee = 0.35/Tr, roughness flag → delta(F_knee) → R_ac = (rho/delta)(1/W + 1/(6H)) (stripline: parallel of the two); ×1.1–1.5 if roughness flagged and F_knee > 200 MHz → attenuation estimate alpha = Zo/(Zo + R_ac·len) → pass if V_swing·alpha >= V_min_required → margin. Sources: HALL00-060..068.

`CHECK-dielectric-g`: inputs C11, tan_d(F), F → G = 2·pi·F·C11·tan_d → compare R_shunt = 1/(G·len) with R_series; flag when R_shunt < 15·R_series (dielectric no longer negligible). Sources: HALL00-069, -070.

`CHECK-serpentine`: inputs for each serpentine: S, H, Lp, net class → pass if S >= 3H (warn if < 4H) and net not clock/strobe; report Lp ranking. Source: HALL00-074.

`CHECK-bends`: inputs per net: count of 90° bends, w, C11 → C_excess = n·C11·w → flag if n > 0 on nets with w > 10 mil or if C_excess adds > 5% to net capacitance; recommend 45°. Source: HALL00-077.

`CHECK-topology-symmetry`: inputs topology graph, leg lengths, leg loads, Zo_base, Zo_leg → T: pass if legs equal (length within skew budget, identical loads) and (Zo_leg = 2·Zo_base or reflection at Zo_leg/2 accepted); star: identical delays/loads; daisy chain: report stub lengths. Sources: HALL00-078, -150.

`CHECK-via-parasitics`: inputs er, T, D1, D2, h, d, count per net, Tr → C_via, L_via; lumped validity delay = sqrt(L·C) < Tr/10; total added C/L per net. Sources: HALL00-079..081.

`CHECK-stub-length`: inputs TD_stub (from length·PD), Zo_stub, C_load, Tr → TD_eff = TD_stub + Zo_stub·C_load → pass if TD_eff <= Tr/10 (lumped-capacitor regime) → else warn "ledge/push-out ≈ 2·TD_stub" → margin = Tr/10 − TD_eff. Sources: HALL00-094, -095.

`CHECK-edge-degradation-shunt-c`: inputs Zo, C (via/stub/receiver), T_in → T_out = sqrt(T_in^2 + (1.1·Zo·C)^2) → pass if T_out <= T_max (timing sheet) → margin. Source: HALL00-096.

`CHECK-distributed-loading`: inputs L, C per in, N loads, C_L, X → Zo', TD' → feed to CHECK-termination-select and timing. Source: HALL00-097.

`CHECK-connector-pinout`: inputs pin map (S/P/G grid) → ratios P/S, G/S >= 1; every S has an adjacent P or G (per return-current plane); every P adjacent to a G; pass/fail list. Source: HALL00-086.

`CHECK-return-path`: inputs per net: reference plane per segment, plane cuts/antipads crossed, plane-change vias, decoupling caps within r of each plane change → fail on any gap crossing by a high-speed net; fail on plane change without adjacent cap pair; warn if strobe and data on different layers; GTL nets not ground-referenced → warn. Sources: HALL00-099..105, -159.

`CHECK-gap-edge`: inputs L_gap (from solver or user), Zo, T_in → T_out = sqrt(T_in^2 + (2.2·L/(2Zo))^2) → compare with budget. Source: HALL00-101.

`CHECK-local-decoupling`: inputs dV (derated noise budget), dI per I/O, I/O cells per capacitor n, T_slow, T_fast, available C_die per cell, mounted L (package + socket + via + plane + ESL) → F_slow = 0.35/T_slow, F_fast = 0.35/T_fast; C_min = n·dI/(2pi·F_slow·dV); L_max = dV/(2pi·F_fast·n·dI) → pass if C_avail >= C_min and L_mounted <= L_max → margins (ratio). Sources: HALL00-111..113.

## 4. Verification procedures & plots

1. **Impedance vs geometry plot** — x: W/H (log), y: Zo (ohm) for microstrip and stripline at er = 4.0–4.5, with the ±15% fab band around target; annotate formula validity limits (0.1 < W/H < 2 for Fig. 2.6a; 0.25–6 for App. A; T/H < 0.25, T/W < 0.11 for stripline). Good: target within band across worst-case er and copper thickness; cross-check with a 2-D solver (mandatory for final). (§2.3.1, App. A)
2. **Lattice/reflection waveform** — x: time (multiples of TD), y: V at driver and receiver; corners: Zo ±15%, Z_odd/Z_even, Rs min/max, Tr min; pass: receiver never re-enters [Vil, Vih] after first crossing; report settling time vs bit period. Overlay slow-edge case (Tr > 2·TD) to see reflection masking. (§2.4, §3.10.4)
3. **Coupled-line crosstalk waveform** — 3-line SPICE (target center), aggressor step V_in with Tr, victim terminated as designed; x: time, y: victim near-end and far-end voltage; expect NEXT pulse of duration 2·TD starting at t = 0, FEXT pulse ~Tr wide at t = TD; compare peaks to formula estimates; pass: peaks + reflections < noise allocation of the threshold region. Sweep spacing S to produce crosstalk-vs-S (log y) and pick S where the curve flattens (EMI/SI). (§3.4–3.5, §10.4.2)
4. **Pattern-dependent impedance/velocity** — simulate common-mode, differential-mode and single switching on the 3-line model (and the SLEM equivalents); x: time, y: receiver V; report Zo and TD ranges; for microstrip expect both amplitude and arrival-time shifts, for stripline amplitude only. (§3.6, Fig. 3.11)
5. **Loss vs frequency** — x: F (log, 1 MHz–10 GHz), y: R_ac (ohm/in) and alpha (dB/in) with skin-onset marker F_skin and roughness-corrected band (+10–50% above ~200 MHz); second panel: FFT of trapezoid → apply alpha → IFFT and overlay input/output eye or edge; pass: attenuated swing and slowed edge still meet Vih/Vil and timing. (§4.1.3, Fig. 4.10)
6. **Serpentine study** — 5-in straight vs serpentined nets at S = 5, 15 mil and S = 3H, 4H; x: time, y: receiver V; ledge magnitude must not enter the threshold region; report arrival-time delta. (§4.3, Fig. 4.14)
7. **ISI sweep** — patterns 0101…, 0011…, 000111… at the fastest period, ≥ 5 periods each; take flight time at every transition; report max − min; then PRBS with mixed rates/odd-even modes at phase 2; include strobe start-up. (§4.4, §9.4.3–9.4.4)
8. **Package/stub effect** — sweep stub length X and stub impedance on a 3-load bus (Fig. 5.15); y: receiver waveform; pass when no ledge enters [Vil, Vih]; compare push-out with 2·TD_stub. (§5.3.3)
9. **Return-path (gap) study** — TDR/TDT of a line crossing a slot: expect inductive bump on TDR and ledge on TDT whose duration ∝ D and height ∝ 1/gap width; coupled-noise plot to a second line across the same slot. (§6.1.2, Fig. 6.4)
10. **Local PDN sweep** — GTL/CMOS driver with L-C ladder (10 nH, 2 uF, 5 nH, C_die) for ground- and power-referenced lines; sweep C_die (e.g., 5 pF … 1 nF); pass when the receiver ledge disappears and no resonance near the edge spectrum. (§6.1.4, Fig. 6.10)
11. **PDN impedance Bode plot** — x: F (log), y: |Z| between power and ground at the component; overlay bare-plane 1/(wCp), each capacitor group and total; mark F_zero, F_pole, F_A; pass: |Z| <= dV/dI from dc to max(0.35/Tr, 5·F_bus). (§6.2.4, §10.3.1, Figs. 6.16, 10.15–10.16)
12. **SSN simulation** — model of Fig. 6.18 (all I/O sharing the same P/G pins, mutual L included), N−1 aggressors switching, quiet net observed; y: quiet-line and supply noise; pass: within threshold-region allocation; validate in lab (SSN cannot be fully predicted). (§6.3)
13. **Buffer-model validation** — Bergeron plot of the driver I-V with Zo load lines; all intersections in the linear region for the linear model to be acceptable; behavioral model: I-V from −Vdd to 2Vdd, V-T with a point at Vdd/2, capacitance removed then re-added. (§7.2)
14. **Timing spreadsheet** — worst-case table (target vs predicted per term, Tguard included) and statistical table (mean/sigma per term); plot margin vs k; report k at zero margin (require >= 3.09 for HVM). (§9.1)
15. **IMC scatter plots** — 1000-iteration Monte Carlo, uniform inputs; scatter of each metric vs each variable with linear fit and correlation r; identify 8 corners and significance list; gaps in the scatter indicate ringback violations — inspect those waveforms. (§9.4.1, Figs. 9.16–9.20)
16. **Ordered sweep surface** — e.g., flight time vs (motherboard Zo, daughtercard Zo) at fixed corner values; top view contour at the flight-time spec (e.g., 1000 ps) defines the impedance solution space; translate to spacing via SLEM including fab tolerance. (§9.4.2, Figs. 9.21–9.23)
17. **Eye diagram (phase 2)** — overlay strobe on data eye at the receiver; measure setup/hold windows at the noise-margin bounds; ringback margin from eye interior; not for sweeps. (§9.4.4, Fig. 9.24)
18. **EMI pre-compliance plot** — x: F 30 MHz–1 GHz (log), y: dB(uV/m); envelope from 1/(pi·PW), 1/(pi·Tr), c/(2l) corners; overlay Class A/B limit lines (Table F.1, +6 dB for open-box); mark PLL-sensitive band and 30 MHz conducted boundary. (§10.2, App. F)
19. **Decoupling/plane pole-zero plot** — as in item 11 but at board level with n capacitors; show that adding capacitors moves F_pole and F_A upward. (§10.3.1)
20. **Ferrite attenuation plot** — manufacturer Z(F) → A_dB(F) = 20log((Zs + ZL + Zf)/(Zs + ZL)); check saturation current with N turns (derate by N^2). (§10.3.2)
21. **Shielding effectiveness vs frequency** — SE_A + SE_R for the chassis material, minus aperture leakage (slot, mesh, seams; N apertures +20log N); mark slot resonances at X = lambda/2 and waveguide cutoff c/(2X). (§10.5)
22. **Measurement-chain check** — bandwidth RSS (Tr_meas) and sample-rate (4x) verification before any lab timing; TDR: open-ended DUT, flattest region, coupon settling; VNA: calibration verification on the Smith chart, |S11| < −20 dB for attenuation, phase-based delay. (§11)

## 5. Pitfalls, failure modes, review checklist

- A "wire" longer than Tr/10 electrically is a transmission line — model it, don't lump it. (§1.1, §2)
- Field-solver Zo of an isolated coupon is higher than the in-bus value: adjacent quiet traces lower the single-line impedance; design and vendor test coupons must reflect bus geometry. (§3.7, §11.4)
- Fab impedance tolerance ±15% (low-cost boards) plus crosstalk excursions must both fit inside the solution space; source termination is the most sensitive. (§2.4.5, §9.4.2)
- Do not serpentine clocks; parallel-section spacing < 3H couples and creates early-arriving ledges. (§4.3)
- Microstrip buses have pattern-dependent velocity (skew) — stripline/embedded routing removes it. (§3.6.1)
- SLEM with S/H < 1 is inaccurate; final sign-off needs fully coupled (>= 3-line) models. (§3.6.2, §9.4.4)
- Package losses are often ignored; small package traces are lossier than board traces. (§5.3.2)
- Bond wires/lead frames (5–15 nH) low-pass the edge and add inductive noise; non-controlled-impedance packages are unsuitable for high speed. (§5.3.3)
- Long, narrowly spaced package stubs on multidrop buses are the primary performance inhibitor; capacitive stub ends extend the stub delay by Zo·C. (§5.3.3)
- Connector return pins: N drivers sharing one ground pin multiply return-path noise by N; P/G:signal ratio must be >= 1 and pins adjacent. (§5.2)
- Signals over plane gaps/antipads/splits, or changing reference planes without local capacitance, produce ledges, EMI and strong coupling to other nets crossing the same gap. (§6.1)
- Plane reference must stay the same type (VDD or GND) from package trace to board trace; mismatches have caused product failures. (§9.7)
- A ledge on the rising edge at the receiver = decoupling problem; at the driver it is the normal source divider — don't confuse them, nor with stub ledges. (§6.2)
- Local decoupling sized with the fastest edge for C (wrong) fails slower-edge components: use the slowest edge for C_min and the fastest for L_max. (§6.2.1)
- Parallel L-C resonances (die C vs package L; plane C vs capacitor L/n) create high-impedance poles that starve current; adding capacitors can worsen impedance above F_A. (§6.2, §10.3.1)
- Star grounding, routed ground "islands" and inductive plane isolation are harmful in high-speed digital boards; use many chassis-ground points and continuous planes. (§10.3.2)
- Slowing edges to fix EMI or SSN increases timing uncertainty and jitter from core noise coupling — last resort. (§6.3.1, §10.3.2)
- Linear buffer models are only valid when the real buffer is roughly linear where reflections land (Bergeron check); errors may surface late. (§7.2.2)
- Behavioral V-T curves that embed output capacitance mis-model reflections arriving at the driver; strip C and re-add as lumped element. (§7.2.3, §7.3)
- Tco simulated into a load unlike the reference load makes silicon + board timings not add up; use one standard reference load everywhere. (§9.2.2)
- Measuring flight time from Vil at the driver to Vih at the receiver double-counts the transition time. (§9.2.3)
- Skew for conventional source-synchronous designs must be evaluated across the threshold region (noise moves Vref between data and strobe). (§9.2.4)
- Ringback into the threshold region on strobes/clocks causes false triggers and catastrophic failures. (§9.2.5)
- IMC scatter with a gap ⇒ ringback violations; trends only valid for well-behaved systems. (§9.4.1)
- Combining worst cases across parts for on-die data-vs-strobe skew is unrealistic; use within-part variation. (§9.4.1)
- Monte Carlo double-check is not a proof — "shotgun blast in the dark". (§9.4.3)
- Do not "design by simulation" — hand-calculate simple topologies and inspect waveforms behind every sweep point. (§9.7)
- Strobe and its data on different layers see uncorrelated process variation — route on the same layer, same topology. (§8.2, §9.7)
- Open-box motherboards get at most 6 dB credit for the chassis. (§10.1)
- Even harmonics appear whenever duty cycle ≠ 50% — include them in EMI estimates. (§4.1.3, App. C)
- Ferrites placed away from the chassis wall leave a radiating cable stub; multiple turns risk saturation and turn-to-turn capacitance. (§10.3.2)
- Floating heat sinks and clock chips under heat sinks resonate and radiate. (§10.5.3)
- Slot apertures of lambda/2 length have zero shielding; break apertures into smaller ones. (§10.5.2–10.5.3)
- Insufficient scope/probe bandwidth hides edge-rate skew; equivalent-time sampling averages out glitches; sample at 4x the highest frequency. (§11.1)
- TDR on short traces (e.g., 1 in) never settles — impedance readings are wrong; terminate-vs-open changes readings 1–2 ohm; hand-held probes with long ground spanners add inductive spikes. (§11.3–11.4)
- VNA attenuation with |S11| > −20 dB is corrupted by reflections; calibrate at the line impedance. (§11.8.4)
