### 2.15 Four-port T <-> S conversions (Appendix B; ports 1,3 left, 2,4 right; `[a1; a3; b1; b3] = T [b2; b4; a2; a4]`; OCR-reconstructed fraction layout, signs verified against the uncoupled two-port limits)

Let `D_t = t11*t22 - t12*t21` and `D_s = s21*s43 - s23*s41`.

T -> S: `s11 = (t22*t31 - t21*t32)/D_t`; `s21 = t22/D_t`; `s31 = (t22*t41 - t21*t42)/D_t`; `s41 = -t21/D_t`; `s12 = -(t13*t22*t31 - t12*t23*t31 - t13*t21*t32 + t11*t23*t32 + t12*t21*t33 - t11*t22*t33)/D_t`; `s22 = -(t13*t22 - t12*t23)/D_t`; `s32 = -(t13*t22*t41 - t12*t23*t41 - t13*t21*t42 + t11*t23*t42 + t12*t21*t43 - t11*t22*t43)/D_t`; `s42 = (t13*t21 - t11*t23)/D_t`; `s13 = -(t12*t31 - t11*t32)/D_t`; `s23 = -t12/D_t`; `s33 = -(t12*t41 - t11*t42)/D_t`; `s43 = t11/D_t`; `s14 = -(t14*t22*t31 - t12*t24*t31 - t14*t21*t32 + t11*t24*t32 + t12*t21*t34 - t11*t22*t34)/D_t`; `s24 = -(t14*t22 - t12*t24)/D_t`; `s34 = -(t14*t22*t41 - t12*t24*t41 - t14*t21*t42 + t11*t24*t42 + t12*t21*t44 - t11*t22*t44)/D_t`; `s44 = (t14*t21 - t11*t24)/D_t`.

S -> T: `t11 = s43/D_s`; `t21 = -s41/D_s`; `t31 = -(s13*s41 - s11*s43)/D_s`; `t41 = -(s33*s41 - s31*s43)/D_s`; `t12 = -s23/D_s`; `t22 = s21/D_s`; `t32 = (s13*s21 - s11*s23)/D_s`; `t42 = -(s23*s31 - s21*s33)/D_s`; `t13 = (s23*s42 - s22*s43)/D_s`; `t23 = (s22*s41 - s21*s42)/D_s`; `t33 = (s13*s22*s41 - s12*s23*s41 - s13*s21*s42 + s11*s23*s42 + s12*s21*s43 - s11*s22*s43)/D_s`; `t43 = -(s23*s32*s41 - s22*s33*s41 - s23*s31*s42 + s21*s33*s42 + s22*s31*s43 - s21*s32*s43)/D_s`; `t14 = -(s24*s43 - s23*s44)/D_s`; `t24 = (s24*s41 - s21*s44)/D_s`; `t34 = -(s14*s23*s41 - s13*s24*s41 - s14*s21*s43 + s11*s24*s43 + s13*s21*s44 - s11*s23*s44)/D_s`; `t44 = (s24*s33*s41 - s23*s34*s41 - s24*s31*s43 + s21*s34*s43 + s23*s31*s44 - s21*s33*s44)/D_s`.

## 5. Pitfalls, failure modes, review checklist

- [ ] Frequency-invariant eps_r / tan_delta line models are noncausal (energy arrives before l*sqrt(eps_r)/c); acceptable only below ~1–2 Gb/s and a few inches — use tabular causal models above that (p.332, 409, 418).
- [ ] Causality errors of individually "small" component models accumulate when cascaded into a channel — check each component and the full channel (p.409).
- [ ] Hilbert-transform causality tests on band-limited data show truncation artefacts; corroborate with the pulse-response precursor check (p.340, 410).
- [ ] Never accept passivity-corrected S-parameters; nonpassivity means bad calibration or wrong model assumptions (p.408).
- [ ] S21 rising above 0 dB, or non-periodic ripple on S21, indicates a bad VNA measurement (calibration breakdown seen after ~17 GHz in the example) (p.410–411).
- [ ] Z/Y (open/short) measurements are invalid at GHz: a 0.3-pF probe changed Z21 from 31.8 to 24.7 ohm at 1 GHz (p.357–358).
- [ ] VNA bandwidth must exceed 0.35/t_r of the pulse used for pulse-response generation (10 GHz for 35-ps edges, 14 GHz for 25 ps); FFT time step = 1/(2*f_max) — 20-GHz data alone gives only 25-ps resolution; zero padding adds ripple (p.377–381).
- [ ] Always reconstruct negative frequencies as complex conjugates before IFFT, appended after the positive samples (p.376–377).
- [ ] S-parameters are meaningless without their reference impedance; renormalize before comparing (p.399).
- [ ] Mode conversion: for a lossy pair the Scd21 peak is not the 100%-conversion point; 100% conversion is where Sdd21 = 0. Do not "operate above f_180" even though Sdd21 recovers — bits are 540 deg apart (p.405–406).
- [ ] Forward crosstalk reaches 100% at f_180 = 1/(2*(tau_even - tau_odd)) for microstrip pairs (4.41 GHz for the 10-in example) — keep operating band well below (p.370–371).
- [ ] Reference plane treated carelessly: gaps, splits, power islands, antipad fields, socket pins and bond wires in the return path add series inductance (TDR spike), slow edges, create ledges when divergence delay > t_r, and couple lines through the slot (~20% at 1.4 in) (p.422–432).
- [ ] Decoupling caps at a plane split bound the return-path divergence (1-nF caps at the island edges in Example 10-1) (p.427–429).
- [ ] Every signal via needs a nearby return via; differential via pairs need symmetric ground vias or differential energy converts to common mode (p.434).
- [ ] PTH via stubs resonate (12 GHz for a 56.6-mil stub in the example); backdrill/microvias; the L-C tank estimate is only within a few GHz of 3D results (p.436–437).
- [ ] Via stubs radiate into plane cavities (62% of power at resonance in the example) and couple to other vias — only 3D EM captures it (p.437–439).
- [ ] Linear driver models mis-predict launch amplitude: a "50-ohm" CMOS driver looks like 18 ohm on the load line (0.65 V/37 mA vs 1.25 V/25 mA) (p.450–452).
- [ ] Transistor i–v varies 2–3x over process/voltage/temperature; use compensation and simulate corners (p.457).
- [ ] IBIS i–v tables must extend from -VDD to 2*VDD; do not double count C_comp if v–t curves already include it; v–t curves must be time-correlated; record the fixture load (p.455, 486–487).
- [ ] CMOS inverter receiver thresholds vary >10% of swing (>20% with supply); example offset +/-201 mV vs +/-30 mV for a differential pair — budget it (p.460, 573–576).
- [ ] ESD structures add pad capacitance and series resistance; include in receiver models (p.461–462).
- [ ] Open-drain drivers fully re-reflect on rising edges (open circuit at Tx): ringing even with matched far-end termination if any discontinuity exists; terminate both ends or slew-control (p.476–478).
- [ ] Bergeron diagrams: ~5 mV/0.5 mA accuracy, lossless lines, discontinuities only at ends — first-order use only (p.470, 474).
- [ ] Z0 manufacturing tolerance up to +/-20%; analyze extremes (p.472, 606).
- [ ] 6 dB of loss slope at the fundamental closes the eye regardless of swing or frequency (p.516–518).
- [ ] Do not confuse power-dB and voltage-dB gains when specifying equalizers (p.522).
- [ ] Tx pre-emphasis/de-emphasis coefficients must satisfy sum|c_i| = 1 (swing limit < 1.0 V in advanced processes) (p.527–528).
- [ ] Adding taps beyond the simplest configuration that meets spec buys only a few % (2nd postcursor: negligible; precursor +7.5% height) (p.529–530).
- [ ] ZFS removes ISI only at tap sample points and is guaranteed only when the initial eye is open; use MMSE for closed-eye backplanes (p.533–534).
- [ ] Linear equalizers amplify noise along with signal (no SNR improvement); DAC resolution limits tap accuracy (10 bits for 0.001) (p.536).
- [ ] Fixed equalization (e.g. PCIe -3.5 dB up to 15 in) over-/under-equalizes other lengths; adaptive EQ costs power/area (p.536–537, 541–542).
- [ ] DFE cancels only postcursor ISI, propagates decision errors, may not close the first-tap loop at high rates; simulate in time domain (p.540–541).
- [ ] Worst-case timing budgets are physically meaningless with Gaussian RJ; design to a target BER with dual-Dirac budgets (p.555).
- [ ] Q_BER in eq. (13-15) is the half-eye value; Table 13-1 lists the two-sided value (14.069 at 1e-12) — do not double count (p.566–567).
- [ ] DJ_dd (56.2 ps) is smaller than DJ_pp (62 ps); use DJ_dd with Q*sigma, not DJ_pp (p.566–568).
- [ ] Jitter budget: DJ adds linearly, RJ adds RSS; linear-sum TJ (458 ps) is overly pessimistic vs RSS (399.6 ps) for PCIe (p.568–571).
- [ ] Supply noise 5–10% external, ~10% local for single-ended; Vref noise +/-2% ac plus dc offsets (HSTL 0.68–0.90 V); equalizer DAC LSB/2 counts as noise (p.572–577).
- [ ] Noise margin alone misleads: judge by noise immunity (swing/noise) since crosstalk, supply noise and ISI scale with swing (p.582–583).
- [ ] Gaussian noise terms: use 7.4 sigma for 1e-12 exceedance; thermal + shot noise negligible for large-swing single-ended links (p.579–580).
- [ ] PDA assumes linearity — re-check worst patterns with IBIS/transistor models; apply a noise floor to simulator residue; PDA does not capture channel amplification of Tx jitter; form v_diff before PDA (p.599).
- [ ] RSM: only valid inside fitted ranges; check residuals, R^2, R^2_adj, F and t tests before use; 10+ variables -> > 60 terms (p.633–634).
- [ ] Equalizer settings must be valid DAC codes; allocate +/-1 LSB error in the defect-rate analysis (p.624–627).
- [ ] Impedance-control circuits censor, and vendor screening truncates, input distributions — model them correctly in Monte Carlo; screening costs ~$1/board (p.628–632).
- [ ] Hilbert-based internal inductance: handle the 1/(pi*w) singularity (Cauchy principal value) and Fourier-convention consistency; test with a smooth conductor (L_int = R_ac/w) (p.650).
- [ ] Several printed numbers are internally inconsistent — recompute before reusing them: PCIe Table 13-2 receiver TJ (147 printed vs 160 consistent with the 458-ps sum); §13.4.2 Gaussian sigma (0.233 printed vs 0.323 mV computed in Example 13-5); Table 14-9 estimated defect rate (484 ppm printed vs ~118 ppm from eq. 14-35 with the printed mean/sigma); Example 9-5 f_180 (4.41 GHz printed vs ~4.5 GHz); Example 13-1 DJ_dd (56.2 ps in text vs 57.2 ps in Fig. 13-13); AGP 8X MTBE (2.5 years printed vs 1.9 years from 1/(BER x rate x width)) (p.371, 555, 567, 571, 580, 631).
