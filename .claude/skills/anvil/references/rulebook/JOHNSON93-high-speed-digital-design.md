## 3. Mechanizable checks

`CHECK-knee-bandwidth`: inputs Tr_s (10-90%, s), F3dB_path_Hz (interconnect/package/connector/probe/scope bandwidth) → F_knee = 0.5/Tr_s → pass if F3dB_path_Hz >= F_knee → margin = F3dB_path_Hz/F_knee - 1 → rows 001, 002, 084, 119.

`CHECK-lumped-or-distributed`: inputs length_in, Tr_ps, Tp_ps_per_in → l_edge = Tr_ps/Tp_ps_per_in; lumped = length_in < l_edge/6 → if not lumped, net must be terminated (flag) → margin = 1 - length_in/(l_edge/6) → rows 018-021, 222, 311.

`CHECK-lumped-ringing`: inputs L_net_H (e.g., 5.08e-9*X*ln(4H/D) or line L), C_load_F, R_source_ohm, Tr_s, V_step, overshoot_budget_frac → Q = sqrt(L/C)/R_s; overshoot = exp(-pi/sqrt(4Q^2-1)) if Q > 0.5 else 0; F_ring = 1/(2*pi*sqrt(L*C)); excitation = 1 if 0.5/Tr >= F_ring else ~0.5 at equality → pass if overshoot*excitation <= overshoot_budget_frac → margin = budget - overshoot → rows 180-183, 126.

`CHECK-reflection-settling`: inputs Zs, ZL, Z0 (ohm), length_in, Tp_s_per_in, eps (settle tolerance, e.g., 0.05), t_available_s → R1 = (Zs-Z0)/(Zs+Z0), R2 = (ZL-Z0)/(ZL+Z0), T_rt = 2*length*Tp; ringing possible if Tr <= T_rt; t_settle = T_rt*ln(eps)/ln(|R1*R2|) → pass if t_settle <= t_available_s (or Tr > T_rt) → margin = t_available - t_settle → rows 219-223, 228-229.

`CHECK-terminator-array-crosstalk`: inputs K_ohm_s (Table T14 or 5.08e-9*Y/(1+(W/H)^2)), R_term, dV, Tr, budget → V = K*dV/(R*Tr) → pass if V/dV <= budget → rows 341-344.

## 5. Pitfalls, failure modes, review checklist

- [ ] Rise time (not clock rate) sets bandwidth needs: every path flat to F_knee = 0.5/Tr (p.2, p.61).
- [ ] Use er = 4.5 (HF) for FR-4 delay, not the 1 MHz/LF 4.7 value; outer traces are faster than inner (p.6).
- [ ] Nets longer than l/6 = Tr/(6*Tp) are distributed and need termination; short nets into heavy C can still ring (Q) (p.7, p.134).
- [ ] Terminator ground trace: 9 nH (1 in trace) = 9.4 ohm at 3 ns — a bank of terminators sharing it fails (p.21).
- [ ] Do not debug-short signals with pliers (10-20 nH, >= 30 ohm at 1 ns); use a knife blade or copper foil (p.22, p.112).
- [ ] Sum crosstalk from all neighbors: 2% x 5 sources = 500 mV in TTL (p.26, p.32).
- [ ] Mutual inductance usually dominates capacitive coupling at 50 ohm levels (~8:1) (p.36).
- [ ] Budget power from active + load terms, not typical Icc (p.39, p.59).
- [ ] Bias/terminating resistors sized for stuck-state worst case (1/8 W overheats at 0.25 W) (p.59, p.239).
- [ ] Do not load a CMOS bus to its DC fan-out: 20 loads x 10 pF + trace turned a 9 ns part into 53 ns (p.49-51).
- [ ] Prefer the slowest logic family/edge that meets timing (p.60).
- [ ] Ground bounce x N outputs can double-clock flip-flops (DIP FCT latches); prefer SMT, separate output/input grounds, spread ground pins (p.68-74).
- [ ] Separate ground pins must each have their own direct path to the plane (p.74).
- [ ] High-impedance static inputs next to clock pins need a capacitor to ground (crosstalk = C_M/C) (p.75-76).
- [ ] Check theta_CA air-speed assumptions (400 ft/min is a lot of air); failure rate doubles per +10 C (p.77-81).
- [ ] Probe with collar/knife-blade ground, not a 3 in ground clip (200 nH -> ringing, 2.8-4.8 ns rise) (p.86-92).
- [ ] 10 pF probe = 100 ohm at 3 ns; fails below 5 ns rise on typical nodes (p.96-98).
- [ ] Shield-current pickup: test with foil-shorted tip on logic ground; never lift scope safety ground (p.104-106).
- [ ] Trigger eye/jitter measurements on the source clock, not on the data (p.108-110).
- [ ] Go/no-go tests must keep running after errors to measure margins (p.113).
- [ ] Every asynchronous input: >= 2 synchronizer flip-flops; compute MTBF (p.125-131).
- [ ] Do not bundle wire-wrap wires; 4 in of neighbor gave 12% crosstalk (p.139).
- [ ] Check line loss at F_knee (0.2 dB on-card) including skin-effect R before choosing terminations (p.149, p.160).
- [ ] Unterminated low-Z-driven lines overshoot ~100% and stress input clamp diodes (p.168).
- [ ] Do not assume a line input "looks capacitive" — only with high source impedance (p.169).
- [ ] Heavy/evenly loaded buses (SIMM arrays) collapse Z0 (8.4 ohm) and add ns of skew — split them (p.174).
- [ ] Right-angle bends only matter below ~100 ps edges with wide traces; 45 deg is fine (p.176).
- [ ] FR-4 delay drifts ~10% over 0-70 C — include in delay-line/timing budgets (p.177, p.354).
- [ ] Simple impedance formulas fail for w > 7h and thin dielectrics; use App. C or a field solver (p.179).
- [ ] Don't over-specify impedance tolerance; plan a two-pass build with microsections for critical designs (p.180-182).
- [ ] Always state the dielectric test frequency (typ. 1 MHz) and use er at the knee (p.185).
- [ ] No traces inside plane slots; keep plane webbing through connector pin fields (p.194-195, p.312).
- [ ] Avoid ground-fingers layouts; two-layer boards use a power/ground grid with a bypass cap at every intersection (p.197-201).
- [ ] Guard traces add little over a solid plane; don't rely on them as return paths (p.201-204, p.262).
- [ ] Series-terminate drivers to kill reverse crosstalk that otherwise reflects to the far end (p.208, p.211).
- [ ] Plan power/ground layers first; symmetric plane pairs prevent warp (p.212).
- [ ] Any cable tied to logic ground leaving the cabinet fails FCC — filter to chassis ground, 360-degree shields, CM chokes (p.212, p.314-316).
- [ ] Trace heating <= 10 C rise (0.010 in x 1 oz ~ 0.75 A) (p.214).
- [ ] Don't plan to fill more than half the inter-pin channels (p.216).
- [ ] Classic stacks are inadequate for FCC/VDE/TEMPEST without shielded card cages (p.217).
- [ ] Account for traces sinking into prepreg when setting dielectric heights (p.219).
- [ ] Isolate routing layers with ground (not power) planes and stitch them with many ground vias (p.221).
- [ ] Most TTL/CMOS cannot source end-terminator current (5 V/65 ohm = 76 mA); check split-termination feasibility (p.226-228).
- [ ] Never daisy-chain receivers on source-terminated lines; end terminator goes beyond the last receiver with no stub (p.230, p.234).
- [ ] Bifurcated (T) lines cannot be terminated unless each branch is 2*Z0 (p.228).
- [ ] Mid-network shunt terminations just lower an already-low impedance (p.236).
- [ ] Terminator inductance: 1 nH at 1 ns = 3.14 ohm; parallel resistors to cut it (p.241-242).
- [ ] Common-ground SIP terminator packs couple ~100x more than separate-ground packs (p.247-248).
- [ ] Via aspect ratio <= 3-6; pads ~2x finished hole for small holes; teardrops not acceptable as annular-ring substitute in hi-rel (p.250-254).
- [ ] Subtract line-width tolerance from air gap; wave solder bridges more than reflow (p.255).
- [ ] Bypass-capacitor vias double the mounting inductance — fat short traces, caps on the plane side (p.260, p.288).
- [ ] A signal via changing reference planes needs an adjacent ground via (p.261-262).
- [ ] Bypass capacitor arrays must be within l/12 of the load; halving Tr makes them 8x less effective (p.260).
- [ ] Remote sense fixes IR drop, not inductive transients (p.269).
- [ ] Fatter round wires barely reduce distribution inductance; use flat plates or differential signaling (p.270).
- [ ] Get ESR in writing; grab-bag "digital bypass" caps can have 1.1 ohm ESR or 10 nH (p.282, p.285).
- [ ] Aluminum electrolytics useless for bypass below 0 C (ESR 14x); Z5U not below 10 C and loses 2/3 over life (p.290-292).
- [ ] Soldering resets ceramic capacitor aging clocks (p.291-292).
- [ ] Don't order the largest capacitance offered in a package size (delays/cost) (p.292).
- [ ] Hot-plug cards: staged pins (ground, soft-start power, power, signals) and duplicate long pins at both ends (p.280-281, p.321).
- [ ] Connector ground pins spread across the connector, not lumped at the ends (p.300).
- [ ] Remote return paths (second connector, I/O cable on daughter-card edge) radiate more than the main connector loop (p.303-305).
- [ ] Multidrop: measure disabled-driver capacitance (up to 80 pF) (p.307-308).
- [ ] Shield drain-wire pigtails radiate; clamp shields into metal shells (p.315).
- [ ] Differential pairs: equal lengths (0.3 in mismatch at 500 ps = 10.8% imbalance) (p.320).
- [ ] IDC connectors are single-use (p.336).
- [ ] Stacked ribbon cables crosstalk more than wires within one cable — use spacers (p.335).
- [ ] Twisted-pair pin assignment: twist each signal with its ground, not with another signal (p.333).
- [ ] Clock skew costs as much as logic delay; keep ~1 gate delay (e.g., 15%) of timing margin (p.342-346).
- [ ] Driving several source-terminated lines from one driver needs equal lengths and loads, R_s = Z0 - N*R_drive (p.351).
- [ ] Gate delays vary 300% — don't use them as precise clock delays (p.354-355).
- [ ] Shorting-jumper inductance matters above 100 MHz — use solder-blob jumpers (p.357).
- [ ] Use inverting clock repeater chains to preserve duty cycle (p.361).
- [ ] Specify oscillator jitter, duty cycle, 10-90% rise time, max load and reflow profile in writing (p.373-376).
- [ ] Filter the ground lead (not +5 V) of positive-ECL oscillators (p.383).
