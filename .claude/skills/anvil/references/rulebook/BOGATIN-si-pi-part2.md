## 3. Mechanizable checks

Inputs are per-net / per-rail table columns; lengths in inches or mils as noted; v defaults to 6 in/ns (FR4) unless a stackup Dk is given (v = 11.8/sqrt(Dk) in/ns).

- `CHECK-xt-budget`: inputs V_swing (V), budget_frac (default 0.05) → XT_allow = budget_frac × V_swing (V). Pass: predicted victim noise ≤ XT_allow. Margin = XT_allow − noise. Rows 2010, 2207.
- `CHECK-next-spacing`: inputs layer ∈ {microstrip, stripline}, w, s (mil), Z0 → NEXT% from table 2.3 (interpolate on s/w; s/w ≥ 3 → ≤ 1%). Pass: 2.1 × NEXT ≤ budget (default 5%), i.e. adjacent-pair NEXT ≤ ≈2%. Margin = budget − 2.1 × NEXT. Rows 2007–2011, 2183.
- `CHECK-fext-microstrip`: inputs w, s, Len (in), RT (ns), v → TD = Len/v; k = {4%, 2%, 1.5%} at s/w = {1, 2, 3}; FEXT per aggressor = min(k × TD/RT, 50%) (saturates at the 0.5·V1 differential component); × 2 for a victim with an aggressor on each side. Pass: FEXT ≤ budget; flag microstrip buses with s = w, RT ≤ 1 ns and Len > 6 in (FEXT > 8%). Rows 2004, 2029, 2051, 2184.
- `CHECK-next-saturation`: inputs Len, RT, v → Len_sat = 0.5 × RT × v. Report whether shortening the coupled length can help (only if Len < Len_sat). Rows 2029, 2207.
- `CHECK-guard-trace`: inputs guard_present, guard_end_termination ∈ {open, Z0, short}, via_pitch (in), RT, v → require termination ≠ open; require via_pitch ≤ RT × v / 3 (microstrip). Margin = RT·v/3 − pitch. Rows 2016, 2017.
- `CHECK-switching-noise-Lm`: inputs Lm (nH) per aggressor pair, N_aggressors, RT (ns), Z0 (Ohm), budget_frac (default 0.05) → Lm_max = budget_frac × Z0 × RT / N (nH) [= 2.5 × RT/N at 5%, 50 Ohm]. Pass: Lm ≤ Lm_max. Also f_clk_max = 250 MHz/(N × Lm). Rows 2024–2026.
- `CHECK-diff-skew`: inputs L_p, L_n (in), BR (Gbps) or UI (ns), v → ΔL = abs(L_p − L_n); ΔL_max = 0.2 × UI × v. Pass: ΔL ≤ ΔL_max; margin = ΔL_max − ΔL. Row 2063.
- `CHECK-diff-symmetry`: inputs per-line width, layer, via count, test-pad count, stub length, neck-down count → all equal between p and n. Pass: no differences. Rows 2034, 2102.
- `CHECK-diff-coupling-regime`: inputs w, s → if s < 3w flag "coupled: Zdiff must come from a 2D field solver; Zdiff ≈ 0.88–0.90 × 2·Z0 at s = w"; if s ≥ 3w Zdiff ≈ 2·Z0. Rows 2036–2040.
- `CHECK-diff-return-plane`: inputs w, s, h (trace-to-nearest-plane) → span = 2w + s; if h ≥ span flag "plane irrelevant to Zdiff (coplanar regime)"; if h ≥ 2·span flag "trace-to-trace coupling dominates". Row 2042.
- `CHECK-common-termination`: inputs Zodd, Zeven, scheme ∈ {single, pi, tee, vtt} → compute resistor values (§2.2 formulas); for `vtt` compute ρ_comm = (Zcomm − Z0/2)/(Zcomm + Z0/2); flag DC load ≈ Zeven per line for pi/tee. Rows 2055–2061, 2208.
- `CHECK-cable-common-current`: inputs Vcomm (V, from skew/asymmetry sim or SCD21 × Vdiff), Zcomm_cable (Ohm, default 300), cable_len (m), f (Hz), R (m, default 3) → Icomm = Vcomm/Zcomm; E = 4π·1e-7·f·Len·Icomm/R. Pass: Icomm ≤ 3 µA at 100 MHz for 1 m and E ≤ 150 µV/m at 100 MHz (other bands need the FCC table). Rows 2066–2069, 2104.
- `CHECK-scd21-cable-channel`: inputs SCD21_peak (dB) for any channel that exits on unshielded cable → pass if ≤ −40 dB (≈1%); warn between −40 and −35 dB. Row 2104 (target quantified from the ≈1% statement — low confidence, keep as a warning).
- `CHECK-via-stub`: inputs stackup layer depths, signal via entry/exit layers, BR (Gbps) → Len_stub = distance from exit layer to the far end of the barrel; Len_max = 300/BR mil; f_res = 1.5/Len_stub(in) GHz. Pass: Len_stub ≤ Len_max (else backdrill/blind/microvia). Margin = Len_max − Len_stub. Rows 2100, 2101.
- `CHECK-channel-loss-budget`: inputs Len (in), BR (Gbps), loss_slope (dB/in/GHz; FR4 dielectric-only −0.1, total −0.2, or from materials: 2.3·Df·sqrt(Dk) + sqrt(f)/(w·f)) → IL_nyq = slope × Len × BR/2. Pass: IL_nyq ≥ −10 dB unequalized (else require equalization). Margin = IL_nyq + 10 dB. Rows 2099, 2205, 2206.
- `CHECK-return-loss-impact`: inputs S11(f) → flag any band where S11 > −10 dB (IL impact ≥ 0.5 dB) and warn above −13 dB. Rows 2084, 2209.
- `CHECK-sparam-sanity`: inputs S-matrix file → verify S21 = S12 (reciprocity) within tolerance; S11_dB(f_min) ≤ −20 dB and S21_dB(f_min) ≥ −0.5 dB; passivity abs(Sij) ≤ 1; port impedance header = 50 Ohm unless justified; ripple spacing Δf → TD = 1/(2Δf) matches the expected length. Rows 2079, 2080, 2094, 2095, 2210.
- `CHECK-interposer-transparency`: inputs Len (in), f_max (GHz), Z0 → if abs(Z0 − 50) > 5 Ohm require Len ≤ 0.3/f_max. Row 2096.
- `CHECK-cavity-resonance`: inputs cavity Len_x, Len_y (in), Dk, clock harmonics / signal BW → f_res,n = n·11.8/(2·Len·sqrt(Dk)); flag any f_res within ±10% of a clock harmonic, or below the signal bandwidth for signals whose vias cross the cavity. Rows 2091–2093, 2165.
- `CHECK-pdn-target-z`: inputs per rail Vdd, ripple_frac, I_transient (A) or I_max or P_max → Z_target = Vdd·ripple/I_transient; if only I_max: I_transient = 0.5·I_max; if only P_max: Z_target = 2·Vdd²·ripple/P_max. Output Z_target (Ohm), flat DC–F_max. Rows 2110–2112.
- `CHECK-pdn-io-rail`: inputs n_SSO, Z0, ripple → Z_target = ripple × Z0/n. Row 2112.
- `CHECK-pdn-bulk-c`: inputs Z_target → C_bulk_min = 159 µF·Ohm/Z_target. Pass: Σ bulk C ≥ C_bulk_min. Row 2118.
- `CHECK-pdn-lf-peak`: inputs bulk ESL_bulk (nH; electrolytic default 15, tantalum 5), MLCC bank C_total → PRF_lf = 159/sqrt(ESL_bulk × C_MLCC_total); require an added capacitor with ESL < ESL_bulk and C > 1/((2π·PRF_lf)²·ESL_add) (≈5 µF for 1 MHz/5 nH). Rows 2144, 2146.
- `CHECK-pdn-package-fmax`: inputs L_pkg (nH; from pairs: 20 nH/in × lead length / N_pairs, or CSP ≈1–2 nH/pair, BGA-plane < 1 nH/pair), Z_target → F_max_board = Z_target/(2π·L_pkg); clamp to the 100 MHz default. Output F_max used by the other PDN checks. Rows 2122–2124, 2211.
- `CHECK-decap-esl-estimate`: inputs per capacitor: N_sq_trace (trace length/width each side, + 2 body squares for 0603/0402, 0.5 for reverse-aspect), depth_to_cavity (mil), via_len (mil), h_cavity (mil), B (mil, distance to package vias), D (mil) → ESL ≈ 32·depth·N_sq + 21·via_len + 21·h·ln(B/D) (pH). Pass: ESL ≤ 2 nH (target), warn > 3 nH. Rows 2131–2137, 2212.

- `CHECK-plane-prf`: inputs A_plane (in²), h (mil), Dk, n, ESL → C_planes = 0.225·Dk·A/h nF; PRF = 159/sqrt((ESL/n)·C_planes). Pass: PRF ≥ 3·F_max (values irrelevant); else flag "sculpt values (FDTIM)". Row 2153.
- `CHECK-value-independence`: inputs Z_target, A_plane (h = 4 mil, F_max 0.1 GHz) → pass if Z_target × A ≤ 0.7 Ohm·in² (anchors 0.1 Ohm / 7 in², 0.3 Ohm / 2 in²). Row 2154.
- `CHECK-parallel-peaks`: inputs sorted capacitor list (C_i, ESL_i, ESR_i, n_i) → for each adjacent pair with SRF ratio > 10: PRF = 159/sqrt(ESL_big·C_small), Z_peak ≈ (ESL_big/C_small)/(ESR_big + ESR_small) (per-bank equivalents). - `CHECK-spreading-limit`: inputs Z_target, F_max, h, b (in), a (in), via depth, N_pairs → L_max = Z_target/(2π·F_max) nH; L_series = 32·h·ln(b/a)/(2π) + 21·depth/N_pairs (pH). Pass: L_series ≤ L_max; if Z_target < 0.05 Ohm require 3D-solver confirmation. Rows 2167, 2168.
- `CHECK-decap-location`: inputs L_mount, L_spread (from h and B) → location matters if L_spread ≥ 0.5 × L_mount; require a 3D solver if L_mount < 0.25 nH. Row 2166.
- `CHECK-on-die-c`: inputs die area (cm²), node → C_die ≈ 260 nF/cm² × (65 nm/node) × (utilization/0.10); Z_die(f) = 1/(2π f C_die); report the frequency above which Z_die ≤ Z_target. Rows 2120, 2121.
- `CHECK-cost-of-nh`: inputs Z_target, F_max, volume → $/nH = 0.01 × 2π × F_max/Z_target; report savings of any ESL reduction and the thin-laminate break-even (Z_target < 0.1/A(in²)). Rows 2151, 2152, 2162.
- `CHECK-dc-resistance`: inputs w (mil), Len (in), copper weight → R = R_sq(weight) × Len/(w/1000); flag R > 1 Ohm in signal paths; report IR drop I × R for power traces. Row 2194.
- `CHECK-ideal-r-bandwidth`: inputs R, L_mount (axial ≈10 nH, SMT ≈2 nH) → f_limit = 0.1·R/(2π·L); flag terminators whose f_limit < signal bandwidth (0.35/RT). Rows 2175, 2190.
- `CHECK-rise-time-defaults`: inputs f_clock or BR → RT ≈ 0.1/f_clock (serial: 0.5 UI); BW ≈ 0.35/RT or 5 × f_clock; measurement BW ≥ 2 × BW. Rows 2187, 2188.

## 4. Verification procedures & plots

1. **PDN impedance profile** — AC sweep (SPICE impedance analyzer: 1-A AC source, 1-TOhm shunt) of VRM (V + R + L) + bulk RLC + MLCC RLC banks (mounted ESL, vendor ESR) + plane C (+ package L and on-die C for the chip view). x: 10 Hz–1 GHz log; y: magnitude of Z, log (Ohm). Good = every peak below the flat Z_target line up to F_max; dips irrelevant. Overlay Z_target, mark PRFs, the bulk/MLCC peak (≈1 MHz class) and the MLCC/plane peak; run corner cases ESL × 1.5 (2 → 3 nH breaks the FDTIM example) and plane-area variants. §13.8, §13.18, §13.22.
2. **Chip-view profile** — same sweep seen from the die pads through L_pkg with C_die and R_die; look for the parallel peak ("Bandini Mountain", ≈80 MHz in the example); pass if peak ≤ Z_target; knobs: on-package IDCs, on-die R (1/3/10 mOhm), flat board profile. §13.26, §13.27.
3. **Capacitor characterization** — measured or modelled impedance magnitude of a single mounted capacitor (10 kHz–1 GHz) with RLC fit; report C, ESR (minimum), ESL (from slope above SRF). Good: ESL ≤ 2 nH conventional, ≤ 0.5 nH IDC; peaks near 200–300 MHz are board parallel resonances, not the part. §13.12, §13.23.
4. **Rail noise time-domain** — square-wave or PRBS current draw (1 A p-p class) into the PDN model; y: V(t) on the pads vs ±ripple lines; sweep the modulation frequency across the impedance peaks (a slight shift can flip pass/fail). §13.4.
5. **Cross-talk time-domain** — coupled distributed model (2D-solver C/L matrices) with actual drivers/terminations; victim near- and far-end voltage vs time for 1, 2, 4, all aggressors switching; report peak as % of swing; conditions: coupled length ≥ saturation length, fastest RT. Good ≤ 5% (or budget). §10.14.
6. **NEXT vs separation** — 2D solver kb vs s/w (log y, down to the numerical floor ≈1e-9); with/without guard; stripline vs microstrip. §10.15, Fig. 10-46.
7. **Differential impedance sweep** — 2D solver Zdiff, Zodd, Zeven, Zcomm vs spacing (and vs solder-mask thickness, vs plane distance); confirm Zdiff within ±10% of target including solder mask; v_odd/v_even for microstrip. §11.4–11.11.
8. **DTDR** — differential and common step (±200 mV) into the pair; read Zodd and Zeven profiles; verify termination match. §11.13.
9. **Skew / asymmetry** — transient sim of the pair with driver skew 0.2/0.5/1/2 × RT and with a 1-pF single-line load: plot Vdiff and Vcomm at the receiver; target: Vcomm small enough for the cable EMI check. §11.15.
10. **S-parameter set** — S11, S21 magnitude (dB vs log f), phase(S21) (sawtooth; slope → TD), polar S21 (inward spiral); 4-port: S31 (NEXT), S41 (FEXT); mixed-mode SDD11, SDD21, SCD21 (mode conversion ≤ −40 dB target for cable channels), SCC21. Check LF limits, reciprocity, ripple period, narrow dips (resonators), stub dips (1.5/Len_stub GHz). §12.5–12.16.
11. **Eye diagram emulation** — impulse response from SDD21 convolved with PRBS at the target bit rate(s) and RT; report vertical opening, horizontal opening = UI − DJ, crossover width; sweep bit rate for the channel limit. §12.17.
12. **Cavity resonance / return-loss absorption** — one-port S11 of package or board leads open at the far end; dips above ≈1 GHz (packages) or ≈300 MHz (10-in boards) mark cavity modes; compare with f_res = n·11.8/(2·Len·sqrt(Dk)). §12.10.
13. **Location sensitivity** — 3D PI solver: bank impedance with capacitors near vs far from the package for the actual cavity thickness (30-mil vs 4-mil example); if the two curves differ, location matters. §13.24.
14. **Radiated-emissions estimate** — Icomm from Vcomm/Zcomm and E at 3 m vs the FCC Class B curve (150 µV/m at 100 MHz); pre-compliance scan with and without the common-mode choke (expect ≥ 40 dB improvement). §11.16.

## 5. Pitfalls, failure modes, review checklist

- Microstrip bus with s = w and coupled length > 6 in at 1-ns edges → FEXT > 8%; route in stripline or add solder mask/laminate. (§10.13)
- Floating (open-ended) guard trace increases cross talk; short both ends, add vias every RT·v/3. (§10.15)
- Guard traces in microstrip buy little; spacing to 3w already gives < 2%. (§10.15)
- Believing lower Dk alone reduces cross talk — it only helps via thinner dielectric at constant Z0. (§10.16)
- Data-dependent delay in tightly coupled microstrip (opposite vs same switching) — a timing, not just noise, effect. (§10.17)
- Shared return pins / long leads: 1 nH of loop mutual inductance caps leaded packages near 50 MHz with five aggressors. (§10.18)
- Calling LVDS "differential" and forgetting the 1.25-V common component; any asymmetry converts differential to common. (§11.1, §11.15)
- Test pad, neck-down or via on one line only (1 pF at 100 ps is visible). (§11.2, §11.15)
- Using "differential-mode impedance" — confuses Zodd (one line) with Zdiff (pair). (§11.7)
- Signing off Zdiff with the AN-905 approximation (1–10% error) instead of a verified 2D solver; ignoring solder mask (up to 10% Zdiff error). (§11.5, §11.9)
- Assuming the other line carries the return current on a board — untrue unless the plane is farther than the pair span; true in connectors, leaded packages, twisted pair. (§11.6)
- Terminating only the differential signal and then wondering why the common signal rings; pi/tee DC load ≈ Zeven per line may overload drivers. (§11.14)
- Two 50-Ohm resistors to ground on a coupled pair: the differential signal sees 4·Zcomm ≠ Zdiff. (§11.14)
- Intra-pair length mismatch > 0.2·UI·v (240 mil at 5 Gbps in FR4). (§11.15)
- Unshielded external twisted pair without a common-mode choke: 3 µA at 100 MHz fails Class B; ≈1 mV of converted common signal at 300 Ohm suffices. (§11.16, §12.15)
- Shield pigtail / high-inductance shield bond → common return leaves the coax geometry and radiates. (§11.16, App. D 1.10)
- Crossing a plane gap with single-ended signals (a 1-in gap destroys a 100-ps edge); use tightly coupled pairs. (§11.18)
- Choosing tight coupling above 10 Gbps where loss dominates (≈30% more resistive loss). (§11.19)
- Wrong S-parameter port assignment silently corrupts the mixed-mode conversion. (§12.3, §12.16)
- Sign confusion between historical "return/insertion loss" (positive) and S11/S21 (negative dB). (§12.5)
- Reading TD from the S21 magnitude or expecting a positive S21 phase; use the sawtooth phase slope. (§12.8)
- Attributing an S21 drop to loss when it is coupling (check S41) or a stub (check S11). (§12.10, App. D 12.24)
- Signal vias transitioning between different reference planes excite cavity resonances (GHz in 1-in packages). (§12.10)
- Via stubs longer than 300/BR mil (60 mil at 5 Gbps) put a quarter-wave notch inside the signal band. (§12.14)
- Non-50-Ohm interposer/connector longer than 0.3/f_max inches. (§12.11)
- Copying another product's decoupling — the PDN is an ecosystem; every design is custom. (§13.5)
- Target impedance from I_max instead of transient current (over-design) or missing a current-spectrum peak on an impedance peak (failure); a slight change in current modulation frequency can flip pass/fail. (§13.4)
- Assuming a "heftier" 0.1%-regulation VRM fixes rail noise; VRM regulation ends at ≈1 kHz. (§13.2, §13.7)
- Using vendor "intrinsic" ESL or the capacitance value as the design variable; count and mounted ESL matter, not µF. (§13.13, §13.27)
- Long narrow capacitor fan-out traces (6 nH) vs short wide with the cavity near the surface (1.8 nH → 0.5 nH). (§13.15)
- Three same-value capacitors "per pin" without a SPICE check — floors at ≈0.6 Ohm at 100 MHz with 3-nH parts, ≈10 Ohm peak with planes. (§13.18)
- Ignoring the bulk/MLCC parallel peak near 1 MHz (15-nH electrolytic ESL). (§13.18)
- Plane area too large for the target (Z_target × A > ≈0.7 Ohm·in² at 4 mil) while using identical capacitor values. (§13.21)
- Signals routed under split planes. (§13.21)
- An ESL change from 2 nH to 3 nH invalidates a tuned FDTIM set. (§13.22)
- Clustered capacitors or clustered P/G pins in the package core when spreading inductance limits (< 0.05 Ohm targets); 16 pH total budget at 0.01 Ohm/100 MHz. (§13.25)
- 63 × 1-µF capacitors give ≈0.2 mOhm of ESR — no damping of the chip-side peak; on-die R and on-package IDCs are the knobs. (§13.26)
- Axial-lead terminators below 1-ns edges (≈10 nH); SMT terminator loop inductance below 150 ps. (App. A #14–15)
- Antipads overlapping in via fields (no web left in the plane). (App. A #54)
- No-connect pins left floating instead of tied to return. (App. A #52)
- Traces closer than 5 line widths to the board edge. (App. A #81)
- Enclosure apertures comparable to a wavelength; fewer large holes are worse than many small ones. (App. A #101)
- Skipping Rule #9 (anticipate the result before measuring/simulating) and consistency tests. (App. D 1.17)
