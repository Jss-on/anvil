## 3. Mechanizable checks

- `CHECK-annular-ring-registration`: inputs pad_dia (mil), hole_dia (mil), laminate_movement (ppm; default 500 actual / 300 spec / 200 stable), panel_span (in) → required_ring = movement × span (mil); actual_ring = (pad − hole)/2 → pass if actual_ring ≥ required_ring; margin = actual − required (mil). Source: COOMBS-1010, 1037.
- `CHECK-signal-layer-count`: inputs total_wiring_length (in), board_area (in²), W_plane (in/in²; 40–60 conventional, 100–140 padless, 200–250 @ 2 mil), layout_efficiency (0.5 default) → N_sig = ceil(L / (W_plane × ε × A)) → pass if stack-up provides ≥ N_sig signal layers; margin = provided − N_sig. Source: COOMBS-1012, 1013, 1182.
- `CHECK-density-balance`: inputs W_d (in/in²) from EIC/DDI or Toshiba map, W_c from stack-up → ratio = W_d/W_c → pass if 0.5 ≤ ratio < 1.0 (ratio ≥ 1 unroutable; ratio < 0.5 flag "sandbag: +15–50 % cost"). Source: COOMBS-1181.
- `CHECK-DDI`: inputs total_leads, board_area → EIC = leads/14; DDI = 13.6 × (EIC/area)^1.53 → look up tracks-per-channel and layer count on the fabricator's calibrated DDI chart (Fig. 16.13 absent; requires calibration table input). Source: COOMBS-1184.
- `CHECK-FPY-complexity`: inputs CI (fabricator formula), A, B → FPY = 100·exp[−(log10 CI/A)^B] → pass if FPY ≥ target (e.g. 90 %); margin = FPY − target. Source: COOMBS-1185 (medium conf).
- `CHECK-price-index`: inputs complexity_points, FPY → PI = points/FPY → map PI 150 → −70 %, 1000 → +275 % (interpolate on fabricator curve) → pass if predicted price ≤ budget. Source: COOMBS-1186.
- `CHECK-cost-lock-in-gate`: at first-stage review require DFM sign-off (60 % of cost fixed at 35 % of effort). Source: COOMBS-1007, 1178 (process gate, boolean).
- `CHECK-panel-utilization`: inputs board outline bbox, panel size list, spacing 0.100 in, border 1.0 in → boards_per_panel via nesting → utilization = N × A_board / A_panel → pass if ≥ site target; report alternatives. Source: COOMBS-1051, 1052, 1187.
- `CHECK-total-z-expansion`: inputs Tg, α1, α2 (ppm/°C), T_peak, T0 = 25 °C → Δz% = [α1 × (Tg − T0) + α2 × (T_peak − Tg)] × 1e-4 → compare materials; pass if ≤ reference material (e.g. 3.4–3.5 % for 260 °C class). Source: COOMBS-1074, 1144 (medium).
- `CHECK-Td-margin`: inputs Td_onset or Td_1% (°C), T_peak (°C), N_cycles → pass if T_peak + 0 < Td_1% and (for N_cycles ≥ 5 at 260 °C) material class ∈ {mid-Tg high-Td, high-Tg high-Td reduced-CTE, non-dicy/non-phenolic}; fail if dicy high-Tg FR-4 at T_peak ≥ 240 °C. Source: COOMBS-1072, 1110, 1148, 1149.
- `CHECK-lead-free-material-class`: inputs board thickness (mm), min hole pitch (mm), inner Cu (oz), T_peak, cycles, curing chemistry → rules: dicy high-Tg → FAIL for lead-free; dicy 140 °C → only thin/low-reliability at intermediate peaks; thickness ≥ 2.5 mm AND pitch ≤ 0.8 mm → require high-Td + reduced-CTE with IST evidence. Source: COOMBS-1148, 1156.
- `CHECK-Tg-rescan`: inputs Tg1, Tg2 → pass if |Tg2 − Tg1| ≤ 5 °C (dicy) / ≤ 7 °C (Ch. 15 general); flag Tg2 << Tg1 as decomposition, Tg1 << Tg2 as undercure. Source: COOMBS-1070, 1164.
- `CHECK-peel-strength`: inputs peel_asreceived, peel_thermal, peel_chem, peel_125C (N/mm) → pass if ≥ 1.0 / 0.8 / 0.55 / 0.7 respectively (unless documented VLP exception). Source: COOMBS-1113.
- `CHECK-ply-count`: inputs dielectric thickness (in), layer function (plane-plane with ΔV, mil/aero flag) → t > 0.0080 → require ≥ 2 plies; t ≤ 0.0050 → 1 ply OK; plane-plane ΔV or mil/aero → require 2 plies; flag asymmetric constructions (e.g. 2313/2116). Source: COOMBS-1123, 1124.
- `CHECK-prepreg-fill`: inputs prepreg thickness, glass thickness, inner-layer Cu thickness, copper coverage % → V_resin = (t_prepreg − t_glass) per unit area; V_needed = t_Cu × (1 − coverage) + buffer → pass if V_resin ≥ V_needed (glass stop prevented); flag plane layers with large copper-free areas (add copper fill). Source: COOMBS-1125, 1126.
- `CHECK-adjacent-layer-CTE`: inputs per-dielectric CTE_xy and RC → flag adjacent pairs with large ΔRC or dissimilar resin systems for hybrid-stack review. Source: COOMBS-1107.
- `CHECK-bandwidth-vs-material`: inputs t_rise → BW = 0.35/t_r; if BW > 1 GHz require foil roughness/oxide process spec; if > 10 GHz require ultra-smooth foil and loss class ≤ low-loss. Source: COOMBS-1121, 1137, 1160.
- `CHECK-critical-length`: inputs t_r (ns), net length (in), terminated? → L_max = t_r × 6/6 = t_r (in) (1/6 rule, FR-4) → if unterminated and L > L_max → FAIL (needs termination/simulation); also flag any net with t_r < 5 ns and L > 1 in for termination. Source: COOMBS-1207, 1208.
- `CHECK-termination-type`: inputs topology (point-to-point / multipoint / daisy / star / plug-in), Z0, Z_drv → recommend series (R = Z0 − Z_drv) for point-to-point, parallel DC/AC for multipoint & daisy chain, distributed for plug-in; for star require branch delays and impedances equal and, if branch > 0.75 in, parallel branch Z = inbound Z. Source: COOMBS-1209.
- `CHECK-propagation-delay`: inputs length (in), Dk → t_pd = 85 ps/in × sqrt(Dk) × L (stripline) → compare with timing budget. Source: COOMBS-1204.
- `CHECK-microstrip-50ohm-quick`: inputs W, H → pass if 1.8 ≤ W/H ≤ 2.2 for nominal 50 Ω FR-4 microstrip (sanity check before field solve). Source: COOMBS-1205.
- `CHECK-reflection`: inputs Z1, Z2 at each discontinuity → Γ = (Z2 − Z1)/(Z2 + Z1) → flag |Γ| above design tolerance (project-set, e.g. 0.1). Source: COOMBS-1206.
- `CHECK-crosstalk-spacing`: inputs W, H, S, net class → pass if S ≥ 3W or S ≥ 3H for sensitive classes; warn if S ≤ 4 mil (20–60 mV expected); note diminishing return beyond ≈ 7 mil. Source: COOMBS-1210.
- `CHECK-crosstalk-plane-distance`: inputs H → prefer H ≤ 4 mil for noise-sensitive buses; flag H ≥ 6 mil; prefer symmetric stripline. Source: COOMBS-1211.
- `CHECK-Cpk`: inputs μ, σ, USL, LSL → Cpk = min((USL−μ)/(3σ), (μ−LSL)/(3σ)) → pass if ≥ 1.0 (99.73 %); target 2.0. Source: COOMBS-1062.
- `CHECK-fine-pitch-flag`: inputs component pitch → flag if < 0.65 mm (fine pitch) and if ≤ 0.4 mm (requires HDI/microvia ≥ 0.1 mm). Source: COOMBS-1189, 1191.
- `CHECK-fab-data-package`: boolean checklist: per-layer RS-274X/ODB++/IPC-2581 files; Excellon drill with units/format header, tool table with size/plating/tolerance/span; outline/rout; stack-up; IPC-D-356 netlist; fab drawing with impedance (ohms, tolerance, frequency, model), material, thickness±tol, finish, mask, marking, datum; negative plane layers; no 274-D; no self-intersecting polygons. Source: COOMBS-1041–1048, 1054.
- `CHECK-CAF-spacing`: inputs min hole-wall-to-hole-wall spacing (mil), bias (V), environment class → if spacing < 25 mil and (bias ≥ 10 V or environment ∈ {automotive, military, aero, outdoor}) require CAF test data at ≤ design spacing (500–1000 h, 65/85 or 85/85, 100 V) on the exact glass/silane/resin lot family; fail if only "CAF-resistant" marketing claim. Source: COOMBS-1130, 1133–1136, 1162.
- `CHECK-moisture-bake`: inputs storage RH/duration, finish type → if uncontrolled storage or non-HASL finish and lead-free reflow → require pre-assembly bake (e.g. 125 °C, ≥ 24 h class). Source: COOMBS-1146, 1147, 1155.
- `CHECK-HTE-foil`: inputs inner-layer foil grade → pass if grade 3 (HTE) or RTF meeting HTE for all MLB inner layers. Source: COOMBS-1099.
- `CHECK-halogen-free-declaration`: inputs Br, Cl ppm → FR-4.1 class requires Br ≤ 900, Cl ≤ 900, Br + Cl ≤ 1500 ppm; resin ≥ 50 % epoxy; filler ≤ 45 %. Source: COOMBS-1077.
- `CHECK-supplier-qualification`: boolean: ISO 9001 cert, PCQR2 data (≥ 10 panels), coupon reliability data, CPP capability study Cpk ≥ 1.0, RFQ ≤ 30 days old. Source: COOMBS-1057–1062.

## 4. Verification procedures & plots

- **TMA expansion scan** — x: temperature (°C, 23 → ≥ 250), y: dimension change (µm or %); 10 °C/min after 2 h/105 °C dry; extract Tg (tangent intersection), α1, α2, total % expansion 50–250 °C; "good": α1 ≈ 45–65 ppm/°C, total ≤ ~3.4 % for 260 °C class; rescan for ΔTg ≤ 5–7 °C. (§9.3.1, §11.2.1, §15.5.2.1.1)
- **TGA decomposition curve** — x: temperature (150 → 800 °C at 5 °C/min), y: mass %; mark onset, 1 %, 2 %, 5 %; overlay Sn/Pb (230–235 °C) and lead-free (245–260 °C) windows; "good": ≤ ~1 % loss inside the assembly window and small spread between 1/2/5 % points; compare surface/volume ratio and filler content before ranking. (§9.3.2, §11.2.4, §15.4.5)
- **Cumulative mass loss vs reflow cycle** — x: cycle number (1–6+), y: cumulative % loss at 235 °C and at 260 °C peaks; "good": flat at 260 °C (phenolic); dicy high-Tg rises steeply within a few cycles. (§13.5.2)
- **DMA Tg and modulus vs cycles** — x: reflow cycles to 235/260 °C; y: DMA Tg (°C) and % modulus change; "good": ≤ small drift. (§13.5.5)
- **T260/T288 TMA isotherm** — x: time (min) from isotherm onset, y: thickness; failure = irreversible step; compare unclad vs clad vs PCB (each shorter); 60 min cap. (§11.2.5, §15.5.2.3.3)
- **Reflow-survival bar chart** — x: peak temperature (230 … 260 °C), y: % boards without blister/measle/delamination after 6 cycles (1.5 min dwell); "good": 100 % at 260 °C. (§13.6.1)
- **IST cycles-to-failure** — x: preconditioning (as-is, 3×/6× 230 °C, 3×/6× 255 °C), y: mean cycles to +10 % resistance; coupon pitches 1.0 and 0.8 mm; "good": no collapse after 6× 255 °C. (§13.6.2, §14.3.1)
- **Moisture uptake / bake-out** — x: bake time at 125 °C (0, 24, 48, 96, 120 h), y: % weight change after 5-day soak or 7-day 35 °C/85 % RH; "good": returns to dry baseline. (§13.5.3)
- **Prepreg dynamic viscosity** — x: temperature, y: viscosity (Pa·s, log), curves per heat-rise rate (1–3.5 °C/min); extract minimum viscosity and time below a fill-viscosity threshold; design kiss/soak cycle. (§14.3.1)
- **CAF insulation resistance vs time** — x: hours (0–1000), y: log IR (Ω), per spacing (10/15/20/25 mil or 16/20 mil), 65 °C/85 % RH/100 V (or 85/85, 10 V); also % coupons failed vs time; "good": < 1 decade drop and IR > 10^8 Ω through 1000 h; follow every failure with cross-section/EDX. (§12.8.1, §14.5.2)
- **Dk and Df vs frequency and resin content** — x: frequency (1–10+ GHz, split-post resonator or SPP/SET2DIL), y: Dk, Df; families of constructions/RC; "good": flat Dk, low and monotonic Df; always label test method. (§12.9.3–12.10)
- **Loss (dB/in or dB/m) vs frequency by foil roughness** — 20 in stripline, 4 and 6 mil, ½ oz; overlay standard/RTF/VLP/EVLP foils; expect divergence above 1 GHz. (§12.3.5, §14.4.1)
- **Eye diagram** — 5 Gbps, 1 m, 50 Ω, 5-mil track; eye height (attenuation) and width (jitter); also differential 2.5 Gb/s with 0/40/80 ps skew; "good": open eye meeting the receiver mask. (§12.9.2, §12.11)
- **Receiver waveform vs edge rate and length** — 5 in trace at 10/5/2.5/1 ns edges; 1 ns driver at 5/1/0.5 in; check overshoot/undershoot against Vih/Vil and monotonic transitions. (§20.2.10–20.3)
- **Crosstalk vs spacing** — two parallel 5-in lines; x: spacing (mil), y: NEXT and FEXT (mV); knee ≈ 7 mil; bus case: victim FEXT vs W/S/H/Dk variants ranked (Table 20.1). (§20.3.3–20.3.8)
- **First-pass yield vs complexity index** — x: CI (log), y: FPY %; fit A, B from 10–15 boards × 10 lots; overlay fabricators. (§4.5, §16.6.2)
- **Relative price vs price index** — PI 150 → 0.30×, PI 1000 → 3.75× (curve missing; two anchors). (§16.6.3.3)
- **Panel utilization layout** — nesting plot, boards per panel (6-up vs 8-up example on 18 × 24 in). (§5.5.5, §16.6.3.4)
- **Control chart / capability histogram** — CPPs (dimensions, plating thickness, impedance by TDR) vs USL/LSL; Cpk ≥ 1.0. (§7.2)
- **PCQR2 plots** — predicted yield vs conductor length, measured vs target line/space, conductor height per panel, via registration vs radial distance. (§6.2.1.1)

## 5. Pitfalls, failure modes, review checklist

- Gerber 274-D with external aperture tables, or Excellon files without units/decimal format — top CAM error source; use 274-X/ODB++/IPC-2581 + IPC-D-356. (§5.4.2.1, §5.7)
- Self-intersecting polygons in plane layers → CAM import failure or wrong copper. (§5.4.2.1.2)
- Positive plane layers instead of negative; missing solder-mask clearances; inadequate drill-to-copper clearance; misaligned layers. (§5.7)
- Impedance note without value/tolerance/frequency/model → fabricator guesses. (§5.3.2.1.2)
- Assuming supplier capability from advertised matrix; no PCQR2/first-article data. (§6.2)
- Low supplier first-pass yield → latent field reliability risk even though shipped boards pass e-test. (§6.2.3, §7.2)
- Corrective action "closed" on a plan rather than measured improvement; single-root-cause convergence; suspect material not segregated. (§8.4)
- Specifying Tg as the reliability proxy; ignoring CTE, Td onset, moisture, T260/T288. (§9.3, §13.5)
- Over-specifying Td (≥ 340 °C) or T260 → cost, availability, brittle resins that crack in scoring/drilling. (§11.2.4, §13.5.2, §14.3.2)
- Using dicy-cured high-Tg FR-4 in lead-free (defects from 240 °C peak). (§13.6.1)
- Treating 245 °C qualification as valid at 260 °C (15 °C flips results). (§14.3.1)
- Assuming laminate slash-sheet compliance = PCB reliability (Tg of PCB differs; sheet values are laminate-level). (§14.3.2)
- Trusting datasheet moisture absorption for solder-shock performance (weak correlation). (§13.5.3)
- Uncontrolled storage before lead-free reflow (700 psi steam) → blisters/delamination; forgetting that non-HASL finishes add no bake. (§13.5.3, §14.2.1.8)
- Innerlayer hold after oxide in > 50 % RH; prepreg stored warm/humid; no pre-lamination vacuum. (§14.2.1.4–14.2.1.5)
- Glass stop: insufficient prepreg resin over heavy copper or large copper-free plane areas → delamination and CAF path. (§14.2.1.2)
- High-RC prepreg adjacent to low-RC core, or mixed resin systems, without CTE-mismatch review. (§13.3.2, §14.2.1.2)
- Asymmetric core constructions curl in conveyorized lines. (§12.4.3)
- Undercured cores → extra z-expansion; poorly cured (moisture-contaminated) cores cannot be recovered by post-cure. (§9.3.1.3)
- Spread glass where resin must flow through the cloth to fill 2 oz+ copper → voids. (§14.3.1)
- Hybrid PTFE/FR-4 stacks and new resins needing plasma desmear/different drill parameters without process re-qualification. (§14.2.1.6–14.2.1.7)
- Comparing Dk/Df across suppliers measured by different methods or resin contents (0.002–0.008 spread). (§14.4.3)
- Ignoring oxide-alternative roughness on loss (Df 0.021 vs 0.026 @ 1 GHz). (§12.3.5)
- Routing differential pairs along 106/1080 yarns → weave skew closes eyes at ≥ 2.5 Gb/s. (§12.11)
- Peel-strength rejection of VLP/RTF foil or polyimide without an agreed exception. (§9.2.2, §11.2.7)
- Copying the "CAF-resistant" label: 3 of 4 such FR-4s failed at 15 mil/100 V/85/85 within 500 h; qualify glass + silane + treater. (§12.8.1)
- IR failures attributed to CAF without failure analysis (silver residues, rayon fiber, hollow filament). (§14.5.2)
- Library footprints built by unqualified staff (mirror-image error); unchecked IBIS models. (§19.2.2)
- Drivers that cannot drive transmission lines discovered after schematic. (§19.2.3)
- Timing budget that omits wire delay (6 ns wire vs 3 ns silicon example). (§19.2.13)
- Whole-board post-layout SI as the only SI step ("horse has left the barn"). (§19.2.18)
- Throwing a high-speed design at an autorouter without net-class rules. (§19.2.17)
- Series termination with receivers mid-line (plateau/skew); star nets with unequal branches; weak driver on star. (§20.3)
- Relying on 1/3–1/6 critical-length rules for < 1 ns edges (1 in still rings) — simulate. (§20.2.8)
- Reducing coupled length as the sole crosstalk fix (no reduction in the case study); copper-thickness reduction alone insignificant. (§20.3.6, §20.3.5)
- Sandbagging routing rules (extra layers/finer lines) — +15–50 % cost. (§16.5.1)
- Optimizing the design for one supplier's exotic process → assurance-of-supply risk. (§4.5.1)
- Through-hole ICs in new designs (availability). (§17.4.2)
- BGA without X-ray inspection plan and via-per-ball routing allowance. (§17.4.3.2)
- Backplane press-fit stubs not back-drilled at ≥ 10–28 Gb/s. (§17.2.5)
