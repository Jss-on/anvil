Conventions: c = 3e8 m/s; lambda(f) = c/f; limit lines for the Table 13.1/13.2-style checks are the book's EN Class B 10 m values (30 dBuV/m 30-230 MHz, 37 dBuV/m 230-1000 MHz); thresholds marked "parameter" are not given numerically by the book and must be supplied by the project.

### 3.1 Layout / grounding
- `CHECK-ground-strap-length`: inputs (strap_id, length_m, f_max_Hz) -> lambda_min = c/f_max -> pass if length_m < lambda_min/20 -> margin = lambda_min/20 - length_m (m) -> WILLIAMS-2038, 2286.
- `CHECK-multipoint-link-length`: inputs (link_id, length_m, f_max_Hz) -> pass if length_m < 0.1*c/f_max -> margin = 0.1*c/f_max - length_m -> WILLIAMS-2034.
- `CHECK-edge-10h`: inputs (net_or_plane, class in {critical_net, power_plane, image_plane}, d_edge_mm, h_mm) -> critical_net: pass if distance to 0 V plane edge >= 10*h; power_plane: pass if inset from 0 V plane edge >= 10*h; image_plane: pass if overlap beyond PCB edge > 10*h -> margin = d_edge - 10*h (mm) -> WILLIAMS-2049, 2075, 2265.
- `CHECK-plane-split-crossing`: inputs (net, class, reference_plane_segments_crossed, stitch_or_bridge_present) -> pass if every critical/high di/dt net crossing a 0 V plane gap has a bridging track or stitch via (count_violations = 0) -> severity estimate: added L_slot = 5*x/(2 + ln(w/s)) nH vs L_return = 5*(h/w)*length nH (ratio reported) -> WILLIAMS-2055, 2057, 2063, 2072.
- `CHECK-slot-inductance`: inputs (slot_length_x_cm, slot_width_s, plane_width_w, track_len_cm, h) -> L_slot = 5*x/(2 + ln(w/s)) nH; L_plane = 5*(h/w)*track_len nH -> pass if no critical net crosses (see above); report ratio L_slot/L_plane -> WILLIAMS-2050, 2057.
- `CHECK-diff-pair-spacing`: inputs (pair_id, spacing_to_other_tracks_mm, h_mm) -> pass if spacing >= 3*h -> margin = spacing - 3*h -> WILLIAMS-2087.
- `CHECK-flood-fill-floating`: inputs (copper_island_id, net, via_count) -> pass if net == 0V (or zero-dv/dt net) and via_count >= 1 -> count floating islands = 0 -> WILLIAMS-2065.
- `CHECK-stackup-adjacency`: inputs (layer list with type {signal_critical, signal, gnd, pwr}, dielectric thickness) -> pass if every critical signal layer is adjacent to a GND or PWR plane AND every PWR plane is adjacent to a GND plane AND each GND plane has <= 2 adjacent PWR planes -> report plane-pair separation (flag > 0.5 mm; best <= 0.1 mm) -> WILLIAMS-2062, 2071, 2107, 2115.
- `CHECK-stackup-thickness-specified`: inputs (fab drawing fields) -> pass if every dielectric thickness and controlled-impedance target/layer are specified -> WILLIAMS-2070, 2077.
- `CHECK-plane-resonance`: inputs (plane_x_m, plane_y_m, er, clock list f_clk and harmonic range to 1 GHz, tolerance_pct parameter) -> f_mn = (c/(2*sqrt(er)))*sqrt((m/x)^2 + (n/y)^2) (single-axis modes f = n*c/(2*D*sqrt(er))) -> flag any clock harmonic within tolerance of a mode -> margin = min |f_harm - f_mode|/f_mode -> WILLIAMS-2074, 2076.
- `CHECK-comb-ground`: inputs (ground topology graph) -> pass if no ground spur tree without cross-links (comb) exists on non-plane boards -> WILLIAMS-2047.
- `CHECK-ground-map-interface`: inputs (ground map: nodes, links) -> pass if interface ground has <= 1 link to circuit 0 V, DGND-AGND links = 1 (at ADC) when split, no DGND link to chassis except via interface ground -> WILLIAMS-2080, 2083.
- `CHECK-heatsink-resonance`: inputs (C_heatsink_F, L_ground_H, f_max_Hz) -> f_res = 1/(2*pi*sqrt(L*C)) -> pass if L_ground < 1e-9 (target "well below 1 nH") and f_res > f_max -> margin = f_res/f_max -> WILLIAMS-2078.
- `CHECK-pcb-shield-mounting`: inputs (C_coupling_F, L_mount_H, f_max_Hz) -> f_peak = 1/(2*pi*sqrt(L*C)) -> pass if f_peak > f_max -> margin = f_peak/f_max (example 10 pF/5 nH = 712 MHz fail at 1 GHz; 0.5 nH = 2.25 GHz pass) -> WILLIAMS-2279.
- `CHECK-hybrid-ground-resonance`: inputs (C_F, L_H, band_low_Hz, band_high_Hz) -> f = 1/(2*pi*sqrt(LC)) -> pass if f outside band of concern -> WILLIAMS-2035.

### 3.2 Digital / decoupling / transmission lines
- `CHECK-tline-critical-length`: inputs (net, length_cm, tr_ns, er or tPD_ns_per_cm, termination_present) -> tPD default = 0.067 ns/cm (FR4 er 4.5) -> l_crit = tr/(2*tPD) -> pass if length < l_crit OR termination_present -> margin = l_crit - length -> WILLIAMS-2105, Table 13.3.
- `CHECK-tline-impedance`: inputs (w, h or b, t, er, Z0_target, tol_pct) -> microstrip Z0 = 87/sqrt(er+1.41)*ln(5.98h/(0.8w+t)); stripline Z0 = 60/sqrt(er)*ln(4b/(0.67*pi*(0.8w+t))) (use er at > 500 MHz ~ 0.95*er_1MHz) -> pass if |Z0 - Z0_target| <= tol -> flag Z0 outside practical 50-100 ohm -> WILLIAMS-2067, 2069, 2333.
- `CHECK-loaded-line`: inputs (Tpd, Z0, total_load_C, length) -> CD = C_total/length; Co = 1000*Tpd/Z0; Z0' = Z0/sqrt(1+CD/Co); Tpd' = Tpd*sqrt(1+CD/Co) -> feed Z0' into termination check and Tpd' into critical-length check -> WILLIAMS-2334.
- `CHECK-decap-distance`: inputs (cap_ref, pin_ref, distance_mm, C_F, L_mounted_H, er, has_close_plane_pair) -> SRF = 1/(2*pi*sqrt(L*C)); d_max_m = (300/SRF_MHz)/(40*sqrt(er)); if no plane pair (< 0.5 mm) and fast logic also d_max = 12.7 mm -> pass if distance <= d_max -> margin = d_max - distance -> WILLIAMS-2106, 2107, 2108.
- `CHECK-decap-per-pin`: inputs (IC power pins, caps assigned) -> pass if >= 1 cap adjacent to each power pin (ASIC/FPGA) -> WILLIAMS-2106, 2107.
- `CHECK-rail-capacitance`: inputs (rail, dI_A, dt_s, dV_allow_V, list of caps with C_nom and DC-bias derating) -> Cmin = dI*dt/dV -> sum C_eff (X7R derated, conservative 50% at rated V) -> pass if sum C_eff >= Cmin -> margin = sum C_eff/Cmin -> WILLIAMS-2110, 2111, 2212.
- `CHECK-bus-stopper-resistors`: inputs (netlist: driver output pins of buses/clock) -> pass if a 22-47 ohm series resistor is within the layout proximity parameter of each driver output -> WILLIAMS-2101, 2156.
- `CHECK-dm-loop-emission`: inputs (loop_id, area_cm2, I_pp_mA, f_clk_MHz, tr_ns, duty) -> harmonics I(n) = 2*I*d*sinc(n*pi*d)*sinc(n*pi*tr/T) up to 1 GHz -> E_n(V/m @10 m) = 263e-12*f_n^2*A*I_n (f MHz, A cm2, I mA) -> E_dBuV/m = 20*log10(E_n*1e6) -> limit 30 dBuV/m (30-230 MHz), 37 dBuV/m (230-1000 MHz) -> pass if max(E - limit) < 0 -> margin = limit - E (dB); n similar loops at same f add +10*log10(n) -> WILLIAMS-2091, 2092, 2093, 2337, Table 13.1.
- `CHECK-cm-ground-track-length`: inputs (track_len_cm, L_per_cm (default 2.8 nH/cm), I_pp_mA, f_clk, tr, cable_len_m) -> per harmonic: ICM_allow = E_lim/(1.26e-4*f*L_cable) mA; VN_allow = ICM_allow*150*10 (20 dB coupling loss); L_allow = VN_allow/(2*pi*f*I_n) -> track_allow = L_allow/L_per_cm -> pass if track_len <= min(track_allow) -> WILLIAMS-2095, 2096, Table 13.2.

- `CHECK-trapezoid-breakpoints`: inputs (f_clk, pulse width t, tr) -> f1 = 1/(pi*t); f2 = 1/(pi*tr); report and compare f2 to first cable resonance band 30-100 MHz -> WILLIAMS-2088, 2095.
- `CHECK-ground-bounce`: inputs (L_gnd_H, di_dt_A_per_s, noise_margin_V) -> V = L*di/dt -> pass if V < noise_margin (parameter) -> WILLIAMS-2159.
- `CHECK-latchup-margin`: inputs (pin, V_abs_max, V_transient_max) -> pass if transient clamp keeps V <= abs max (7 V @5 V, 4.6 V @3V3 typical) -> WILLIAMS-2155.

## 5. Pitfalls, failure modes, review checklist

### 5.1 A structured approach to PCB layout for EMC (sec.12.2.5, p.328-329) - transcribed in full
(Assumes at least one 0 V plane; suitable as in-house design policy / review checklist, partly implementable in CAD DRC.)
Before routing begins:
- [ ] identify and label high di/dt circuits (p.328)
- [ ] identify and label sensitive circuits (p.328)
- [ ] identify 0 V plane(s), including separate areas if these are vital (p.328)
- [ ] identify power plane segments (p.328)
- [ ] identify the interface ground plane (p.328)
- [ ] decide on layer stack-up: identify 0 V plane layers; identify constant-impedance layer(s); identify power plane layer(s), next to 0 V plane (some may also carry tracks where power planes aren't needed) (p.328)
- [ ] check component placement: no unnecessarily long track routes; no proximity of noisy components to sensitive ones; critical circuits away from ground plane edge; maximum partitioning of interfaces and functional sections - no unprotected interface routes pass close to operational circuits; all filter components at the interface they protect, no functional circuits between the interface and the protection (p.328)
- [ ] board-to-board connections: ground pins distributed along multi-way connectors close to high-speed or sensitive signals (p.328)
- [ ] identify points for bonding the ground plane(s) to chassis (p.328)
During routing:
- [ ] flag any breaks or gaps in a 0 V plane and decide whether they are necessary or can be avoided (p.329)
- [ ] ensure no tracks cross any unavoidable breaks in a 0 V plane - if they must, place series buffer resistors appropriately at the break (p.329)
- [ ] check that critical and constant-impedance tracks do not swap layers - if they must, route above/below a single 0 V plane, not jump to a different 0 V plane (p.329)
- [ ] check adequate placement of decoupling capacitors - near device power pins - minimum-inductance track/via layout (p.329)
- [ ] ensure interface filtering and transient protection is tracked with low inductance to the interface ground plane (p.329)
- [ ] identify and control common-impedance current paths for power switching circuits and sensitive wideband circuits (p.329)
- [ ] check implementation of the 10*h rule for power planes and critical tracks versus the ground-plane edge (p.329)
- [ ] balanced differential pairs: adequate balance along the entire run - separation of at least 3*h from other tracks is usually enough (p.329)
- [ ] minimize surface areas of nodes with high dv/dt (p.329)
- [ ] flood-filled empty areas of any layer: each area connected to 0 V, not floating (p.329)
If designing a PCB without a 0 V plane:
- [ ] identify critical (high-current, high di/dt or sensitive) circuit loops, including the appropriate segment of the 0 V track (p.329)
- [ ] minimize enclosed loop areas in these loops (p.329)
- [ ] flood-fill and mesh the 0 V tracks as much as possible (p.329)

### 5.2 Pitfalls - layout and grounding (Ch.12)
- Slot/split in the ground plane under a track: +25-30 dB radiated emission above 400 MHz in demo (p.316).
- Row of through-hole pads (DIL/SIL/connector) forms a slot in the plane unless pads are bridged (p.315).
- "Comb" ground topology - forbidden for any class of circuit (p.310).
- Copper flood fill left floating (p.319-320).
- Single heatsink ground contact resonating (10 pF/3 nH -> 900 MHz) can raise emissions after "grounding" it (p.324).
- Power plane mirroring the ground plane edge-to-edge: plane resonance + edge radiation (p.322).
- Segmenting (splitting) ground planes - never; only power planes may be segmented (p.322).
- Layer thicknesses left to fabricator default; supplier change alters EMC (p.322-323).
- Digital 0 V connected separately to external ground in split-ground design (p.326).
- Cable screen terminated to a noisy point (driver decoupling return) instead of the interface ground (p.325).
- Safety earth wire assumed to be an RF ground (p.306).
- Ground straps/wires longer than lambda/20 at f_max (1.5 cm at 1 GHz) (p.306).
- Hybrid ground capacitor resonating with cable inductance (0.1 uF + 0.1 uH = 1.6 MHz) - screen "anything but grounded" there (p.305).
- Clock edges slowed with shunt capacitance: raises driver di/dt, can worsen emissions (p.338).
- Meeting Table 13.1 loop-area limits does not assure compliance - CM emissions usually dominate (p.334).
- Unplanned substitution of faster logic family (74HC -> 74AC) raises harmonics above 200 MHz (p.336-337, Fig 13.5).

### 5.3 Appendix A - Design checklist (p.500-502) - transcribed in full
- [ ] Design for EMC from the beginning; know what performance you require
- [ ] Partition the system into critical and non-critical sections:
  - [ ] determine which circuits will be noisy or susceptible and which will not
  - [ ] lay them out in separate areas as far as possible
  - [ ] select internal and external interface locations to allow optimum common mode current control
- [ ] Select components and circuits with EMC in mind:
  - [ ] use slow and/or high-immunity logic; apply slew rate limiting to data transmission interfaces
  - [ ] use series R buffering on all high-speed clock and data lines
  - [ ] use good power decoupling techniques: small, low-inductance capacitors adjacent to the ICs they are decoupling
  - [ ] use series ferrite chips in the supplies to create power segments
  - [ ] reduce fan-out on clock circuits by liberal use of buffers
  - [ ] minimize analogue signal bandwidths
  - [ ] maximize dynamic range of analogue signal paths
  - [ ] check stability in wideband amplifiers
  - [ ] don't leave unused IC input pins floating: tie them to 0V or VCC
  - [ ] include resistive, ferrite or capacitive filtering at all sensitive analogue inputs
  - [ ] incorporate a watchdog circuit on every microprocessor
  - [ ] avoid edge triggered digital inputs if possible, protect them if unavoidable
- [ ] PCB layout: refer to separate checklist in section 12.2.5 (see 5.1 above)
- [ ] Cables:
  - [ ] segregate, and avoid parallel runs of, signal and power cables
  - [ ] choose RF-screened cables if the wanted signal cannot be properly filtered
  - [ ] avoid screened cable with the screen connected only at one end; if unavoidable, treat the cable as unscreened at RF
  - [ ] use twisted pair both within and outside an enclosure, for balanced or high di/dt lines
  - [ ] use properly designed looms, ribbon or flexi for internal wiring - avoid loose wires or bundles
  - [ ] run cables away from apertures in the shielding, tied close to conductive grounded structures
  - [ ] apply ferrite suppressors to damp resonances and control common mode currents
  - [ ] ensure that cable screens are properly terminated to the connector backshell; avoid pigtails
  - [ ] terminate lines carrying high frequency signals with the correct transmission line impedance
- [ ] Grounding:
  - [ ] design and enforce the ground system at the product definition stage
  - [ ] consider the ground system as a return current path, not just as 0V reference
  - [ ] provide for parallel earth conductors at the system level
  - [ ] ensure metal-to-metal bonding of screens, connectors, filters, and enclosure panels
  - [ ] ensure that bonding methods will not deteriorate in adverse environments
  - [ ] mask paint from, and apply a conductive finish to, any intended contact surfaces
  - [ ] keep earth straps short and define their geometry
  - [ ] avoid common ground impedances for different circuits
  - [ ] provide an interface ground area for decoupling and filtering
- [ ] Filters:
  - [ ] assume that a supply filter is needed: design the filter for the application
  - [ ] filter all I/O lines, using either or both of three-terminal capacitors to interface ground, and common mode chokes
  - [ ] apply pi filters at the DC power input to each board, in multi-board designs
  - [ ] ensure a defined ground return for each filter
  - [ ] apply filtering to interference sources, such as switches or motors, directly at their terminals
  - [ ] locate all filter components and associated wiring or tracks adjacent to the interface being filtered
- [ ] Shielding:
  - [ ] design all metallic structures as if they were electrical components: account for their stray capacitance and inductance
  - [ ] consider segregated enclosures: enclose particularly sensitive or noisy areas with extra internal shielding
  - [ ] avoid large or resonant apertures in a shield, or take measures to mitigate them
  - [ ] avoid dipole-like structures in a metallic enclosure
  - [ ] ensure that separate panels are well bonded along their seams using conductive gaskets: apply good bonding practice as in "grounding" above
  - [ ] design plastic enclosures to allow internal conductive coating if necessary
  - [ ] decide on and implement DC or RF tie points between circuit 0V and the shield
  - [ ] use multiple internal tie-points to minimize box resonances
- [ ] Test and evaluate for EMC continuously as the design progresses

### 5.4 Design-rule issue list for design reviews (sec.17.2.2, p.487-488)
- [ ] Circuit design: analogue bandwidth limitation; power segmentation and decoupling; power bus regulation, conversion and distribution; choice of clock frequencies; clock distribution and buffering; risetime and slew rate limitations
- [ ] PCB layout: 0V plane(s); power plane(s); layer stack-up; decoupling placement; component placement; constant impedance layers; heatsink and mechanical aspects; ground connections and general routing
- [ ] Interfaces: power supply filtering; LF unscreened cable port filtering; HF unscreened cable port balance and common mode chokes; connection of screen to chassis for screened cable ports
- [ ] Enclosure design: aperture size and location; bonding of structural parts; conductive gaskets; mating surface treatment and paint masking; PCB-to-enclosure connections; localized screening; moulding design for conductive coatings and choice of coating

### 5.5 Pitfalls - circuits, interfaces, filters, shielding, systems (Ch.13-17, App.C)
- Remote decoupling capacitors on a board with ground plane but no power plane can INCREASE noise current at track resonances (2-50 MHz) (p.346).
- Paralleled different-value decouplers create anti-resonance impedance peaks (p.345).
- Low-loss 1-10 uF ceramics as analogue bulk decouplers can resonate with the HF ceramic; use lossy electrolytic (p.349).
- Unterminated coax load (10 m RG58 ~ 1000 pF) destabilizes op-amp outputs (p.350).
- Heatsink of switching device bolted to chassis shorts CHS and injects CM noise (p.353).
- Transformer high-dv/dt winding ends adjacent across the isolation barrier (p.353).
- DM filter tested only at light load - inductors saturate at peak line current (p.357).
- Ferrite on a high-impedance (150 ohm) circuit: only ~2.5 dB for 100 ohm ferrite (p.413).
- Multi-turn ferrite windings: lower SRF, attenuation peak moves down in frequency (p.414).
- Filter input and output leads in the same loom / poor filter ground: HF CM attenuation lost (p.411).
- Mains switch wired before the filter with unfiltered wiring routed across the box (p.418).
- CX ineffective against the very low DM source impedance of an SMPS reservoir capacitor (p.419-420).
- Mains filter rated on RMS current: CM choke saturates at capacitor-input peaks (3-10x RMS) (p.423).
- Standard mains filters let through saturating CM surges (lightning) only slightly attenuated (p.423).
- Earth-line choke bypassed by an earth path via a signal cable (p.424).
- Capacitive RF filters on balanced/isolated lines: 10% tolerance mismatch limits CMR to ~20 dB (Ethernet: use CM choke only) (p.427).
- CM filter capacitors rated only for signal voltage, not for circuit-to-chassis surge (can exceed 1 kV) (p.427).
- Suppressor fails open silently; no protection at next surge (p.430).
- 0603 resistor used as the series element ahead of a surge suppressor (p.431).
- Opto-coupler with external base pin: blinded for several us by 2 kV transients (p.385-386).
- Digital isolators with on-chip power transfer (180-300 MHz) radiate via barrier CM current (p.386).
- Screen grounded at one end only: no RF shielding (p.393); pigtail terminations (p.400); PCB track from connector shell to ground acts as a pigtail (p.401).
- Foil/drain-wire screens: poor magnetic screening, ~20 dB worse ZT than braid (p.396-398).
- "Shield not connected to chassis" rules (e.g. NMEA 2000 2.4.1.1) negate RF shielding (p.393).
- Single ground conductor in ribbon cable carrying HF data (p.403).
- Slot perpendicular to E-field / long thin slots; seams with sparse fasteners; painted mating surfaces (p.442-449).
- Cables routed near apertures/seams or across seams without bonding (p.444).
- Conductive coating scratches/cracks act as apertures; coatings may flake and bridge safety isolation (p.450-451).
- Loose/corroded wire-mesh crossovers destroy mesh vent SE (p.453).
- Conductive shafts or cables passed through waveguide-below-cutoff vents (p.454).
- PCB shield can with few mounting points: 10 pF/5 nH mounting gives zero SE below 1 GHz (p.455).
- Two conductive box halves joined by a wire form a dipole (App.C.4, p.513).
- Differential DC-input capacitor used to cure a CM wall-wart emission problem (App.C.3, p.511).
- Safety bond wires assumed to be EMC bonds; bonding straps replaced by wire loops in maintenance (p.463, p.471).
- DC continuity check used to "prove" 360 deg penetrations (p.471).
- Star earthing on large systems at MHz frequencies; decays into accidental loops over time (p.461).
- Ladder/basket or heavily slotted cable trays relied on as HF PECs (p.475).
- Programmable timer used as watchdog; watchdog disabled during long operations; watchdog driving an interrupt instead of RESET (p.374-375).
- Software input filtering masking hardware immunity weakness during tests (p.376).
- In-circuit emulator connected during ESD/EFT tests (p.377).

4.
