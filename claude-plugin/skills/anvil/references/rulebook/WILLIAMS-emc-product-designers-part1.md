## 3. Mechanizable checks

Interface-list schema assumed by the checks below (one row per port): `port_id, port_type ∈ {ac_mains, dc_power, signal_control, wired_network_telecom, antenna, enclosure, functional_earth}, max_cable_length_m, leaves_building (bool), shielded (bool), conductor_count, notes`; product-level fields: `environment ∈ {residential, industrial}`, `has_radio (bool)`, `market ∈ {EU, US, CA, CN, AU, JP, TW, KR, EAEU}`, `rated_input_A_per_phase`, `mains_V`, `P_in_W`, `product_type`, `f_h_MHz` (highest internal frequency incl. on-chip PLLs), `f_clk_offchip_MHz`, `ehs_max_dimension_m`.

**CHECK-directive-route** — inputs: has_radio, mains_V, battery_only, market → if EU and has_radio → RED 2014/53/EU (EMC via EN 301 489 + LVD safety objectives with no lower voltage limit + spectrum standards); elif EU → EMCD 2014/30/EU (+ LVD if 50–1000 V AC / 75–1500 V DC); US → FCC Part 15 B if digital device (timing > 9 kHz) unless exempt (P < 6 nW; f_h < 1.705 MHz and not mains-operable; exempt application classes) → pass criterion: route and required documents (DoC, technical documentation retained ≥ 10 years, CE ≥ 5 mm; RED DoC accompanies unit) listed → source: WILLIAMS-1017, 1021, 1022, 1023, 1032, 1039.

**CHECK-standard-selection** — inputs: product_type, environment, has_radio → if a product-family standard exists use it (e.g. multimedia → EN 55032 emissions; ISM → EN 55011; household/tools → EN 55014-1/-2; lighting → EN 55015/EN 61547; medical → EN 60601-1-2; marine → EN 60945; telecom network → EN 300 386; radio → EN 301 489-x); else generic: residential → EN 61000-6-3 + EN 61000-6-1, industrial → EN 61000-6-4 + EN 61000-6-2; always add EN 61000-3-2/-3-3 if mains ≤ 16 A (EN 61000-3-12/-3-11 if 16–75 A) → pass: every essential-requirement area (LF emissions, LF immunity, transients, RF emissions, RF immunity) covered by a dated standard → source: WILLIAMS-1036, 1047–1060, 1071–1075.

**CHECK-emission-class** — inputs: environment, standard → EN 55032: residential-primary → Class B else Class A; EN 55011: domestic → Class B; Group 2 if RF intentionally used for material treatment/inspection → pass: class recorded; Class A → user warning text present → source: WILLIAMS-1026, 1049, 1052.

**CHECK-port-test-matrix (immunity, generic)** — inputs: per-port rows, environment → for each port emit test, level, applicability:
- enclosure: ESD 4 kV contact / 8 kV air; radiated RF 80–1000 MHz 3 V/m (res.) or 10 V/m (ind., 3 V/m in 87–108/174–230/470–790 MHz), 1.4–2.0 GHz 3 V/m, 2.0–2.7 GHz 1 V/m, 80 % AM 1 kHz; PF magnetic 3 A/m (res.) / 30 A/m (ind.) only if magnetically sensitive devices present.
- ac_mains: EFT 1 kV (res.) / 2 kV (ind.); surge 2 kV L–E and 1 kV L–L (res.), 1 or 2 kV (ind.); conducted RF 3 V (res.) / 10 V (ind., 3 V in 47–68 MHz) 150 kHz–80 MHz; dips ½ and 1 cycle to 0 % (crit. B), 0.5 s to 70 % and 5 s to 0 % (crit. C) [EN 61000-6-1:2007 as quoted].
- dc_power: EFT 0.5 kV/1 kV (res.), 1/2 kV (ind.); surge 0.5 kV on some DC ports; conducted RF as mains — applicability by max_cable_length_m and connection to a DC network.
- signal_control / wired_network: EFT and conducted RF apply only above the standard's cable-length threshold (record length); surge 0.5 kV (ind.) only if cables are long or leave the building (leaves_building = true → surge applies, 10/700 µs for outdoor telecom lines).
→ pass: every port has a test or a recorded exemption rationale → source: WILLIAMS-1054, 1055, 1056, 1064, 1065, 1066, 1214.

**CHECK-port-test-matrix (emissions)** — inputs: per-port rows, standard/class → ac_mains: 150 kHz–30 MHz QP+AV (LISN 50 Ω/50 µH); dc_power: 150 kHz–30 MHz Class A if connected to a local DC network or battery via cable > 30 m (EN 61000-6-3); wired_network/telecom: CM 150 kHz–30 MHz via ISN (150 Ω) or current/voltage probe; enclosure: 30–1000 MHz QP, plus 1 GHz–f_upper (CHECK-radiated-upper-frequency); harmonics/flicker if mains ≤ 16 A → source: WILLIAMS-1047, 1051, 1052, 1142.

**CHECK-radiated-upper-frequency** — inputs: f_h_MHz (CISPR 32 includes on-chip PLL frequencies), market → CISPR 22/32: f_h < 108 → 1000 MHz; 108 ≤ f_h < 500 → 2000 MHz; 500 ≤ f_h < 1000 → 5000 MHz; f_h ≥ 1000 → min(5·f_h, 6000) MHz; FCC: same but above 6 GHz min(5·f_h, 40000) MHz; FCC f_h < 1.705 MHz → 30 MHz only → pass: planned test range ≥ computed range → source: WILLIAMS-1078, 1079; T-W9.

**CHECK-emission-margin** — inputs: list of (f_MHz, level_dB, detector, distance_m), limit table, U_lab_dB, U_cispr_dB (Table 7.5) → normalise distance: L(d) = L(10 m) + 20·log10(10/d) (1/d; optimistic at LF); X_eff = X + max(0, U_lab − U_cispr); margin = L − X_eff → pass: margin ≥ 0 for compliance; design target margin ≥ 4–6 dB for a single sample (≈10 dB if pre-compliance uncertainty is large); report ≥ 6 highest emissions within 10 dB of the limit (CISPR 32) → limits: Class B radiated 10 m: 30 dBµV/m (30–230 MHz), 37 dBµV/m (230–1000 MHz); > 1 GHz at 3 m: Class B AV 50/PK 70 (1–3 GHz), AV 54/PK 74 (3–6 GHz); Class A AV 56/PK 76, AV 60/PK 80; conducted AV = QP − 10 dB (B), QP − 13 dB (A) → source: WILLIAMS-1076, 1077, 1127, 1160, 1169, 1170, 1265; T-W8, T-W10, T-W23.

**CHECK-loop-radiation (DM, eq. 11.13)** — inputs per loop/net: A_cm2 (signal+return loop area), I_S_mA per harmonic, f_MHz per harmonic, limit_dBuV_m (10 m) → E_V_m = 263e-12·f²·A·I_S; E_dB = 20·log10(E_V_m·1e6) → pass: E_dB ≤ limit − margin (margin default 6 dB) for every harmonic below the upper test frequency; also assert loop max dimension < λ/4 (λ = 300/(f·sqrt(εr_eff)) m) else flag "model invalid" → worked check: A = 10, I = 20, f = 50 → 42.4 dBµV/m (fails Class B by 12 dB) → source: WILLIAMS-1284, 1285, 1286.

**CHECK-cable-CM-radiation (eq. 11.14)** — inputs per external cable: L_m, I_CM_mA(f) (measured with current probe or predicted), f_MHz → E_V_m = 1.26e-4·f·L·I_CM; E_dB vs limit; I_CM_max_mA = 10^((limit−120)/20)/(1.26e-4·f·L) → pass: E_dB ≤ limit − margin AND measured I_CM ≤ 5 µA (13.98 dBµA) per cable as pre-compliance indicator; flag L ≥ λ/4 (resonant — model invalid, use App. D.3.6) → worked check: L = 1, f = 50, I = 0.02 mA → 42 dBµV/m; I = 0.005 mA → 30 dBµV/m → source: WILLIAMS-1288, 1289.

**CHECK-cable-resonance** — inputs: cable length L_m (each external cable), clock/harmonic list → f_λ/4 = 75/L MHz, f_λ/2 = 150/L MHz (free space) and multiples → flag any clock harmonic or immunity-sensitive frequency within the resonance region (tolerance not given in text; default ±10 %, low) → source: WILLIAMS-1288, 1298.

**CHECK-plane-patch-resonance** — inputs: plane dimensions L_x, L_y (m), εr (default 4.2), clock harmonic list → f_n = n·300/(2·L·sqrt(εr)) MHz (centre feed) and n·300/(4·L·sqrt(εr)) (edge feed) → flag harmonics near f_n; verify 10·h edge rule (Part 2) → worked: L = 0.15 m, εr = 4.2 → 488 MHz → source: WILLIAMS-1287.

**CHECK-near-far-field** — inputs: f_MHz, D_m (EUT/antenna max dimension), d_m (measurement or victim distance) → λ = 300/f; r_M = λ/(2π); r_R = 2D²/λ; far = d > max(r_M, r_R) → pass/flag (near-field results cannot be scaled by 1/d) → source: WILLIAMS-1280, 1281; T-W31.

**CHECK-small-loop / small-EUT (GTEM)** — inputs: EUT max case dimension, f_max, has_cables → small EUT iff d_max < 300/f_max (m) AND no cables → otherwise GTEM emission correlation not valid → source: WILLIAMS-1145.

**CHECK-common-impedance** — inputs: shared conductor length/inductance L_H (or R, L), victim's dI/dt (A/s), victim noise margin V_NM → V_N = L·dI/dt (+ I·R) → pass: V_N < V_NM (margin factor per design rules) → source: WILLIAMS-1271.

**CHECK-inductive-coupling** — inputs: parallel run length ℓ (m), M per metre (default 0.2 µH/m for loomed wires, else from Fig 11.4/App. D), dI/dt → V_N = M·ℓ·dI/dt → pass: V_N < victim threshold → source: WILLIAMS-1272.

**CHECK-capacitive-coupling** — inputs: C_C (default 50 pF/m × ℓ for insulated wires 0.1 in apart), dV/dt, Z_in, R_S → V_N = C_C·dV/dt·(Z_in·R_S/(Z_in+R_S)) (valid when 1/(ωC_C) ≫ circuit impedance) → pass: V_N < threshold → source: WILLIAMS-1273.

**CHECK-crosstalk-LF (eqs 11.5–11.9)** — inputs: V1, f, C, M (for the coupled length), R_S1, R_L1, R_S2, R_L2; assert coupled length ≪ λ → I_C, V_M, V_NE, V_FE → pass: |V_NE|, |V_FE| < victim noise margin → source: WILLIAMS-1276, 1277.

**CHECK-balance (DM→CM, eq. 11.12)** — inputs: I_CM, Z_A, Z_B (stray impedances of the two conductors to ground) → V_load = I_CM·|Z_A − Z_B| → pass: below receiver threshold; else require CM choke / balance → source: WILLIAMS-1283.

**CHECK-harmonic-class** — inputs: product_type, P_in_W (max over windows), professional (bool), mains_V, I_phase → if mains_V ∉ 220–240 V: IEC 61000-3-2 n/a; if I > 16 A: IEC 61000-3-12 (choose Rsce ≥ 33); exempt if (P ≤ 75 W and not lighting) or (professional and P > 1000 W) or (symmetric heater ≤ 200 W) or (incandescent dimmer ≤ 1 kW); Class D if PC/monitor/TV/VSD fridge-freezer and P_spec ≤ 600 W (P_spec may be set within ±10 % of measured); Class C lighting; Class B portable tools/non-professional arc welders; else Class A → source: WILLIAMS-1057, 1058, 1227, 1233, 1234, 1235, 1236.

**CHECK-flicker-inrush** — inputs: I_rms_halfcycle_max (A) incl. inrush, steady current variation band ΔI (A), V_nom (default 230 V), R_ref (0.4 Ω single phase) → deemed compliant if I ≤ 20 A AND ΔI ≤ 1.5 A (manual switching, cl. 6.1); else estimate d_max ≈ I·R_ref/V_nom and require d_max ≤ 4 % (6 % manual, 7 % attended), d_c ≤ 3.3 %, and time above 3.3 % ≤ 500 ms; I_inrush,max = 0.04·230/0.4 = 23 A → source: WILLIAMS-1059, 1238, 1241, 1242.

**CHECK-Plt** — inputs: 12 successive Pst values → Plt = (Σ Pst³/12)^(1/3) → pass: every Pst ≤ 1 and Plt ≤ 0.65 (Plt only if normally operated > 30 min) → source: WILLIAMS-1243.

**CHECK-surge-current** — inputs: surge level V (kV), coupling (L–L power 2 Ω; L–E power 12 Ω; I/O 42 Ω) → I_peak ≈ V/Z (8/20 µs) for protector selection; apply all lower levels (0.5, 1, 2, 4 kV up to the level) and 4 phase angles on AC → pass: protector rated for I_peak and repetition (≤ 10 surges/level) → source: WILLIAMS-1065, 1214, 1215.

**CHECK-dip-transformer-inrush** — inputs: transformer-input PSU (bool), I_rated → expect half-cycle-dip re-application inrush 10–40 × I_rated → pass: fuse/switch/rectifier I²t and surge ratings cover 40 × I_rated for the recovery period → source: WILLIAMS-1249.

**CHECK-conducted-vs-radiated-immunity-range** — inputs: EUT max dimension L_EUT (m) → conducted injection representative up to f ≈ 150/L_EUT MHz (λ/2); IEC 61000-4-6 stops at 80 MHz (or 230 MHz for ~0.6 m) → radiated immunity required above → source: WILLIAMS-1204.

**CHECK-immunity-test-power (planning)** — inputs: E_target (V/m), r (m), antenna gain G(f), room ∈ {anechoic, non-anechoic} → P_t = (r·E)²/(30·G); P_amp ≥ P_t·3.3 (80 % AM) ·(4 if non-anechoic) plus losses; linearity: ≤ 2 dB compression at 1.8 × E → source: WILLIAMS-1181, 1182, 1184.

**CHECK-immunity-level-uncertainty** — inputs: E_spec, standard uncertainty u, policy ∈ {LAB34, CENELEC-IS} → E_applied = E_spec + 1.64·u (LAB 34) or E_spec (CENELEC interpretation sheets for EN 61000-4-3/-6) → record policy in test plan → worked: 10 V/m, u = 1.5 → 12.46 V/m → source: WILLIAMS-1205, 1267.

**CHECK-measurement-noise-floor** — inputs: receiver noise N_rx (dBµV in RBW), AF(f) (dB/m), cable loss A(f) (dB), preamp gain G and NF (dB), limit L → floor = N_rx − (G − NF) + AF + A → pass: floor ≤ L − 6 dB (CISPR 16-1-1: < 1 dB error) → worked: +13 dBµV + AF + 3 dB → 41 dBµV/m at 1 GHz vs 37 → fail without preamp → source: WILLIAMS-1121, 1126.

**CHECK-mismatch-uncertainty** — inputs: VSWR_S, VSWR_L → Γ = (VSWR−1)/(VSWR+1); U± = 20·log10(1 ± Γ_S·Γ_L) → worked: 1.5 and 4 → ≈ ±1 dB → source: WILLIAMS-1172.

**CHECK-production-sampling-80/80** — inputs: n units tested, failures c (emissions or immunity) or measured levels (scheme 1) → scheme 2 pass: c ≤ c_max(n) with (n, c_max) = (7,0), (14,1), (20,2), (26,3), (32,4); scheme 1 pass: X̄ + k·S_n ≤ L with k from the non-central t table (2.04 at small n … 1.2 at n = 12; intermediate values not printed) → source: WILLIAMS-1027; T-W2.

**CHECK-scan-time** — inputs: span, RBW, dwell, EUT repetition period t_EUT → steps = span/(0.5·RBW); T = steps·dwell; P_intercept = min(1, dwell/t_EUT) → flag P_intercept < 1 in pre-scan (use FFT receiver or longer dwell) → source: WILLIAMS-1119, 1162.

**CHECK-EN50155-supply** — inputs: converter input range V_min..V_max, V_nom → pass: [0.7·V_nom, 1.25·V_nom] within continuous operating range AND [0.6·V_nom, 1.4·V_nom] survived for 100 ms without deviation of function → source: WILLIAMS-1096.

**CHECK-functional-safety-margin** — inputs: susceptibility threshold per frequency/phenomenon, specified level, required SIL → margin_dB = 20·log10(threshold/level) → pass: documented thresholds exist (not just "pass") and safe-state behaviour verified above threshold; PFD/PFH within Table 6.1 band for the SIL → source: WILLIAMS-1097, 1098.

**CHECK-earth-bond** — inputs: list of bond resistance measurements (Ω) → pass: every bond ≤ 2 mΩ (DEF STAN 59-411 Part 4 B.3 general limit) → source: WILLIAMS-1107.

## 5. Pitfalls, failure modes, review checklist

- [ ] A radio module anywhere in the product moves it from the EMCD to the RED (safety with no lower voltage limit, spectrum requirements, DoC with each unit) — §2.3.1 p.51, §2.4.3 p.58.
- [ ] CE compliance is not FCC compliance: FCC requires ANSI C63.4 procedures and US mains voltage ($1m fine, 2006) — §3.2.2 p.66.
- [ ] Declaring to superseded standards (e.g. EN 50082-1:1992) or undated references without checking Annex ZA — §4.1.2.5 p.82, §4.6 p.96–97.
- [ ] Class A equipment shipped without the Class A warning / residential-use restriction in the user information — §2.2.3.6 p.41.
- [ ] Module/plug-in card sold to end users treated as a "component" (it is apparatus, test in a representative host) — §2.2.2.4 p.37–38.
- [ ] Engineering changes (HW or SW) not assessed for EMC before continuing to ship under an old DoC — §2.2.3.3 p.39–40.
- [ ] Highest internal frequency taken from off-chip crystals only, missing on-chip PLL multiples (CISPR 32 counts them; CISPR 14-1 does not) — §4.8.1 p.105.
- [ ] Radiated tests stopped at 1 GHz for a product with clocks ≥ 108 MHz — §4.8.1 p.104–105, §3.2.2 p.66.
- [ ] Generic-standard port exemptions claimed without recording the maximum allowed cable length per port — §4.4 p.90–91, §10.2.3.3 p.249.
- [ ] Assuming EN 61000-3-2 compliance covers 115 V/60 Hz markets or military CE101 (it does not; CE101 is stricter above 1 kVA) — §9.1.3.3 p.234–235.
- [ ] Electronic power supply exceeding the flicker voltage-change limit at switch-on (inrush > ~23 A on 230 V) because "flicker doesn't apply to electronics" — §9.1.4 p.236–238.
- [ ] Burst-fired (few-cycle) heater control of a substantial load — fails flicker — §9.1.4 p.236.
- [ ] Half-cycle dip testing of a transformer-input product: 10–40× rated inrush on recovery blows fuses — §9.2.2.1 p.243.
- [ ] Measuring conducted or radiated emissions with signal ports disconnected — gives false (low) results — §11.2.2.1 p.278.
- [ ] Coiling excess cable (inductance ∝ N²) instead of bundling back-and-forth — §10.2.6.2 p.253.
- [ ] Power-supply emissions tested only at full load (light load/standby can be worse) or with a floating resistive load (wrong CM termination) — §10.2.6.2 p.253.
- [ ] Pre-compliance with a bare spectrum analyser: mixer overload gives artificially low readings; system noise floor at 1 GHz is above the Class B limit without a preamp — §7.1.2 p.141–142, §7.2.1.1 p.152.
- [ ] Transient limiter omitted before an analyser on a LISN (mains transients > 1 kV destroy the mixer); or limiter clipped by out-of-band LF signals creating false harmonics — §7.2.2.1 p.157.
- [ ] LISN not bolted to earth (≈ 0.9 A earth current; case and EUT can become live); LISN on an RCD-protected circuit — §7.2.2.1 p.157.
- [ ] Unlined screened-room radiated measurements used for amplitudes (±30 dB nulls/peaks) — §7.3.1.3 p.169.
- [ ] 3 m results scaled to 10 m by −10.5 dB at low frequencies (near field; optimistic) — §7.3.1.1 p.167.
- [ ] Peak pre-scan dwell shorter than the EUT's longest repetition period — intermittent narrowband emissions missed — §7.4.2.2 p.177, §7.4.2.3 p.177.
- [ ] Only one EUT orientation pre-scanned — emissions lost in radiation-pattern nulls — §7.4.2.2 p.177.
- [ ] Antenna cable not choked with ferrites (poorly balanced antenna): up to 5 dB error in vertical polarisation — §7.5.2.4 p.187.
- [ ] Using the same antenna for high-power immunity and emissions (balun heating shifts antenna factor) — §8.1.1.4 p.196–197.
- [ ] Calibrating RF immunity levels with modulation on (meters misread) — §8.1.1.2 p.195.
- [ ] Closed-loop field levelling in a non-anechoic room over-tests when the sensor sits in a null — §8.1.1.3 p.196.
- [ ] 1 % frequency steps skipping narrowband susceptibilities near ADC/clock frequencies — §8.1.3.4 p.206.
- [ ] Spot-frequency RF immunity checks (ISM, amateur bands, a phone) taken as proof of immunity — resonances fall between spots — §8.1.3.6 p.207.
- [ ] BCI on long cables treated as a defined stress (depends on AE impedance and resonance; λ/4 at 80 MHz = 94 cm) — §8.1.4.1 p.209.
- [ ] Conducted RF immunity used as a substitute for radiated immunity above the EUT's λ/2 frequency — §8.1.4.3 p.211.
- [ ] ESD air discharge applied slowly/timidly (not repeatable; approach speed and humidity matter); ungrounded EUT not bled between discharges (charge accumulation; up to 2× stress on polarity reversal) — §8.2.1.3 p.214–215, §8.2.5.3 p.222.
- [ ] Testing pins of plastic connectors by contact discharge, or skipping them when the connector may be left open — §8.2.1.3 p.214.
- [ ] EFT applied line-by-line instead of common mode on all lines (later editions of IEC 61000-4-4) — §8.2.2.2 p.217.
- [ ] Surge levels applied only at the top level (all lower levels must also pass; protectors may let lower levels through) — §8.2.3.2 p.219.
- [ ] Surge tests damaging filter components silently — repeat conducted emissions afterwards — §10.2.3.4 p.249.
- [ ] Too few transient applications to catch low-probability timing coincidences in digital EUTs — §8.2.5.2 p.222.
- [ ] Immunity monitoring equipment itself upset by the stress (or emissions carried into the chamber on support cables) — §10.2.4.3–10.2.4.4 p.250–251.
- [ ] Performance criteria left undefined until the test (no quantitative degradation limits, no marketing sign-off) — §10.3.2 p.256–257.
- [ ] Passing the DM loop-radiation estimate taken as proof of compliance — CM currents on PCB and cables usually dominate — §11.2.1.1 p.275.
- [ ] Low-speed interface cables (e.g. 19.2 kbaud RS-232) assumed harmless — they carry CM clock harmonics from a noisy ground — §11.2.1.3 p.277.
- [ ] Any external cable carrying > 5 µA common-mode current in the VHF band — likely radiated failure — §11.2.1.3 p.277.
- [ ] Shared ground/supply conductors between high-di/dt and sensitive circuits (common-impedance coupling; wire inductance dominates above tens of kHz) — §11.1.1.1 p.262–263.
- [ ] Unbalanced stray impedances on differential pairs converting DM to CM (no CM choke) — §11.1.5.4 p.272–273.
- [ ] Power/ground plane pair with large h and long straight parallel edges (patch-antenna radiation at L = λ/2√εr) — §11.2.1.2 p.275–276.
- [ ] Partially screened enclosure increasing CM capacitance and conducted emissions — §11.2.2.1 p.278.
- [ ] Relying on a single-level immunity "pass" for safety-related functions (no threshold/margin data) — §6.2.1 p.128.
