## 3. Mechanizable checks

Common trace-table columns assumed below (SI units unless noted): `net`, `type` (microstrip | stripline | diff_stripline | diff_microstrip), `w` (m), `t` (m) or `T_oz` (oz), `h` (m, trace-to-nearest-plane), `b` (m, plane spacing, stripline), `er` (Dk at f_spec), `tan_d` (loss tangent at f_spec), `f_spec` (Hz), `Z0` (ohm), `v0` (m/s, or derived c/sqrt(er_e)), `length` (m), `tr` (s, 10-90), `bit_rate` (b/s), `sigma` (S/m; default 5.98e7 ED Cu), `kp` (proximity factor; default from Table 5.1 or 1.6-2.0), `kr` (roughness factor; default 1), `Rs_drv` (ohm), `C_load` (F), `n_loads`, `temp_range` (degC). Constants: c = 2.998e8 m/s, mu0 = 4*pi*1e-7 H/m, 1 Np = 8.686 dB.

`CHECK-knee-frequency`: inputs `tr` → f_knee = 0.5/tr; f_edge = 0.35/tr; omega_knee = pi/tr → informational (feeds all other checks; the analysis bandwidth for every parasitic is f_knee) → margin n/a → JOHNSON03-1001, 1002, 1003, 1122.

`CHECK-trace-rdc`: inputs `w`, `T_oz` (or `t`), `length`, `temp_range` → R_DC = 4.798e-4/(w*T_oz) ohm/m (= 1.669e-8/(w*t)); R_total = R_DC*length*(1 + 0.0039*(T - 25)); for differential add both conductors (ka = 2) → pass if R_total(T_max) <= 0.25*Z0 (RC-free per l_RC with Delta = 1/4) and meets any DC-drop budget → margin = 0.25*Z0/R_total - 1 → JOHNSON03-1060, 1063, 1061, 1229, 1245.

`CHECK-lumped-element`: inputs `length`, `R_DC` (ohm/m), `Z0`, `v0`, `tr` → L = Z0/v0, C = 1/(Z0*v0); gamma = sqrt((j*omega*L + R_DC)*(j*omega*C)) at omega = pi/tr; x = abs(length*gamma) → pass (lumped; pi model within ~1% if Zs/Zc and Zc/ZL < 2) if x < 0.25 → margin = 0.25/x - 1 → JOHNSON03-1124, 1126, 1129.

`CHECK-short-line-transparency`: inputs `length`, `Z0`, `v0`, `R_DC`, `Rs_drv`, `C_load` (total), `tr` → at omega_edge = 2*pi*0.35/tr: Z_Cline = 1/(omega*length*C); Z_series = abs(length*(j*omega*L + R_DC)); Z_load = 1/(omega*C_load) → pass if x < 0.25 AND Rs_drv <= Z_Cline/10 AND Z_series <= Z_load/10 (a 2:1 ratio rang prodigiously in the book's example); if lumped but failing, flag resonance f_res = 1/(2*pi*sqrt(length*L*(length*C/2 + C_load))) vs f_edge → margin = min(Z_Cline/(10*Rs_drv), Z_load/(10*Z_series)) - 1 → JOHNSON03-1134, 1136, 1137. (The 10x factor quantifies "far less than"; conf low.)

`CHECK-rc-critical-length`: inputs `length`, `R_DC` (ohm/m, signal + return), `Z0` → l_RC = 0.25*Z0/R_DC (= (Delta/R_DC)*sqrt(L/C)) → pass (no RC-mode behavior; terminate with Z0) if length < l_RC; else flag mixed RC/LC (equalization / frequency-varying termination may be needed) → margin = l_RC/length - 1 → JOHNSON03-1138, 1168, 1224.

`CHECK-region-breakpoints`: inputs `R_DC`, `R0` (skin R at omega0 incl. kp, kr), `omega0 = 2*pi*f_spec`, `Z0`, `v0`, `tan_d`, `length`, `b` or `h`, `er` → omega_LE (exit lumped) = 0.25/(length*sqrt(L*C)) if length < l_RC else (0.25/length)^2/(R_DC*C); omega_LC = R_DC/L; omega_delta = omega0*(R_DC/R0)^2; omega_d = (1/omega0)*((v0*R0)/(Z0*tan_d))^2; omega_c = pi*c/(b*sqrt(er)) (stripline) or k*pi*c/(h*sqrt(er)), k = 1/10..1/6 (microstrip) → report the region containing omega_knee and f_baud/2; pass if omega_knee < omega_c/10 (microstrip: well below k-scaled cutoff) → margin = omega_c/(10*omega_knee) - 1 → JOHNSON03-1126, 1138, 1154, 1170, 1182, 1195, 1198 (Table 3.10 as test vector: expect 9.58 MHz, 27.1 MHz, 498 MHz, 142 GHz).

`CHECK-skin-onset-rect`: inputs `w`, `t`, `sigma`, `kp`, `ka` → omega_delta = (8/(mu0*sigma))*((w + t)/(w*t))^2*(ka/kp)^2; delta(f) = sqrt(2/(2*pi*f*mu0*sigma)) → informational; flag if f_knee within 0.1x..10x of f_delta (mixing zone: use z_BETTER model, not z_SIMPLE) → JOHNSON03-1067, 1069, 1075, 1085 (test vector: w = 0.008 in, t = 0.00065 in, kp = ka = 1 -> 75 MHz).

`CHECK-roughness-onset`: inputs `h_pv` (foil avg peak-to-valley, m), `sigma`, `f_nyquist = bit_rate/2` → h_RMS = 0.29*h_pv; f_rough = 2/(2*pi*mu0*sigma*h_RMS^2) → if f_nyquist >= f_rough apply kr in 1.1-1.5 (worst 2.0) to R0; pass if kr-adjusted loss still within CHECK-attenuation budget → margin via CHECK-attenuation → JOHNSON03-1087, 1088 (test vector: 6 um p-v -> ~1.5 GHz; 18 um -> ~160 MHz).

`CHECK-r0-skin`: inputs `w`, `t`, `sigma`, `kp`, `kr`, `f_spec` → p = 2*(w + t); R0 = (kp*kr/p)*sqrt(2*pi*f_spec*mu0/(2*sigma)) ohm/m → compare with Table 5.1 row for same w/h (within ~2-5%) → informational → JOHNSON03-1068, 1230, 1232 (test vector: Table 3.10 differential stripline -> 76.74 ohm/m with kp = 3.2).

`CHECK-attenuation-at-f`: inputs `length`, `R_DC`, `R0`, `Z0`, `v0`, `tan_d`, `f_spec`, evaluation frequency f (default bit_rate/2) → omega = 2*pi*f, omega0 = 2*pi*f_spec; above skin onset A_dB(f) = 4.34*length*[(R0/Z0)*sqrt(omega/omega0) + (omega*tan_d/v0)*(omega/omega0)^(-tan_d/pi)] [3.150]; near/below onset replace (R0/Z0)*sqrt(omega/omega0) by Re(R(omega))/Z0 with R(omega) = sqrt(R_DC^2 + 2j*R0^2*omega/omega0) [3.4] (or evaluate the full model [3.2]-[3.10]) → pass if A_dB(f_baud/2) <= budget: 3 dB for unequalized NRZ with > 70% eye opening, 3.5 dB aggressive NRZ limit, ~1 dB (about 10% amplitude) for ordinary single-ended CMOS/TTL receivers → margin_dB = budget - A_dB → JOHNSON03-1114, 1173, 1182, 1189, 1200, 1203, 1258, 1260.

`CHECK-loss-percent-per-inch`: inputs per-inch skin and dielectric losses p_s, p_d (fraction/in, from Fig 5.11 or CHECK-attenuation: p = 1 - 10^(-dB_per_in/20)), `length_in` → remaining a = (1 - p_s - p_d)^length_in; loss = 1 - a (dB/m = 3.44 x %/in) → pass if loss <= 10% (single-ended CMOS/TTL) or <= design budget (e.g. ~24% only with well-centered thresholds) → margin = budget - loss → JOHNSON03-1259, 1260.

`CHECK-loss-tilt`: inputs attenuation curve A(f) (from CHECK-attenuation), `bit_rate`, code type (NRZ: f_low ~ DC or 1/10 of rate; DC-balanced code: lowest code frequency) → tilt = A(bit_rate/2) - A(f_low) → pass (no EQ) if tilt <= 3 dB; 3-6 dB: fixed linear EQ recommended; > 6 dB marginal; > 12 dB adaptive EQ required; never > 6 dB unequalized binary → margin = 3 dB - tilt → JOHNSON03-1144, 1200, 1209.

`CHECK-bandwidth-vs-bitrate`: inputs A(f) → f_3dB where A = 3 dB → pass if f_3dB >= 0.7*bit_rate (robust unequalized binary) → margin = f_3dB/(0.7*bit_rate) - 1 → JOHNSON03-1202.

`CHECK-loss-negligible-exemption`: inputs `length`, `tr`, material → exempt from loss analysis if (length <= 0.25 m AND tr >= 500 ps) [trace losses] and, for FR-4 dielectric loss, length <= 10 in AND tr >= 500 ps → pass = exempt (else run CHECK-attenuation) → JOHNSON03-1226, 1237.

`CHECK-risetime-degradation`: inputs `length`, `R0`, `Z0`, `omega0`, `tr_in`, lumped loads list (C_i, L_i), RC data if RC mode → skin: tau_s = (2/omega0)*(length^2*R0^2/(4*Z0^2)); T50_skin = 1.099*tau_s; t10-90_skin = (31.664 - 0.1848)*tau_s (long tail: T99 = 3183*tau_s); lumped C: t_FWD = sqrt(tr^2 + (2.2*Zc*C/2)^2) per discontinuity; RC mode (open end, low-Z drive): t10-90 = 0.901*length^2*R*C; dielectric: from inverse FFT of [3.140] (no closed form); total t_out = sqrt(tr_in^2 + t_skin^2 + t_diel^2 + sum(2.2*tau_i)^2) → pass if t_out <= design fraction of unit interval (user budget; Johnson's examples keep settling within the bit) AND T99_skin/T_bit is covered by the test pattern → margin = budget/t_out - 1 → JOHNSON03-1149, 1178, 1180, 1269.

`CHECK-prbs-run-length`: inputs `tau_s` (or T50), `bit_rate` → N_run = T99/T_bit = (3183/1.099)*T50*bit_rate → pass if PRBS pattern longest run >= N_run (e.g. 29 bits for T50 = 1 ns at 10 Mb/s); flag a 7-bit PRBS (max run 7) as leaving 2-3% ISI untested → margin = run/N_run - 1 → JOHNSON03-1179.

`CHECK-impedance-tolerance`: inputs nominal `w`, `h`, `er`, `t` and tolerances dw, dh, der (e.g. +/-1 mil on 3 mil) → sensitivity estimate dZ/Z = 0.5*dh/h - 0.5*dw/w - 0.5*der/er (from Z ~ sqrt(h/(w*er_e)); thickness secondary) combined worst-case (sum of magnitudes) and RSS; microstrip er_e by Bahl-Garg [5.4]-[5.6] or field solver; add soldermask/plating shift (Table 5.4: 0.5-mil mask lowers er_e ~0.07-0.2 and fab narrows w ~0.3-0.5 mil) → pass if worst-case dZ/Z <= spec tolerance (e.g. +/-10%) → margin = tol - abs(dZ/Z) → JOHNSON03-1084, 1227, 1238, 1247. (Sensitivity exponents are Johnson's "approximately"; conf medium. Also flag 2-D solver error of the same order as the geometric tolerance, e.g. +/-33% for a 3 +/- 1 mil trace.)

`CHECK-microstrip-er-eff`: inputs `w`, `h`, `t`, `er` → F = (1 + 12*h/w)^(-1/2) (+ 0.04*(1 - w/h)^2 if w/h <= 1); er_e = (er + 1)/2 + ((er - 1)/2)*F - C_t (C_t thickness term); v0 = c/sqrt(er_e); tan_e = (er/er_e)*((er_e - 1)/(er - 1))*tan_d → informational; cross-check Table 5.1 (~3%) → JOHNSON03-1238, 1240.

`CHECK-lumped-discontinuity`: inputs per discontinuity (pad, via, connector, bend, stub): C (F) or L (H), `Z0`, `tr`, noise-margin budget fraction m → a/dV = Z0*C/(2*tr) (shunt C) or L/(2*Z0*tr) (series L) → FAIL if a/dV > 0.25; pass if a/dV <= m (the logic family's reflection allocation) → margin = m - a/dV → JOHNSON03-1269, 1274, 1278.

`CHECK-loaded-impedance`: inputs `Z0`, `v0`, `length`, loads (n_loads x C_each), spacing vs tr → C_LINE = (length/v0)/Z0; Z_LOADED = Z0*sqrt(C_LINE/(C_LINE + C_LOAD)); delay_LOADED = delay*Z0/Z_LOADED → pass if Z_LOADED within impedance tolerance (else narrow the trace in the loaded section) → margin = tol - abs(1 - Z_LOADED/Z0) → JOHNSON03-1278, 1279 (test vector: 1.2 pF/cm + 0.72 pF/cm -> 0.79).

`CHECK-pothole-compensation`: inputs `Z0`, `CL` or `Ls`, `v`, achievable k (Z1/Z0), `tr` → capacitive: x = Z0*CL*v*k/(k^2 - 1), t_LOADED = Z0*CL*k^2/(k^2 - 1); inductive: x = (Ls/Z0)*v*k/(1 - k^2), t_LOADED = (Ls/Z0)/(1 - k^2) → pass if tr >= 3*t_LOADED (conservative 6x) → margin = tr/(3*t_LOADED) - 1 → JOHNSON03-1271, 1272 (test vector: 50 ohm, 3 pF, k = 2 -> 1.446 cm, 200 ps, needs tr >= 600 ps).

`CHECK-via-first-order`: inputs `Lv`, `Cv` (incremental), `Zc`, `tr` → Zv = sqrt(Lv/Cv); tv = sqrt(Lv*Cv); if Zv < Zc: C_EXCESS = Cv - Lv/Zc^2, a/dV = Zc*C_EXCESS/(2*tr); else L_EXCESS = Lv - Cv*Zc^2, a/dV = L_EXCESS/(2*Zc*tr) → pass if tr >= 3*tv AND a/dV within budget (and < 0.25) → margin = min(tr/(3*tv), budget/(a/dV)) - 1 → JOHNSON03-1313, 1317, 1318, 1320.

`CHECK-via-stub-resonance`: inputs stub length l_stub (unused via barrel beyond the signal layer, m), `er`, `tr` → tv = l_stub*sqrt(er)/c; f_notch = 1/(4*tv) (pi-model ~10% lower) → pass if f_knee <= f_notch/1.1 with margin (recommend >= 2x); else back-drill, blind/buried via, or lower-band coding → margin = 0.9*f_notch/f_knee - 1 → JOHNSON03-1315 (test vector: 6.35 mm, er 4.3 -> 44 ps, 5.7 GHz).

`CHECK-return-via-inductance`: inputs h (plane separation traversed, in), r (hole radius, in), s (distance to nearest stitching via(s), in), count of symmetric return vias (1, 2, 4), plane potentials (same / different) → Lv = h*5.08*(2*ln(s/r)) | h*5.08*(1.5*ln(s/r) - 0.347) | h*5.08*(1.25*ln(s/r) - 0.347) nH (+ bypass-capacitor mounting L if planes differ) → then run CHECK-lumped-discontinuity with L = Lv; FAIL if a layer-changing via between different-potential planes has no bypass capacitor nearby → margin as CHECK-lumped-discontinuity → JOHNSON03-1276, 1320, 1322.

`CHECK-via-crosstalk`: inputs s1 (aggressor to shared return via), s2 (aggressor to victim), s3 (return via to victim), r, h (in), `dV`, `Zc`, `tr`, noise budget V_n → L_M = h*5.08*ln(s1*s3/(s2*r)) nH; V_peak = (dV/Zc)*L_M/tr → pass if V_peak <= V_n → margin = V_n/V_peak - 1 → JOHNSON03-1323.

`CHECK-series-term-stub`: inputs t_STUB (driver-to-resistor delay), Z_STUB, Ls (package, H), `Z0`, `dV`, `tr` → L_STUB = t_STUB*Z_STUB; a = (dV/2)*((L_STUB + Ls)/Z0)/tr → FAIL if t_STUB > tr/3; pass if t_STUB <= tr/6 (for >= 20 dB reflected-wave attenuation) and a <= noise allocation → margin = (tr/6)/t_STUB - 1 → JOHNSON03-1280, 1281 (test vector: 6000 pH, 70 ohm, 72 ps, 3.3 V, 1 ns -> 260 mV).

`CHECK-end-term-stub`: inputs t_STUB (terminator-to-receiver), Z_STUB, C_IN, `Z0`, `dV`, `tr` → C_STUB = t_STUB/Z_STUB; a/dV = Z0*(C_STUB + C_IN)/(2*tr) → FAIL if t_STUB > tr/3 (~20% reflection); pass if t_STUB <= 0.1*tr (~5%) and a within budget; prefer fly-by (receiver before terminator) → margin = (0.1*tr)/t_STUB - 1 → JOHNSON03-1282, 1283.

`CHECK-termination-needed`: inputs `length`, `v0`, `tr`, termination style, `Rs_drv`, `Z0` → f_res1 = v0/(4*length) (voltage-driven open line); lumped test x = abs(length*gamma(pi/tr)) → pass (no termination required) if x < 0.25 and no heavy reactive load; else require end, source or both-ends termination; for source termination compute abs(G_s) = abs(Rs_min + Rt - Z0)/(Rs + Rt + Z0) over the driver's Rs range and n_settle = ln(0.05)/ln(max abs(G_s)) round trips before sampling → margin = 0.25/x - 1 (lumped) or first-incident requirement abs(G_s) <= spec → JOHNSON03-1032, 1124, 1127, 1162, 1164, 1284.

`CHECK-crosstalk-spacing`: inputs `s` (edge or center spacing), `h`, `type`, crosstalk budget X_max → X_est ~ 1/(1 + (s/h)^2) (Lorentzian return-current spread; anchor s/h = 100 -> ~1e-4 = -80 dB; approximately quadratic in s and h) for microstrip over a solid plane (stripline falls faster); use 2-D solver for final numbers → pass if X_est <= X_max and no plane gap/slot crosses aggressor or victim → margin_dB = 20*log10(X_max/X_est) → JOHNSON03-1083, 1290, 1288. (Closed form is a low-confidence estimator; conf medium.)

`CHECK-next-saturation`: inputs coupled length l_c, `v0`, `tr` → t_overlap = l_c/v0; NEXT fraction of saturation = min(1, 2*t_overlap/tr) → informational: if t_overlap > tr/2, shortening the parallel run does not reduce NEXT (only spacing/height/termination do) → JOHNSON03-1293.

`CHECK-microstrip-dispersion`: inputs `h`, `bit_rate`, `type` → h_max = 0.5 mm*(10e9/bit_rate) (FR-4 microstrip); lambda/h at f_-6dB (~0.35/tr ... Johnson uses 15 GHz for 35 ps) with lambda = c/(f*sqrt(er)) → pass if h <= h_max (equivalently lambda/h >= ~74 comfortable, fail near 6:1) → margin = h_max/h - 1 → JOHNSON03-1196, 1254, 1256.

`CHECK-stripline-cutoff`: inputs `b`, `er`, f_knee → fc = c/(2*b*sqrt(er)) → pass if f_knee <= fc/10 → margin = fc/(10*f_knee) - 1 → JOHNSON03-1195, 1255 (test vector: 0.5 mm, er 4.3 -> 141 GHz).

`CHECK-stripline-edge-distance`: inputs trace-to-plane-edge distance d_edge, `h` → pass if d_edge >= 20*h → margin = d_edge/(20*h) - 1 → JOHNSON03-1025.

`CHECK-nickel-finish`: inputs surface finish on trace (not just pads), f_nyquist → if Ni (ENIG/electroless Ni) plated on high-speed trace surfaces at ~1 GHz: R_AC,eff = R0*((1/3)*sqrt(4.5*mu_r) + 2/3) with mu_r = 10 -> x2.9 → FAIL for long high-speed traces unless loss budget covers x2.9; recommend mask-before-plate (pads only) → JOHNSON03-1235, 1236.

`CHECK-elmore-delay`: inputs RC tree (series R_i along path, downstream C per node, distributed RC lines as R_line, C_line) → tau = sum_i R_i*C_downstream_i (distributed line contributes R_line*C_line/2 for its own C); t50_est <= tau (upper bound) → pass if tau <= timing budget (well-damped RC only; FAIL applicability if inductance or non-monotonic) → margin = budget/tau - 1 → JOHNSON03-1152, 1153.

`CHECK-worst-case-bounded-response`: inputs sampled step response s[n] (from measurement or simulation, driven 0..Vcc by the system's own driver) → find local extrema, Y = (1/2)*sum(abs(s[k+1] - s[k])) over successive extrema (excursion above/below DC steady state) → pass if Y <= noise/crosstalk/PDN budget → margin = budget/Y - 1 → JOHNSON03-1034, 1035, 1036.

`CHECK-shield-bond`: inputs Z_bond (shield-to-chassis impedance at f_op), Z_cm (cable common-mode impedance) → SE_dB = 20*log10(Z_cm/Z_bond); required Z_bond <= 0.1 ohm at ~1 GHz for 1000BASE-CX class (57 dB); capacitive bond ESL must be < Z_bond/(2*pi*f) (16 pH) → pass if Z_bond <= 0.1 ohm (or SE >= requirement) and 360-degree metallic contact → margin = 0.1/Z_bond - 1 → JOHNSON03-1309, 1310.

`CHECK-dielectric-model-causality`: inputs tabulated Dk(f), tan(f) for the simulator → for constant-tan segments verify Dk slope: Dk(f2)/Dk(f1) = (f2/f1)^(-2*theta/pi) (per decade factor 10^(-2*theta/pi)); verify Hilbert consistency (FFT method) and simulated step response under heavy dielectric/light resistive loss shows no pre-t=0 response beyond the bulk-delay correction → pass if deviations <= ~1% (the FFT method's stated accuracy) → JOHNSON03-1102, 1103, 1104, 1106, 1118, 1243.

`CHECK-fft-sim-setup`: inputs dT, N, tr_min (Gaussian-filtered), t_settle, bulk delay → pass if dT <= tr_min/4 (Gaussian; /10 parabolic), N*dT >= 2*t_settle, stimulus starts and ends at the same value, bulk delay removed or < N*dT, impulse test X_k = 1 passes → JOHNSON03-1215, 1216, 1218, 1220, 1222.

## 5. Pitfalls, failure modes, review checklist

- Using 0.35/tr as "the" bandwidth for parasitic screening; Johnson uses 0.5/tr as the conservative knee (p.2).
- Believing a short line never needs termination: a zero-length line between a ferociously reactive source and load still resonates (p.135, p.148; 65-ohm 1-in trace + 10 pF rings, Fig 3.7).
- Assuming a transmission line's input impedance is capacitive: only true when delay <= tr/6 (at most tr/3) AND lightly loaded (p.141).
- Routing an IC ground ball to a remote via with a trace: the trace looks inductive and creates ground bounce (p.141-142, Fig 3.5).
- Forgetting the return-path resistance (ka) or the return-path/ground impedance: it affects the signal as much as series signal impedance (p.55-56, p.115-117).
- Using z_SIMPLE = R_DC + R_AC near the skin-effect onset (50% error at onset, infinite DC inductance) (p.72-73).
- Treating a single measured Dk as frequency-independent or unspecified in frequency; Dk must be quoted with its frequency (1 kHz, 1 MHz or 1 GHz) (p.97-98).
- Feeding non-causal Dk/tan tables to SPICE W-element models (bogus simulations); constant loss tangent at all frequencies is non-physical (p.105-107).
- Trusting bulk-material loss numbers: trapped solvents/contaminants can double measured loss; measure a test board (p.102-103).
- Confusing resin content by weight with by volume in mixture formulas (p.100, p.274).
- Relying on the skin/dielectric Zc cancellation near omega_delta (coincidence; varies with temperature and moisture) (p.204-205).
- Designing systems that depend on a minimum interconnect attenuation (break when cabling/laminate is upgraded) (p.193-194).
- Using truncated step responses or short PRBS patterns to characterize skin-effect channels (optimistic BER) (p.197-198).
- Ignoring dielectric loss because it is "small": FR-4 dielectric loss matters below 1 GHz; skin and dielectric mix over a very broad band (p.201, p.268).
- Printed-text inconsistencies to watch: p.172 TDR slope printed 4.62e9 V/s (arithmetic gives 4.62e6 V/s); p.209 says dielectric loss grows with sqrt(f) (it grows with f); p.183 PTR says end termination is least sensitive to line resistance while the prose says both-ends termination shows no tilt; Table 5.1 first stripline row dB/in printed .013 (should be 0.130); Table 5.4 last row 2.98 dB/m (formula gives 2.77); Table 5.9 header "nF" (pF) and transposed lengths.
- Nickel (ENIG) plating over trace surfaces: ~2.9x resistive loss at ~1 GHz, one-third useful length; 2-D solvers do not predict it (p.266-268, p.278).
- Soldermask/plating lowers Z0; fab narrows traces to compensate, raising R; coating sag makes exact prediction impossible (p.277-279).
- Microstrip trace heights > 0.5 mm (20 mil) at 10 Gb/s: microstrip dispersion rings even with perfect termination (p.284-288).
- Using big fat low-loss traces without proportionally larger spacing: crosstalk scales with h^2 (p.282).
- Thin cores (3 mil) with 3-mil traces: glass-weave modulation of impedance/delay (p.273).
- Two-layer boards with power/ground grids instead of planes: terminations cannot reliably control ringing (p.256).
- Plane slots, cuts or gaps under (especially perpendicular to) high-speed traces: tremendous crosstalk and radiation increase (p.318-319).
- Layer-change vias between different-potential planes without a nearby bypass capacitor or stitching via (p.305-306, p.351-354).
- Series terminator placed more than tr/3 from the driver (resonance); > tr/6 costs the 20 dB reflection target (p.309-311).
- End terminator ahead of a receiver stub: stub of tr/3 reflects ~20% (termination useless); use fly-by (p.312-313).
- Computing Rt = Z0 - Rs for CMOS drivers whose Rs spans 20-200 ohm: first-incident switching impossible; wait ~5 round trips or use low-Z driver + precise resistor (p.314-315).
- Assuming crosstalk is capacitive: it is largely mutual-inductive; heavier loads increase it; opposite-direction victims flip polarity (p.323-325).
- Source-terminated aggressor + end-terminated victim does NOT reduce NEXT (the reciprocal combination does) (p.322).
- Opposite-direction links routed adjacent: NEXT lands directly at the victim receiver (p.323).
- Open pin-field connectors with too few power/ground pins or too many heavy loads: phantom interrupts, resets, double clocking (p.327).
- Assuming the fab built the board as laid out (enlarged antipads cut ground webs; >2 V crosstalk example) (p.328-329, p.353-354).
- Straddle-mount/SMA pads sized for microwave microstrips placed over a close digital ground plane (0.69 pF, 43% reflection at 5 GHz) (p.332).
- Grounding a high-speed cable shield at one end only or via capacitors/RC: needs <= 0.1 ohm 360-degree metallic bond at both ends (p.336-338).
- Using "partial inductance" of a via or wire without the return path/mutual terms (p.339).
- Dangling via stubs in thick backplanes (quarter-wave notch ~5.7 GHz for 6.35 mm) (p.343-344).
- Stripping non-functional pads to cut via C increases pad-to-plane short risk from plating-solution capillary migration (p.350).
- Right-angle-bend paranoia (irrelevant to 2 Gb/s) vs real 10-Gb/s/skew/serpentine effects; rounding corners removes only 21% of the excess copper (p.304-305).
- FFT simulations without settling time, with mismatched start/end values, unremoved bulk delay (wrap-around), or ramp/square edges without band-limiting (p.242-251).
- Using Elmore delay on inductive, resonant or non-monotonic networks (p.165).
- Single-ended CMOS/TTL links whose total loss exceeds ~10% of swing (~1 dB) (p.288, p.290).
